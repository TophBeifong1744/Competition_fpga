## 校验与复现

仅需Python标准库校验快照（不重新运行算法/RTL）：

```text
python build_snapshot.py --verify-only
```

从含固定提交的原仓库重新构建到新目录：

```text
python build_snapshot.py --repo <仓库根目录> --out <新的归档目录>
```

结果应为 `PASS_SNAPSHOT_INTEGRITY`。这是逐文件原件一致性检查，不是新技术验收。ZIP是**选定验收材料快照，不是完整工程运行环境**；部分复现脚本仍需在固定提交的完整仓库中运行，外部工具及未打包依赖按原说明准备。未额外打包第三方数据手册PDF；原仓库保留其引用。
