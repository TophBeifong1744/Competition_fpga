## A/C 可执行的实物验收记录表

由 C 保存原生仪器文件、命令记录和完整视频，A 按固定源 SHA 与接线/顶层合同复核。接线和上电前应先确认两只舵机各自的真实标签或手册、允许供电/信号电平、供电能力、公共地、控制板实际 PWM 引脚与约束；如与 5 V 报告冲突，以确认后的实物资料为准。A 机的 Vivado/Vitis 配置、构建和下载仍由 A 在其工程中操作。

| 顺序 | 操作 | 要保存的观察 | 完成状态 |
|---|---|---|---|
| 1 | 固定 `motor_drive.v` SHA、顶层实例参数、bit/elf/XDC 及板卡/电源身份；拍摄两轴接线与机械限位 | 源/产物 SHA、完整引脚表、实际供电与公共地、照片 | 待提供 |
| 2 | 舵机未接入负载时，在两路实际 PWM 引脚测量复位保持、释放、0°/中间/最大角的周期及高电平脉宽 | 双通道示波器原始波形或逻辑分析仪导出，通道、时间基准、命令时间戳 | 待提供 |
| 3 | 只给水平轴一拍 valid，再只给垂直轴一拍 valid，最后同拍给两轴不同目标；每次等待完整 PWM 帧 | 命令/valid 时序、两路 PWM 波形；另一轴不得因角度总线变化而更新 | 待提供 |
| 4 | 分别给水平轴和垂直轴若干安全的中间目标，测量启动位置、最终位置和停稳时间；重复命令与复位回位 | 连续完整视频、角度尺或编码器原始读数、目标与读数、误差与时间；观察是否持续旋转或撞限位 | 待提供 |
| 5 | 按实际机构可行范围检查两轴同时运动及复位后的回位，记录负载和供电波动 | 同步命令记录、两轴轨迹/终点读数、供电波形或电源日志 | 待提供 |

PWM 发送正确与机构到位是两项验收。v2 RTL 没有位置反馈或“到位”输出；到位判据须在试验前由 A/C 给出允许角度误差、停稳时间和测试负载，不能从仿真 PWM 推算。商品页的 360°/220°也不能直接当实际机械无障碍行程；机械端点测试必须以实物手册与安装余量为准。

后续需补：两只舵机铭牌或厂家手册/准确商品链接，购买/实物照片，电源型号与额定电流，板卡型号及双路 PWM 实际引脚/XDC，原生测试记录。无这些证据时 E03 保持待核验。
