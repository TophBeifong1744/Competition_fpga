# SoundSight 硬件外设采购指标

日期：2026-09-05  
状态：M0 采购筛选指标，具体型号与板级连接尚未冻结

## 1. 已知条件与采购原则

当前已有：

- 正点原子领航者 ZYNQ-7020 开发板；
- ADC 模块，具体型号、通道数和接口待确认；
- DAC 模块，具体型号、接口和输出能力待确认。

本项目真正需要的是“四路严格同步的原始音频”，不是四个能分别采到声音的通道。现有 ADC/DAC 只有在型号、接口、时钟和通道能力满足本文要求后才能计入可用硬件。

采购遵循以下顺序：

1. 先完成四路同步声音采集；
2. 再完成阵列结构和同源标定；
3. DOA 稳定后再采购或集成转台闭环；
4. 显示屏、无线通信、滑环等不影响核心闭环的器件暂缓购买。

## 2. 推荐采集路线

### 2.1 首选：四只数字 MEMS 麦克风

首选 PDM；若找到明确支持四路共享时钟的 TDM/I²S 模块，也可以候选。数字麦克风可以绕开模拟前置放大器和多通道模拟一致性问题，更适合先完成可靠的 FPGA 采集闭环。

| 指标 | 最低要求 | 推荐目标 | 淘汰条件 |
|---|---:|---:|---|
| 数量 | 4 只 | 同型号、同批次购买 5 只，1 只备用 | 少于 4 只 |
| 指向性 | 全向 | 四只声学结构完全一致 | 混用不同指向性 |
| 输出 | 原始 PDM 或原始 TDM/I²S | PDM，带左右沿/通道选择 | 仅输出 USB 音频或经过内部算法处理的数据 |
| 同步方式 | 四路共用同一个采样时钟 | 一个时钟输出驱动全部麦克风 | 每只麦克风自由运行、无法共用时钟 |
| 供电与 IO | 与 3.3 V LVCMOS 兼容 | 1.8～3.3 V 供电，3.3 V IO | 5 V 数据直接接入 PL |
| 信噪比 | ≥60 dBA | ≥64 dBA | 未给出 SNR 或明显低于 60 dBA |
| 灵敏度偏差 | ≤±3 dB | ≤±1 dB | 无公差说明且无法逐通道标定 |
| 频率范围 | 覆盖 200 Hz～4 kHz | 覆盖 100 Hz～8 kHz | 只有声强检测，不能还原语音波形 |
| PDM 时钟 | 支持约 3.072 MHz | 支持 1～3.25 MHz，48 kHz 下采用 64 倍过采样 | 时钟范围不覆盖设计值 |
| I²S/TDM 采样率 | 支持 48 kHz | 48 kHz、有效位宽 24 bit | 采样率不可固定或各通道时延不确定 |
| 自动处理 | 无 | 无 AGC、降噪、AEC、波束形成 | 内置不可关闭的 AGC/降噪/回声消除 |
| 引脚 | VDD、GND、CLK、DATA | 额外具有 L/R、SEL 或时隙选择 | 不公开时序或无法取得原始数据 |
| 资料 | 有完整数据手册与时序图 | 有原理图、PCB 尺寸和声孔说明 | 只有商品宣传页 |

PDM 接口的目标连接形式：

```text
ZYNQ PL PDM_CLK  -> 4 个麦克风共用 CLK
ZYNQ PL PDM_D01 <- 麦克风 0/1，共用数据线，以 SEL 区分上升沿/下降沿
ZYNQ PL PDM_D23 <- 麦克风 2/3，共用数据线，以 SEL 区分上升沿/下降沿
3.3 V / GND      -> 四路共用低噪声供电与参考地
```

购买前必须在数据手册中确认两个麦克风能否共用一根数据线；若不支持，则购买能独立引出四根 DATA 的模块并预留 1 个 CLK + 4 个 DATA。

### 2.2 备选：四只模拟麦克风 + 四通道同步 ADC

只有当现有 ADC 确认满足下表时才采用。该路线模拟电路、增益匹配和电源噪声风险更高，不是当前默认路线。

#### 模拟麦克风及前置放大器

| 指标 | 最低要求 | 推荐目标 | 淘汰条件 |
|---|---:|---:|---|
| 麦克风 | 4 只相同全向麦克风 | 同型号、同批次、可测灵敏度 | 混用不同模块 |
| 前置增益 | 四路固定且一致 | 增益误差 ≤0.5 dB | 带不可关闭的自动增益 AGC |
| 带宽 | 100 Hz～8 kHz | 低频截止一致、相位响应可查 | 只有包络/比较器输出 |
| 输出 | 能匹配 ADC 输入范围 | 差分输出优先 | 输出幅度、偏置和 ADC 不兼容 |
| 噪声 | 不明显限制 ≥60 dBA 的系统 SNR | 低噪声运放、独立去耦 | 电机启动时出现明显底噪或削顶 |

#### ADC 必须满足的指标

| 指标 | 最低要求 | 推荐目标 | 淘汰条件 |
|---|---:|---:|---|
| 通道数 | 4 路 | 4 路或以上 | 单通道/双通道且无法严格同步扩展 |
| 采样方式 | 四通道同时采样，或固定且可标定的统一时隙采样 | 四通道共用采样时基的音频 ADC | 四块模块使用四个独立晶振 |
| 采样率 | 48 kS/s/通道 | 48～96 kS/s/通道可配置 | 每路采样率不一致 |
| 有效分辨率 | ≥16 bit | 24 bit 音频数据接口 | 只有高标称位数但有效位数不足且无指标 |
| 数字接口 | 可直接进入 PL | TDM/I²S，3.3 V IO | USB、仅能进入 PC，或隐藏内部缓冲时延 |
| 时钟 | MCLK/BCLK/FS 关系明确 | FPGA 提供或锁定到同一主时钟 | 时钟来源、相位或复位行为不公开 |
| 延迟 | 通道间延迟固定 | 有数据手册给出的群延迟 | 通道延迟随启动或配置变化且不可测 |
| 模拟输入 | 与前置放大器幅度/偏置兼容 | 差分输入、输入范围和抗混叠明确 | 需要超出当前能力的高压模拟前端 |

高速 ADC 不等于适合音频阵列。如果现有 ADC 是单通道高速采样模块，即使采样率远高于 48 kS/s，也不能自动满足四路同步要求。

## 3. 麦克风阵列结构指标

首版采用水平二维正方形阵列，不采用直线阵列。直线阵列难以独立判断二维方向，并容易出现前后模糊。

| 指标 | 最低要求 | 推荐目标 |
|---|---:|---:|
| 阵元数量 | 4 | 4 |
| 阵列形状 | 水平二维非共线 | 正方形四角 |
| 相邻中心距 | 35～50 mm | 40 mm |
| 尺寸误差 | ≤1 mm | ≤0.5 mm |
| 高度误差 | ≤1 mm | 四个声孔同一平面 |
| 安装方向 | 四只一致 | 声孔方向完全相同且无遮挡 |
| 结构 | 刚性固定 | PCB、亚克力板或 3D 打印支架 |
| 坐标标识 | 有明确编号和正前方 | 标出 MIC0～MIC3、X/Y 轴和 0°方向 |

40 mm 相邻间距在 48 kHz 下的最大相邻时延约为：

\[
\frac{0.04}{343}\times 48000 \approx 5.6\text{ 个采样点}
\]

该间距为语音频段、角度分辨能力、空间混叠和机械尺寸之间的首版折中。结构最好能在 35～50 mm 范围更换孔位，便于实测后调整。

## 4. 接线与小型转接板指标

| 物料 | 数量 | 指标 |
|---|---:|---|
| 麦克风转接板或洞洞板 | 1 | 能汇总 CLK、DATA、3.3 V、GND，并设置各通道 SEL |
| 排针/插座 | 1 批 | 2.54 mm，连接方式必须防反插 |
| 信号线 | 若干 | 原型线长尽量 ≤20 cm；CLK-GND、DATA-GND 成对布线 |
| 串联电阻 | 22～47 Ω 若干 | 放在 FPGA 时钟输出端附近，用于抑制边沿振铃，最终值由波形确认 |
| 去耦电容 | 每麦克风 0.1 µF + 1 µF | 靠近模块电源脚；若模块已带去耦则核对原理图 |
| 测试点 | CLK、各 DATA、3.3 V、GND | 示波器和逻辑分析仪能够直接夹取 |

最终演示版不使用长杜邦线悬空连接。扩展口具体引脚、Bank 电压和 XDC 必须依据手中开发板的底板版本与官方引脚表冻结。

## 5. 自动声源跟踪转台指标

转台在 DOA 稳定后再做闭环，但现在可以按下列指标筛选机械和电气方案。

### 5.1 执行机构

| 指标 | 最低要求 | 推荐目标 | 淘汰条件 |
|---|---:|---:|---|
| 运动形式 | 水平单轴旋转 | 独立承重轴承 + 电机传动 | 用电机轴直接承受整个设备重量 |
| 有效转角 | ≥270° | 约 ±160°，保留线缆安全区 | 只有很小转角且无法覆盖演示范围 |
| 角速度 | 可调，≥20°/s | 30～60°/s | 速度不可控、启动冲击明显 |
| 定位误差 | ≤3° | ≤1° |
| 重复定位误差 | ≤3° | ≤1° |
| 回程间隙 | ≤3° | ≤1° | 明显松旷导致持续摆动 |
| 驱动方式 | 可由 3.3 V 控制信号驱动 | STEP/DIR 或可读写位置指令 | 必须直接给 PL 输入 5 V 信号 |
| 微步 | ≥1/8 | ≥1/16 | 低速振动和噪声无法接受 |
| 转矩余量 | ≥计算动态需求的 2 倍 | ≥3 倍 | 满载启动易失步 |

水平转台绕竖直轴旋转，重力本身不会直接形成绕轴转矩。应先估算所有转动部件对旋转轴的转动惯量

\[
I\approx\sum_i m_i r_i^2
\]

再按

\[
T_{estimate}=I\alpha+T_{friction}+T_{cable}
\]

估算加速转矩，并乘不少于 3 的安全系数。最终还要计入皮带/齿轮效率和驱动电流限制。应优先减小转动惯量、采用独立承重轴承并让质量靠近旋转轴，而不是单纯购买更大电机。

### 5.2 电机驱动器

| 指标 | 最低要求 | 推荐目标 |
|---|---:|---:|
| 电机类型 | 双极步进电机或带位置反馈的执行器 | 低噪声双极步进方案 |
| 控制接口 | STEP/DIR/ENABLE | STEP/DIR + UART/SPI 状态配置 |
| 逻辑电平 | 明确兼容 3.3 V | 3.3 V 可直接识别 |
| 电流能力 | 连续电流 ≥电机额定相电流 | 留 20%～30% 裕量并可调限流 |
| 细分 | ≥1/16 | 内部插值至更高微步 |
| 保护 | 过流、过温、欠压 | 具有故障状态输出 |
| 声学表现 | 可低速平稳运行 | 静音斩波模式，可配置保持电流 |

### 5.3 位置反馈与限位

| 物料 | 最低指标 | 推荐指标 |
|---|---:|---:|
| 绝对角度编码器 | ≥10 bit/圈 | ≥12 bit/圈，I²C/SPI 或 PWM 输出 |
| 零位传感器 | 1 个 | 非接触霍尔或光电开关 |
| 机械限位 | 左右各 1 个 | 常闭触点，断线也能触发故障 |
| 急停/总使能 | 能切断电机驱动 | 独立于软件的硬件使能 |

编码器分辨率不是最终角度精度。装配偏心、传动间隙、阵列零位和设备正前方的标定误差仍需单独测量。

### 5.4 机械件

- 转台轴承：额定载荷至少为实际载荷的 3 倍；径向间隙小，无明显晃动；
- 传动：优先同步带或低间隙齿轮减速，推荐减速比约 2:1～4:1；
- 底座：能够分别固定开发板、阵列、电机和驱动板，不能让电机振动直接作用于麦克风板；
- 线缆：先限制在约 ±160°，暂不购买滑环；需要连续旋转时再评估滑环的通道数、额定电流和信号完整性；
- 防护：必须有机械止挡，防止软件错误拉扯线缆。

## 6. 电源指标

| 电源对象 | 要求 |
|---|---|
| ZYNQ 开发板 | 使用原装或已验证的独立适配器 |
| 麦克风 | 使用安静的 3.3 V 电源；总电流留 2 倍以上裕量 |
| 电机 | 使用独立电机电源，不从开发板 3.3 V/5 V 扩展口取电 |
| 电机电源容量 | 连续电流 ≥驱动器设定电流需求的 1.5 倍，启动时不掉压 |
| 接地 | 信号地必须共地，但电机大电流回路与麦克风地在电源入口附近单点汇合 |
| 驱动端储能 | 驱动器附近放置符合其手册要求的电解/固态电容和 0.1 µF 高频去耦 |
| 保护 | 电机电源开关、保险丝或自恢复保险、反接保护和急停/使能 |

电机线与麦克风时钟/数据线分开走线；电机线尽量绞合。验收时必须比较电机断电、保持和转动三种状态下的四路噪声底。

## 7. 音频输出与扬声器指标

现有 DAC 和领航者底板可能已经具备音频输出能力，因此本项暂缓购买，先核对实际硬件。

若需要外购：

| 项目 | 最低要求 | 推荐目标 |
|---|---:|---:|
| DAC 输入 | 48 kHz、16 bit | 48 kHz、24 bit、I²S/PCM |
| 通道 | 1 路 | 2 路，实际使用单声道也可 |
| 功放 | 能驱动实际扬声器 | 3～5 W，THD+N <1% |
| 扬声器 | 4 Ω 或 8 Ω，与功放匹配 | 3～5 W 全频单元 |
| 调试输出 | 耳机或线路输出 | 先用耳机/有源音箱验证，减少声反馈 |

最终扬声器不能靠近麦克风阵列，否则系统会把自身输出当作声源。扬声器播放与定位同时工作时，还要增加回声处理或时分工作策略；这不是第一阶段采购重点。

## 8. 测试与标定工具指标

实验室已有的工具无需重复购买。

| 工具 | 最低指标 | 用途 |
|---|---:|---|
| 示波器 | 2 通道、≥50 MHz | 检查时钟、电平、振铃、电源噪声 |
| 逻辑分析仪 | ≥8 通道、≥24 MS/s | 检查 PDM/I²S、通道顺序和连续性；推荐 ≥100 MS/s |
| 数字万用表 | 基础电压/电流/通断 | 上电前检查与功耗测量 |
| 可控声源 | 能稳定播放 200 Hz～8 kHz 扫频、白噪声和语音 | 同源测试、DOA 和 SNR 标定 |
| 角度标定盘 | 分度 ≤1° | 测量真实声源角度和转台误差 |
| 卷尺/激光测距 | 精度 ≤5 mm | 固定声源距离与阵列位置 |
| 三脚架/声源支架 | 高度可调且稳定 | 保证声源与阵列在同一水平面 |

## 9. 明确不应购买的器件

- 只输出高低电平的“声音检测模块”；
- 带不可关闭 AGC 的麦克风模块；
- 四个独立 USB 麦克风或内部同步机制不公开的 USB 麦克风阵列；
- 只因为采样率高就购买的单通道 ADC；
- 直接输出 5 V 逻辑、又没有可靠电平转换的模块；
- 用于最终转台但没有位置反馈、回程间隙明显的廉价舵机；
- M0 阶段的显示屏、无线模块、滑环和装饰性结构件。

## 10. 分批采购清单

### 第一批：立即用于 M0/M1

- 4+1 只满足第 2.1 节指标的同型号数字麦克风；
- 可调整间距的 40 mm 正方形阵列支架；
- 小型转接板、排针、信号线、22～47 Ω 电阻、去耦电容和测试点；
- 缺少时再补逻辑分析仪、示波器探测附件和标定声源。

### 第二批：四路采集闭环通过后

- 满足负载转矩的执行机构；
- 低噪声电机驱动器；
- 绝对角度编码器、零位传感器和两个机械限位；
- 转台轴承、2:1～4:1 传动件、刚性底座；
- 独立电机电源、保护器件和急停/使能。

### 第三批：DOA 与波束形成稳定后

- 仅在现有输出链路不满足时购买音频 DAC、功放和扬声器；
- 只有确认必须连续旋转时才采购滑环；
- 显示屏、外壳和演示优化件最后确定。

## 11. 购买前必须补齐的信息

在确定具体商品前，需记录：

1. 领航者核心板和底板的硬件版本、对应原理图及 IO 引脚总表；
2. 现有 ADC、DAC 的完整型号和模块照片；
3. ADC 的通道数、是否同步采样、时钟来源、数字接口和 IO 电平；
4. DAC 的数字接口、采样率、输出幅度以及是否带功放；
5. 转台上实际需要转动的部件、总质量、尺寸和质心位置；
6. 是否已有示波器、逻辑分析仪、万用表、3D 打印或机械加工条件。

在以上信息未补齐前，只能按指标筛选候选，不能冻结型号、引脚或电源方案。

## 12. 指标依据

以下资料只用于证明接口与指标路线可实现，不代表指定购买其中某个型号：

- [正点原子领航者 ZYNQ 开发板官方产品页](https://www.alientek.com/Product_Details_17/38.html)：用于确认板卡产品与官方资料入口；实际引脚仍以手中板卡对应版本的原理图和 IO 表为准。
- [Adafruit PDM 麦克风接口说明](https://cdn-learn.adafruit.com/downloads/pdf/adafruit-pdm-microphone-breakout.pdf)：给出 PDM 时钟、SEL 上升沿/下降沿通道选择和 1.8～3.3 V 供电示例。
