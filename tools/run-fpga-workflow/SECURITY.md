# Security policy

Report vulnerabilities privately through GitHub Security Advisories for this repository. Do not open a public issue containing credentials, proprietary RTL, customer data, bitstreams, board schematics, register maps, or sensitive logs.

The project provides engineering process prompts and scripts. It does not certify electrical safety, functional safety, timing closure, or board readiness. Physical wiring, power-up, motion, heating, laser, relay, high-voltage, and other high-energy operations require qualified human supervision and project-specific evidence.
