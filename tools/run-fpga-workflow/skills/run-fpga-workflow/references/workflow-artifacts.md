# Minimal useful artifacts

Reuse the original Issue/PR and existing evidence index. Record actual candidate/input/configuration, changed behavior, commands/results, reused/skipped/not-run scope, necessary originals and next responsible entry. Only material new design needs the applicable budget/interface detail. Schemas are optional validation aids, not universal paperwork. Failure summaries plus minimum necessary raw replace indiscriminate full failed-run retention. Do not falsify old evidence or discard quantitative inputs. Complete project ZIPs occur at useful delivery nodes; equivalent small repairs are direct increments. Generic references are technical lookup material; current SKILL and authorized project contract govern when to apply them.
