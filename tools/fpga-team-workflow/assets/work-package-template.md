# 一批可交付任务

新功能/重要增量：系统目标与S阶段；准确输入/候选；接口、数制、时钟复位、资源/缓存及吞吐延迟依据；一名结果责任入口、执行和下一接收人；允许路径/动作、保护项及写入归属；完成判据、必要命令/原件入口、实际Git权限。

工程同时说明：接合对象/就绪条件，ILA加入/复用/无需，首次或本次上板触发、现场操作者、正常/错误/停止判据和数据下一责任人。按能力配人，未知人数不影响任务定义；缺接任者标待认领，不假定已接单。

普通小修：父任务链接＋准确差异/影响＋必要检查/未测＋直接接收人，继承未变合同，不重填全表。

完成回报：实际改动和准确版本；实际运行/复用/跳过/未测；必要原件；重大问题和累计停止状态；下一可执行动作和写权释放。非作者判断只在重要模块/系统批次结合接入完成。
