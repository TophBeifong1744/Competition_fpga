## 赛题映射

依据AMD 2026选题指南第三赛道 §3.3.3.1、§3.3.5.2～3.3.5.5（PDF物理22～25页）：

| 要求 | 对应交付 | 验证边界 |
|---|---|---|
| 可复用经验技能包，放在skill/并有README | 本索引及各条目README/入口 | 不要求所有Skill都含脚本或必须两个；PYNQ加分不替代主作品 |
| 适用场景、用法、失效条件、已验证效果、失败/观察来源 | 各README，工程工作流的记录模板 | 只列实际运行结果；无硬件不填板测PASS |
| 可见的大模型协作和纠错、技能提炼过程 | 可见交互模板及对应包的报告取材 | 隐藏思维链、系统/开发者提示不提交 |
| 完整工程、仿真/验证、综合实现、板上输出与参考、可复现构建 | 工作流的独立证据类别与交付记录 | 模板齐全不表示工程齐全，局部通过不传给整机 |
| 英文路径、推荐目录或README映射、可再分发许可 | 当前Skill路径与项目发布预检 | 整仓库/第三方资料/公开身份仍须发布前检查，不直接打包官方PDF |
| Vivado/Vitis 2026.1推荐或2025.2；器件/资格声明 | 项目版本化配置与验收资料 | 2025.2符合所读版本指南；实际工程和器件声明另需证据 |

匿名要求另来自竞赛FAQ，不能归给AMD技能包条款。报告/视频/演示及公开材料均按届时已核对规则处理。大模型协作与技能包合计权重15，不是每个Skill自动得分。
