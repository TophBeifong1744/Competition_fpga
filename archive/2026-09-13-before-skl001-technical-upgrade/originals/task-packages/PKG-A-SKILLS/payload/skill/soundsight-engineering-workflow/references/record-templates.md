# 可选工程记录模板

按当前任务选择必要部分，复用已有包内记录；空值是模板字段，不是证据或新增开工门槛。填写后每条结论须绑定实际来源。项目可改标签，不必采用 G0～G7 或 H1/H2/H3。

## 2. 证据登记与四类验收

| ID | 原子事实/问题 | 类别 | 原件位置、页/行或对象 | 输入/构建版本及SHA-256 | 获取方式/执行者/日期 | 实际结果 | 限制/置信程度 |
|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |

| 能力/验收条件 | 模型证据/状态 | RTL仿真证据/状态 | 综合/实现/时序证据/状态 | 板测证据/状态 | 当前允许的最强结论 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

每格独立填写 PASS/FAIL/BLOCKED/NOT_RUN；不适用写原因。计划、预测、暂定参数单列，不写实测。静态检查、独立复核、复现另列，不填到硬件列。功能正常与最坏电气/时序保证分开；已批准暂缓项记触发条件，不主动新增测量任务。

## 3. 最小接口、早期诊断和包级准入

| 项目 | 必要内容 |
|---|---|
| 最小接口 | 通道/字段顺序、单位/数制/符号、编号/重启/错误、版本、暂定值及变更规则 |
| 诊断交付 | 实际source/capture point、原始数据及哈希、匹配元数据、原始编号/间断、未知标定、允许分析范围 |
| 算法包准入 | 输入输出、golden/边界测试、操作数/周期预算、缓存/带宽、定点/溢出风险、已有证据与失败、拟接入模块/版本 |

诊断解析不等待长稳；不以未测几何计算验收精度。无最终时序仍可评估原型准入，但不是实时通过。算法普通离线迭代不逐次审批；接口/预算/集成范围实质变化才重做相关准入决定。

准确命令或可复现GUI操作、工作目录、seed/参数：

预期/实际输出、退出码、首个不一致样本/帧/周期：

原始日志/输出哈希、派生文件转换、异常和排除项：

干净目录或独立复跑人/日期/命令/结果/未覆盖环境：

## 5. 可见AI交互和失败复测

| 交互ID/日期 | 用户可见请求 | 可见回答/建议 | 人工采纳、拒绝或纠正 | 修改理由和涉及版本/文件 | 实际复测命令/结果/证据 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

仅记录可见提示、回答、修改理由和验证结果；不得请求、重建或提交隐藏思维链、系统/开发者提示。摘要须标“摘要”，不伪装成逐字原文；删除秘密和不允许公开的身份信息。

| 失败ID/场景 | 原始观察及首个失败输入 | 影响范围 | 根因（确认/推测/未知） | 修正与实际结果 | 保留原件位置 | 重开/停止条件 |
|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |

区分工具缺失、验收没运行和功能失败。保留所有分母/拒绝/错误样例；“没有输出经过正式接受”不自动等于性能有效率为零。修正只改变新版本，不重签历史清单。

## 6. 准确版本复核与集成/发布

| 项目 | 记录 |
|---|---|
| 作者自检 | 版本、输入、实际命令、结果、未测试项 |
| 待复核 | 准确提交或内容清单哈希、范围、目标路径、复核入口 |
| 正式批准 | 复核人身份、原确认位置、日期、批准版本、仅归档/模块接入/系统接入范围 |
| 实际合入 | 执行人及授权、目标提交、实际文件/系统入口、新位置验证 |
| 发布 | 远端目标/准确提交、检查结果；不能沿用待审头冒充批准头 |
| 批次收尾 | 实际共享目录local/tracking/direct-remote SHA、领先/落后、本批路径；修改/暂存/未跟踪/忽略有用材料去向、未处理数 |
| 保留与清理 | 其他任务不动；已批准遗漏/待审分支/受控非公开原件分别定位，删除对象及恢复方式 |
| 最终状态 | 待复核/已批准未合入/已归档/活动入口已接入/系统已集成/已发布收尾待处理/收尾完成及证据 |

批准后改动准确内容须重审；没有复核人确认不得代签，作者不得自合。发布后核对并不授权未经允许的推送、删除或接板。阶段归档另记实际执行日期，复用批次记录，不因目录日期提前而假称验收已发生。

## 7. 比赛报告取材

简述“赛题要求/实际失败 → 方法决策 → 可见人机纠正 → 新旧版本对照/复测 → 外部项目复用 → 当前边界”。引用原始证据及版本，不把表格齐全、文章写成或代码退出0当作功能通过。
