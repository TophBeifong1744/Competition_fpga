# 给 C 的四麦转接板绘制要求

版本：adapter-requirements-0.1；日期：2026-09-10。

所属完整包：PKG-A-ACQ。A 拓芙负责技术方案和电气/结构判断，B BryanZheng802负责技术复核与正式合入；C hsc119按本要求绘图、核对实物并交付，不自行选型或审签。本文件为作者自检后待复核草案，允许准备图纸，不是已批准的生产图、接板单或采购授权。

## 1. 这块板要做什么

先按“四个现有IM73D122V01模块的汇线转接板”绘制：把一组电源、地和共享PDM时钟分配到四个模块，分别把四路DATA接回开发板。使用现有带排针模块，不重新设计裸MEMS芯片贴装板。

首版只服务V1四麦二维，不改成六麦采集板，不加电机、ADC、DAC、USB、蓝牙、AGC或PDM转PCM芯片。转接板只连接PDM电气信号；滤波/抽取在后续FPGA采集链完成，板上不需要24位并行音频总线。

本稿将“汇线转接板”与“固定声孔位置的阵列支架”分开：模块可通过固定短线连接转接板，转接板不必同时承担40 mm正方形支架。若A实际希望四模块直接插在同一块阵列PCB上，先回报这项需求，待A给出尺寸和固定图后再改布局，不把本稿默认为一体式阵列板。

## 2. 现在可以画什么，什么必须先停

| 工作 | C现在的动作 | 缺项时怎么办 |
|---|---|---|
| 逻辑原理图 | 按第3节画四个模块连接、共用电源/地/时钟及四路独立DATA；标DRAFT | 可先用逻辑连接器符号，不猜封装编号 |
| 模块与连接器机械记录 | 沿用已有照片；按第4节测量尺寸、标明观察面 | 不具备量具或针脚朝向不清，拍照回传A |
| PCB封装和板框 | A给定准确封装、板框/固定位置后照图放置 | 缺任一关键尺寸，不生成可生产封装或钻孔文件；仅做示意布局 |
| 电源/保护/缓冲/阻尼器件 | 使用A明确给出的电路、值、封装和装配状态 | A未给时列待定，不自行加稳压器、电平转换或时钟缓冲 |
| 生产/接板 | 本次不下单、不焊接、不插板、不上电 | 图纸检查通过也不自动放行这些操作 |

不必等所有缺项补齐才开始逻辑图；只暂停依赖缺项的封装、走线定版和生产步骤。

## 3. 电气连接：照此画候选逻辑图

采用现有[四麦接线候选](microphone-wiring-candidate.md)的首调路线：**1个共享CLOCK、4个独立DATA，每只模块LR分别接本模块GND。**这是待复核路线，不把候选J4引脚升级为正式连接。

```text
开发板端                          四个模块端
MIC_3V3  ───────────────────────→ 全部VDD
GND      ──────────────────────── 全部GND和各自LR
PDM_CLK  ───────────────────────→ 全部CLOCK
PDM_D0   ←─────────────────────── mic0 DATA
PDM_D1   ←─────────────────────── mic1 DATA
PDM_D2   ←─────────────────────── mic2 DATA
PDM_D3   ←─────────────────────── mic3 DATA
```

### 3.1 模块连接表

本表编号来自成员提供的六针模块接口图，不是裸芯片脚号，也不决定PCB插座焊盘从左到右的编号。原始图与资料见[归档证据](../../../../hardware/evidence/microphone-c-2026-09-09/README.md)。

| 模块图号 | 标注 | mic0～mic3的连接要求 |
|---|---|---|
| 1 | 3.3V | 全部接MIC_3V3，极性必须核对 |
| 2 | GND | 全部接GND |
| 3 | NC | 全部悬空；原理图明确NC，不接地、不当备用信号 |
| 4 | L/R | 各自接GND；A先确认模块没有相反硬连接，不让C短接未知电路 |
| 5 | CLOCK | 全部接同源PDM_CLK |
| 6 | DATA | 分别接PDM_D0/D1/D2/D3，四根之间不得相连 |

禁止把DATA两两并联来省线。本版独立DATA路线不要求双边沿共线接收；若后续要改变拓扑，须由A重新给图并升版。

### 3.2 开发板侧：暂存候选映射，不自行封装定版

| 网络 | 现有草案中的底板J4针号 | 本稿边界 |
|---|---:|---|
| PDM_CLK | 19 | 候选，不代表有效工程已配置 |
| PDM_D0 / D1 / D2 / D3 | 20 / 21 / 22 / 23 | 候选，须核对占用与方向 |
| MIC_3V3 | 38 | 实际供电能力、电压待A核实 |
| GND | 37、39 | 实物朝向及连接须核实 |
| +5V | 40 | 禁止连接模块或MIC_3V3，其他未用脚同样不随意连接 |

本表是底板J4编号，不是核心板X4编号，也不是FPGA封装脚号。若画直插J4转接板，必须由A确认插接面、1脚、奇偶排、上下镜像和机械干涉；不能看正面照片直接照搬到焊接面。

若采用单独线束连接器，A须明确针号、封装、公母和线束两端对应表，C不能自行选择顺序。3.3V/GND/CLOCK/四DATA共七类网络，不等于连接器只应有七针；地回流与防反插需要计入连接器方案。

### 3.3 电源和可调元件

- 首版采用单一、经A核实的板端供电路径；不并联外接3.3V，不引入USB供电，不把5V降压方案自行补进图中。
- A核实单模块及四模块总电流、已有模块去耦、板端余量和电源路径后给出器件表。C可预留电容位置，但不把待定电容值当已批准BOM。
- 时钟源端阻尼电阻位置由A结合真实时钟源、板端走线和线束决定。需要时在草图标出可选串联位置，阻值、封装和装配状态由A填；不要在每条支路随意串同一阻值，也不承诺某阻值必然消除振铃。
- 不默认需要电平转换或缓冲器。两端标称3.3V不等于最坏电平、驱动能力和时序裕量已通过，判断由A完成。
- 图纸注明“断电插拔”；模块断电时不得继续由信号脚灌电。具体上下电顺序由A后续给定。

## 4. 布局与机械要求

### 4.1 先填实测表

同一套图纸内保留`mechanical-check.md`，至少填写下列项目；未知写“未测”，不要估计：

| 项目 | 记录要求 |
|---|---|
| 模块身份 | mic0～mic3标签与正反面照片对应；不把库存报告数当逐件核验 |
| 模块板径/外形、厚度 | 单位mm，附量具读数或尺寸照片 |
| 排针 | 针距、两排间距、每排针数、针长、公母、插接面 |
| 声孔 | 所在面、相对安装基准的坐标；与排针/器件的高度关系 |
| 固定 | 安装孔位置/孔径、可夹持区域、插拔净空 |
| 开发板接口 | J4的1脚、针排方向、插接面和附近器件高度；A确认 |

### 4.2 阵列声孔与编号

V1四个声孔同高、同安装朝向、无遮挡。候选边长40 mm，保留35～50 mm调整能力；间距按声孔中心，不按模块外缘或转接板插座中心。汇线板与支架分离时，固定坐标由支架保证。

H1暂定坐标为x前、y左、z上，以下俯视图仅用于标签核对：

```text
                设备前方 +x
                     ↑
          mic2 ●────────● mic1
               │        │
               │ 中心O  │
               │        │
          mic3 ●────────● mic0
                左侧 +y ←
```

mic0=(-20,-20,0)、mic1=(20,-20,0)、mic2=(20,20,0)、mic3=(-20,20,0)，此处单位mm；对应[H1接口](../../../../docs/minimal-data-interface.md)中的米单位候选坐标。软件名义坐标不能当实物测量；装配不符时回报A，不自行换标签掩盖差异。

若要做一体式阵列PCB，A先确认模块外形和插接高度能否满足上述间距。若相撞、挡声孔或无法调整，停止该布局，回报尺寸；不自行放大阵列间距、折弯排针或改成六麦。

### 4.3 PCB布线要求

以下为布局要求，不是完成了信号完整性验证：

- 电源、地、CLOCK与四DATA分别命名，跨页标签一致。优先保持连续地参考；CLOCK/DATA不跨地缝，不绕板一圈或留长悬空支线。
- CLOCK分配紧凑，记录从输入连接器到四模块的各支路长度；线束也计入路径。不要为追求机械等长刻意蛇形增加路径，允许偏差由A结合接收窗口判断。
- CLOCK与DATA附近给出地回流连接；连接器、公母和线束方向可追溯。电源/地铜宽、过孔数量由A依据电流与板厂能力给值，不让C猜通用线宽。
- 给MIC_3V3、GND、CLOCK和四DATA设置可接近的测试点及地参考。避免大测试支线；示波器探头负载是后续测量条件，不认为加测试点后时序自动不变。
- 丝印清楚标注板名、版本、1脚、3V3、GND、CLK、D0～D3和模块朝向；显示“NC”与禁止接5V的提示。不只用线色区分。
- 声孔和插接/螺钉区域划禁布、禁器件或机械净空区。声孔尺寸与开窗由实际模块资料和A/B要求决定，不凭金属盖位置挖孔。
- 层数、板厚、铜厚、板框、安装孔、线宽/间距、孔径及公差由A填入制造参数表后再定版；C先用草图完成逻辑和空间核对，不自行选择板厂或下单。

## 5. C按顺序执行及停止条件

| 步骤 | 操作 | 预期交付/现象 | 停止条件 |
|---|---|---|---|
| 1 | 沿用已有模块图，建立尺寸与缺项表 | 图号、观察面、测量值能对应实物 | 未给测量方法/无量具的项目记缺失，只暂停该项 |
| 2 | 按第3节画逻辑原理图并输出PDF | 一条共用CLK，四条互不连接DATA；各LR接地、NC空接 | 实物标注与表不符，或LR存在未知连接，反馈A |
| 3 | 用A确认的封装作1:1纸面/尺寸核对，不插电 | 针距、两排间距、公母及插接面对应 | 无尺寸依据或上下镜像不清，不进入封装定版 |
| 4 | 在已给定板框与净空内做PCB草稿 | 能看清器件、走线、地参考、固定和声孔避让 | 关键制造参数/尺寸未给，先交示意布局，不猜值 |
| 5 | 运行所用EDA的ERC/DRC | 导出实际报告；无未解释错误 | 不靠忽略规则使计数归零；警告逐项交A判断 |
| 6 | 逐网对照连接表，整理同一版本文件 | 原理图、PCB、网表、BOM版本一致，缺项完整 | 任一文件不同步，不标“可打板” |

步骤1～6可在同一完整交付内反复修订，不为每次改线单独打包。ERC/DRC通过不证明封装、电平、同步或声学通过。C报告“完成了哪些步骤、还有什么未知”，不签“电气验收通过”。

## 6. 文件交付位置与清单

C的绘图成果放在现有完整包内：`task-packages/PKG-A-ACQ/outsourcing/C-PCB-001/submission/`。`C-PCB-001`只是本次绘图子项标识，不新增成员交接点或改变A/B责任。目录本次不代C填造设计成果。

- `README.md`：版本、EDA名称/版本、已完成步骤、缺项、作者；状态为草稿/待复核。
- `source/`：可编辑原理图、PCB及用到的自定义符号/封装，不能只交截图。
- `schematic.pdf`：全部原理图页，清楚标DRAFT及版本。
- `pcb-top.png`、`pcb-bottom.png`：标明观察面；尚未布局则在README注明未生成，不伪造图片。
- `mechanical-check.md`：第4.1节测量表及照片路径。
- `pin-map.csv`：开发板候选针号、转接板焊盘、网络、模块图号、方向、依据/待定状态；数针方向单独说明。
- `bom.csv`：位号、值、封装、数量、装配/不装配、待A决定项；不填写猜测器件型号。
- `erc-report.txt`、`drc-report.txt`：实际导出；软件不支持该扩展名可保留原格式并在README说明。
- `manifest.md`：文件路径、版本/哈希、目标路径、缺失或未生成项。
- `REVIEW.md`：保留A技术意见、B批准身份/版本哈希/范围/时间及合入记录；未批准保持空缺或待复核。

本要求文档自身属于A的待复核交付，目标活动路径为`hardware/microphone-adapter-board-requirements.md`；未获B批准不得覆盖总工程活动文件。C绘图由A检查后纳入完整工程包，B复核批准准确版本并负责合入。打板、采购、装配、试接与实测分别授权，不以文档通过替代。
