## 三次交接之外如何协作

H1 给共同软件接口，H2 给可解析诊断数据，H3 给可集成算法包。其余是各人任务包内部的迭代与必要沟通，不设逐实验、逐函数、逐截图审批。电气安全、实测真实性和 FPGA 资源时序证据仍不可跳过；M0～M6 用于验收记录，不作为所有开发活动的串行开工许可。

完整包集中到 task-packages/，复核人批准准确版本后负责合入，见[交付规则](task-package-handoff.md)。A 的个人 Git 分支安排见[Git 工作规则](git-workflow.md)。C 不替 A/B 技术审签；A/B 的包不可由作者自己批准。旧角色安排见[本次备份](../archive/2026-09-08-before-three-handoffs/README-ARCHIVE.md)。
