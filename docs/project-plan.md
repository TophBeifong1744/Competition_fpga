## 2. 项目简介

SoundSight 是一套基于 Zynq-7020 的四麦克风实时声源定位与定向拾音系统。系统使用严格同步的四路音频估计声源方向，再根据该方向进行 Delay-and-Sum 波束形成，输出增强后的目标方向音频，同时显示方向、置信度和运行状态。

核心链路为：

```text
四路同步麦克风
  -> 采集与预处理
  -> 分帧、FFT 与 GCC-PHAT
  -> TDOA 与亚采样估计
  -> DOA、置信度与错误拒绝
  -> Delay-and-Sum 波束形成
  -> 增强音频与状态显示
```

系统分工原则：

- PL 负责实时数据路径：采集、预处理、定位和波束形成；
- PS 负责参数配置、状态显示、日志、数据导出和非实时控制；
- MATLAB 负责黄金模型、测试向量、参数选择和结果判定，不能代替板上实现；
- 自动转台不是首版交付内容。只有固定阵列的定位和音频收益得到实测证明，并且存在摄像头或定向扬声器等明确朝向载荷时，才进入后续开发。

## 4. 10 月 1 日首版的定义

### 4.1 主目标：固定阵列核心闭环 V1

10 月 1 日的首版应在受控室内、单个主要声源、固定四麦阵列的条件下完成以下闭环：

1. Zynq 板接收四路共享采样时基的原始音频；
2. 四路数据能够连续导出，并带有通道顺序、采样编号或帧编号；
3. PL 完成核心实时声学数据路径，输出方向、置信度和异常状态；
4. 系统能够在手动方向和自动方向两种模式下驱动 Delay-and-Sum；
5. 能播放或保存固定单麦、手动真实方向、自动估计方向三种输出；
6. PS 或上位机能显示方向、置信度、模式和错误计数；
7. 项目可以从明确版本复现构建，并完成一套固定演示流程。

### 4.2 必须交付的证据包

即使整机联调遇到问题，以下内容仍必须在 10 月 1 日完整交付，不能只留下零散代码：

- 具体板卡、麦克风/ADC、时钟树、电平、引脚、阵列坐标和接线图；
- 静音、同源、已知角度、语音、目标加干扰的四通道原始录音；
- MATLAB 浮点模型及可复现命令；
- 定位的 P50、P95、有效输出比例、错误指向比例和失败样本；
- 同一四通道录音的 A/B/C 音频对照：A 为单麦，B 为手动真实方向，C 为自动方向；
- RTL 源码、自检 TB、测试向量及逐级比对结果；
- Vivado 资源、时序、吞吐和错误计数结果；
- 演示说明、已知限制和后续改进清单。

两项Skill及可见AI协作记录同为本队首版必交材料：各自的用法/失败条件/经验来源、可运行或可执行流程、真实案例与跨项目复用、前后效果对照、独立复核、许可及干净复现记录。具体判据见[Skill交付计划](skills-delivery-plan.md)。赛题明确通用PYNQ Skill单独加分，但不是固定分值承诺；无真实PYNQ证据时只能按离线范围验收并登记加分缺口。

### 4.3 首版暂不包含

- 自动声源跟踪转台；
- 语音识别、声纹识别和“自动知道用户想听谁”；
- 复杂多声源分离；
- MVDR 等自适应波束形成；
- 为了展示效果而临时加入、但无法复现的上位机替代算法；
- 没有实测条件说明的“5°精度”或“提升 4 dB”宣传。

首版的目标声源策略采用“手动选择允许扇区”和“锁定首次稳定方向”中的一种或组合，并明确重新捕获条件。

## 9. 仍不可跳过的等待

- 电平、供电和接线无依据：只暂停相关接板，不凭猜测接线或烧录含猜测 IO 的工程；可以建空工程、写无硬件依赖的逻辑与 TB。
- 没有真实录音：可以做离线/码型测试，不得宣称实际房间定位与降噪。
- 只有短诊断录音：可定位问题，不得宣称采集已通过长稳/同步/标定验收。
- 没有资源、时序和吞吐证据：可以研究 FPGA 原型，不得宣称实时运行。
- H3未准入的算法不能直接成为正式 FPGA 主链；接口/预算实质变化重新评审，普通离线参数实验不因此排队。
- 手动波束无改善先查几何/频带/标定/算法，不把它归咎于自动定位。

## 12. 10 月 1 日后的改进顺序

2026-09-07 补充决策及数量复评：三维方向纳入 V2，指方位角、俯仰角和三维单位向量，不是声源距离或离地高度。四麦二维V1先验收；六麦（水平方形四麦＋上下各一麦）为三维首选候选，非共面四麦为低成本备选，八麦暂缓。当前已形成六麦指南和首轮离线软件基线，继续保留可改装结构、扩展预留与接口兼容约束，保留原V1场景，验收日期按本轮更新为10月1日，不采购或更改四通道合同。

V1 封版后，按证据决定改进方向：

已授权预研边界：保持原麦克风选型，六麦声学评审与离线软件模拟成果保留；不做四麦模拟或四/六麦比较。本轮提速优先复用已有结果，新非必要预研后移，不解除V1保底与扩展采集准入。首轮结果见[六麦软件预评审](six-mic-acoustic-software-review.md)，是合成模型证据，不是首版或六麦实板通过。

1. 如果手动波束效果不足，优先调整阵列间距、频带、标定或波束算法；
2. 如果手动有效而自动无效，优先改进相关峰、置信度、DOA 和目标锁定；
3. 如果算法有效但 FPGA 资源或时序不足，优化复用、缓存、位宽和调度；
4. 如果实际房间仍频繁选错峰，再用同一录音比较 SRP-PHAT；
5. 关键可靠性问题处理后，进入三维方向升级：六麦首选/四麦备选的数量、几何、浮点与资源评审 → 扩展采集准入3D-GA → 实录标定 → 定点/PL/板测 → 三维波束对照；不必先完成四麦三维产品或转台；
6. C的双轴转台方案已在线下提前开展，收到后独立评审；采购、双轴动力学、实物及闭环集成不因方案到件自动获准，也不是V1通过条件；
7. 多声源、自适应波束和语音相关功能最后评估，不抢占核心可靠性工作。

三维声学后续分工：BryanZheng802 负责原理/模型/评价，拓芙负责工程/PL/兼容；C当前仅执行用户线下三维转台方案，不在此派采集整理任务。现有两个 Skill 任务只补通用流程适配指南，五个聊天任务均为GPT-6 Astra/high。阶段门与候选指标见[三维方向升级计划](three-dimensional-doa-plan.md)。原V2约3～5周估算基于四通道复用，已不直接适用于六麦扩展；在3D-G0后纳入3D-GA工作重新排期，不承诺新截止日期。
