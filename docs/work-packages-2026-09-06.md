# SoundSight 首轮工作包台账（2026-09-06）

## 1. 使用方法

本表是今晚的本地 Issue 底稿。负责人认领后，以一个工作包一个短分支推进；复核人依据“完成定义”给出通过或退回。未完成前不得用口头进度替代证据链接。

状态只使用：`未开始`、`进行中`、`待复核`、`已通过`、`阻塞`。
