## 重点裁决

1. **8前视/17历史成立于候选域。** n=t−8，延迟∈[−8,+8]，非零邻点只访问[t−16,t]；整数−8时不读零权重的t+1。每步加入当前点前保留16行，峰值17行。final仅记录外补零，不能据此批准实际外设输出时钟或服务上界。
2. **串行策略可继续研究，生产不接入。** 480淡变内至多两个beam端点及一个最新pending；完成当前淡变后再处理仍有效请求。STOP/SEARCH/TTL先清期望目标但不撤销当前淡变，最坏两次480才完全mono；STOP不是硬件紧急停机。已有源合同、HOLD不续TTL和fresh先于过期均与代码/参考相符。未来若要求硬截止，应另设计优先级并增量复核，不扩大本次批准。
3. **ROM归位与预算。** 当前离线准入文件为任务包 `dynamic-das-20260921/validation/portable01/delay/delay-rom-s16.npy`，包含容器头；净载荷552960B，mic0隐含0。下一步建议优先评估PS DDR驻留、按控制请求读取并下发延迟，而非默认放完整PL ROM；这是候选部署建议，尚无地址/所有权/带宽/实际装载批准。若选其他压缩/片上方案需单独验证。ROM域S16可用，通用+32768必须S17；不混用8B ROM域配置和通用打包/32位容器预算。
4. **ROM数值与范围证明分开。** Decimal Taylor/象限生成未调用旧sin/cos当期待值；60/90位一致和距半码裕量支持本次枚举，不称形式化超越函数证明。运行入口SHA/shape/整数角域严格；+180需上游规范化。
