# 三维声源方向的工程工作流与 Skill 对齐指南

日期：2026-09-07。状态：`3D-P4` 指南已同步六麦首轮软件预研结果与材料整理路径；不表示 V1、3D-G0、3D-GA、3D-G1、3D-G2 或 3D-G3 已通过。依据[三维方向总计划](three-dimensional-doa-plan.md)、[六麦软件评审报告](six-mic-acoustic-software-review.md)及用户补充，本轮仅六麦软件预研，不开展四麦模拟或四/六麦比较。

## 1. 定位与范围

本指南说明如何用现有 [`soundsight-engineering-workflow`](../skill/soundsight-engineering-workflow/SKILL.md) 承接三维方向升级，不创建三维专用 Skill，也不修改现有 Skill、RTL、Vivado 工程、接口合同或硬件结论。记录格式继续复用现有[工程记录模板](../skill/soundsight-engineering-workflow/references/record-templates.md)。

主线保持不变：V1 的目标交付日期为 2026-10-07，范围为四麦二维与 M0～M6 验收；日期是目标，不是已通过证明。本 3D-P4 任务只修订这份指南；用户已授权主流程开展六麦声学评审和离线软件模拟，属于可提前进行的 3D-G0 预研，不受本任务“仅指南”的范围限制。V2 输出是方位角、俯仰角和指向声源的单位向量，不输出距离、三维位置或离地高度；三维不是赛题强制项。

V2 本轮评审与模拟只研究水平正方形四麦加中心上、下各一麦的六麦结构。非共面四麦仅保留为未来重新决策的备选背景，八麦暂缓；不新增四麦模拟、四/六麦比较或六路抽四路任务，也不要求先完成四麦三维产品。本轮模拟范围明确为六麦，具体模块、尺寸及硬件实施仍需证据与阶段评审，不代表采购、接线或实现授权。

麦克风沿用用户原先选好的 IM73D122V01/PDM 路线，本轮不重新选型、不更换采集接口。具体模块型号/版本、实物一致性、声孔位置、电平、时钟负载和同步行为仍需相应资料与测量证据；用户选定路线不等于模块或采集链已验收。该路线仅为项目背景，不写入通用 Skill 的硬编码要求。

本指南只把项目专用的 `3D-PREP`、`3D-G0`、`3D-GA`、`3D-G1`～`3D-G3` 映射到通用阶段门。其他 FPGA/嵌入式项目仍使用通用 Skill 的 G0～G7；通道数、pair 集和维度作为项目记录，不把四麦、六麦或 SoundSight 阶段名硬编码进 Skill。

## 2. 独立核查结论

对[三维方向总计划](three-dimensional-doa-plan.md)中的几何路线进行独立检查后，可保留以下结论：

- 对 N 个有效麦克风，参考基线矩阵 `B` 有 N−1 行、3 列；全部无序 pair 数为 `N(N−1)/2`。理想到达时间差的线性独立自由度最多为 N−1：四麦是 6 pair、3 个自由度，六麦是 15 pair、5 个自由度。线性差分自由度不等于噪声统计独立性，共享通道误差使 pair 相关；15 pair 不能当作 15 个独立观测或精度保证。
- 四麦备选中，四个点非共面可使 `rank(B)=3`；失去任一整路后，剩余三麦最多提供两个独立时差，通常不能无额外先验保证无歧义全空间三维。该结论仅限四麦，不可沿用为六麦的单通道故障结论。
- 六麦候选的理想非退化结构中，失去上麦或下麦后仍有水平四点及一个离面点；失去任一水平麦后仍有三个不共线水平点和上下两点，故完整保留其余基线时仍可达到秩 3。这是几何推导；底部遮挡、噪声、失效识别、选 pair 与阈值均需另验。已知坏通道剔除后可解，不证明算法能自动找出坏通道。
- 每帧检查实际有效、加权且与当前 mask 对应的基线矩阵的数值秩和条件数；仅计有效通道或 pair 数不足以判断可观测性。六麦只保留水平四麦时仍有上下镜像问题；切成四路也不自动等于可用的非共面四麦备选。
- `rank(B)=3` 只证明理想几何可观，不证明抗噪、抗混响、安装公差、俯仰精度或板上实时性。条件数、坐标误差、固定通道延迟和声速误差仍会放大方向误差。
- 方位和俯仰只参数化单位方向。没有距离或近场联合估计时，不能从俯仰角推出声源位置或高度；测试中的距离和高度只是场景真值与适用条件。
- 原始最小二乘解的模长和几何残差属于有效性证据。不能把任意非零解归一化后直接称为合法三维方向。
- 正上方或正下方的方向向量可以有效，但方位角没有唯一值；接口和报告必须允许“向量有效、方位无效”。

进入对应验收前，主流程仍需冻结以下问题：

1. 六麦自身水平场景的验收门槛，以及未来实际修改/恢复 V1 时的回归标准；不以新增四麦模拟或四/六麦比较作为本轮依赖。
2. 有效基线矩阵的数值秩、条件数、原始解模长和残差阈值，以及通道失效时是否允许自动回退二维。
3. 3D-G0 候选指标、训练/调参集与独立验收集的划分；不能在看到最终结果后再放宽门槛。
4. “V1 可恢复交付物”的精确定义、保存位置和批准人；至少要能恢复源码/脚本、几何与标定版本、测试数据、工具版本和已验证构建物之间的对应关系。
5. 六麦自身的声学验收目标、可接受实现成本、所选 pair 集及失效覆盖；当前不以四麦对比结果作为准入依赖。
6. 3D-GA 的采集/合同评审负责人、实物扩展能力和验证条件，以及纳入扩展采集与联调后的工期。

| `3D-G1` 实录与标定 | G1 硬件事实、G2 真实录音离线基线、G5 采集证据 | 3D-GA 通过后，六通道实录与标定可复现，离线三维方向达到冻结门槛 | 同步未知的数据不得用于正式验收；板上采到录音不等于三维算法已在 PL 上运行 |

| `3D-G3` 三维波束 | G2 指标基线、G5 板测、G6 复现 | 同一实录的单麦/手动真值/自动三维方向对照完成 | 三维定位通过不自动证明音频改善 |

G6 可复现记录和 G7 失败/边界登记贯穿每个阶段。项目阶段通过只代表该行定义的范围，不改变通用 Skill 的证据分类。

正式准入顺序为 `V1 保底门 → 3D-G0 评审 → 3D-GA → 3D-G1 → 3D-G2 → 3D-G3`。主流程已授权的六麦 G0 声学评审和离线模拟可在 V1 完成前开展，结果按理论/合成/预算登记；这不自动解除 GA 对 V1 与 G0 通过的依赖。3D-GA 内先审查接口/约束，再单独实施六路采集并完成仿真、实现及实板验证；它不会因接口表已填写而整体通过。

旧“3～5周”估算基于四通道复用，不直接适用于六路扩展。在 3D-G0 后，将 3D-GA 的扩展采集、版本化合同、PS 联调及失败重测纳入重新估时；本指南不承诺 V2 新截止日期。

### 3.1 通道变更需要重新提交的证据

- 接口输入：沿用 IM73D122V01/PDM 路线，核验具体模块与实际板卡扩展引脚/电平、时钟负载与扇出、采集器件能力、供电、复位/启动顺序；当前仅列证据需求，不重新选型或填写猜测值。
- 版本化采集合同：同一采样时基、通道数与顺序、有效 mask、数据位宽/字节序、样本组与块长度、ID、丢失计数、DMA 打包、配置原子生效与旧客户端拒绝行为。
- 数值与实现预算：六路采集/抽取、每通道 FFT、所选 pair 的 PHAT/IFFT/峰值、求解、搬运、最坏停顿、缓存端口与余量。全 pair 假设下六麦为 6 FFT＋15 IFFT；次数不等于资源倍数，删 pair 后须重验秩、噪声与故障覆盖。
- 带宽预算：48 kHz、24 bit PCM 下六路净码率为 6.912 Mbit/s，32 bit 容器净带宽为 1.152 MB/s；须另加块头、对齐、协议与最坏服务间隔，PDM 原始位流另计。这些是按假设计算的预算，不能作为 DDR/DMA 实测结果。
- 实板采集证据：六通道的同源、重启/复位、固定差异标定、长录音解析、ID 连续性和一小时零丢样/乱序；采集主链和导出完整性分别检查。异常时保存原始输入及错误计数。
- 若沿用候选 `hop=512`、`fs=48 kHz`，每 hop 约 10.67 ms；该值是配置预算约束，实际周期、时序与长稳必须由对应实现和板测证明。

## 4. 二维 V1 基线保护

正式进入 V2 阶段评审与采集扩展前，由人类负责人确认一份可恢复的 V1 基线清单；已授权的 G0 离线预研可以先进行，不能改写 V1 结果。本任务只定义以下清单，不创建目录或改工程：

- 源码与构建脚本的版本、相关未提交状态及文件哈希；
- 完整 FPGA part、Vivado 2025.2 实际版本输出、接口/寄存器/数据格式版本；
- 二维阵列坐标、声孔位置、通道映射、固定延迟和增益标定版本；
- V1 评价数据及哈希、场景元数据、A/B/C 输出、指标脚本与门槛；
- 仿真、综合、实现、时序、资源和板测报告的独立证据 ID；
- 匹配的构建物、部署步骤和从零复现结果；
- 已知失败、未覆盖范围和可安全恢复的方法。

三维准备和后续试验必须遵守：

现行 V1 四麦二维文档仍服务于 2026-10-07 交付，不能因 V2 软件预研已有结果就列为废弃方案。历史快照归档用于追溯；现行 V1 与 V2 文档按各自范围继续有效。

1. 不覆盖 V1 数据、坐标、标定、构建物或结果；三维候选使用新的几何/标定/数据版本。
2. 夹具变化后的录音不能继续引用旧二维标定；旧录音也不能套用新三维几何。
3. 3D 试验失败时先恢复 V1 的物理布局和配置，再用原 V1 数据与场景复验；“切回 2D 模式”本身不是恢复证据。
4. 保留原 V1 构建及其已有水平验收记录，供未来修改或恢复 V1 时复核；本轮不新增四麦模拟、跨数量对比或六路抽四路。六麦自身的水平测试按其指标评价，四路历史录音不能补零伪装为六路实录。保护 V1 不构成主流程六麦离线预研的额外对比依赖。
5. 当前不新增接口字段。未来通道扩展及向量、俯仰或有效标志变化，须保持 V1 方位语义不变，并另做版本、长度和旧消费者拒绝不支持格式的测试。
6. 区分恢复已验收 V1 四麦二维与六麦运行时屏蔽通道：前者需恢复复验，后者须验证 mask 后可观测性与输出语义。若未来改选非共面四麦三维，须由主流程重新决定范围；它不是本轮回退实现或验收依赖。

## 5. 证据分级与声明规则

沿用[声学验证计划](acoustic-validation-plan.md)的 E0～E5，并映射到通用 Skill 的四类证据：

| 内容 | 记录类别 | 当前可支持的声明 | 不能支持 |
|---|---|---|---|
| 秩、可观测性、尺度与误差传播推导 | E0 理论 / model | 几何必要条件与候选数量级 | 实际精度、稳定性或覆盖范围 |
| P50/P95、有效率、错误率、上下误判等草案 | 拟议指标，不是验证证据 | 等待评审和冻结的验收候选 | “已达标”或事后调整 |
| 合成场景、噪声/公差扫描、平面负例 | E1 合成 / model | 算法符号、边界和敏感度 | 真实麦克风、夹具和房间表现 |
| 通道数、pair、周期、缓存与带宽估算 | 预算 / model | 在明确配置假设下的工作量与资源需求 | 实际 FPGA 资源、时序或 DMA 吞吐 |
| 六通道录音的离线处理 | E2 / model with recorded input | 与几何/标定/通道版本绑定的实录离线算法表现 | RTL 数值一致性、实时性或 PL 上板运行 |
| 位精确与 RTL 自检 | E3 / simulation | 定点与 RTL 在版本化向量上的一致性 | 资源、时序和板上声学表现 |
| Vivado 综合与实现 | E4 / synthesis and timing | 指定器件/约束下的资源和静态时序 | 持续板上运行或三维声学效果 |
| 实际采集、PL 输出和长稳记录 | E5 / board | 已声明硬件与场景下的板上结果 | 未测试房间、方向或失败模式 |

文档、指南、静态链接检查和 Skill 校验单独登记，不能代替 E0～E5。使用真实板卡录音作为离线输入时，同时保留“采集链板测证据”和“离线模型结果”两条记录，不能合并成“板上三维算法通过”。

| 证据或观察 | 当前可核实内容 | 登记与限制 |

| 六麦合成评估 | 9 场景各 300 帧，共 2700 帧；60 个方向，每场景每方向 5 个随机样本 | E1；独立样本评估，不是连续 2700 帧跟踪或真实录音 |
| 自检与复现 | 21 项自检通过；报告记载独立临时目录复跑的 15 个产物 SHA-256 全部一致 | 计算自检与复现证据；本任务未复跑，不能替代声学验收 |
| `band_noise0` | 带内约 0 dB：141/300 帧有效，即 47%；有效帧 P50/P95 为 4.82°/10.20° | 明显低于草案 90% 有效率目标；低条件误差不能掩盖被拒绝的 53% 帧 |
| `interferer0` | 等强竞争：78/300 帧有效，即 26%；有效帧 P50/P95 为 40.07°/75.31° | 错误指向占全部目标帧 17.33%、占有效帧 66.67%；当前目标选择与选峰存在失败 |

| 单通道剔除几何检查 | 六种已知剔除情形的秩检查通过 | 仅几何自检；自动坏通道识别、实际遮挡与剔除后声学精度尚未通过 |

模拟沿用 IM73D122V01/PDM 作为路线背景，但采用一致全向麦理想传递函数，未包含具体模块声孔/频响、PDM 抽取或实际板级采集。`noise0` 全频白噪声名义 0 dB 在处理频带内约为 8.03 dB，必须与真正带内约 0 dB 的 `band_noise0` 分开报告。

据此，3D-G0 只能登记“部分模型证据已形成、失败条件已发现”，不能整体 PASS。与草案门槛的差距作为预研失败观察保留；正式门槛尚待人工冻结，不能把草案追认为已完成的正式验收。GA/板测准入仍未通过。

## 6. 失败登记与回退规则

| 触发条件 | 阶段状态 | 处理与允许回退 | 禁止做法 |
|---|---|---|---|
| V1 M0～M6 未完成或不可恢复 | GA 准入 `BLOCKED` | 继续 V1；主流程已授权的 G0 离线预研可进行 | 用预研或三维演示替代二维验收 |
| 六麦声学结果或扩展预算未达到冻结标准 | 已测未达标为 `FAIL`，证据不足为 `BLOCKED` | 记录六麦缺口、调整获准的参数，必要时回报主流程重新决策 | 自动扩大为四麦模拟或跨数量对比 |
| 3D-GA 同步、复位、映射、长录音或一小时稳定性未过门 | 未运行为 `NOT_RUN`，受阻为 `BLOCKED`，实测未达标为 `FAIL` | 先修六路采集或暂停 V2，保留 V1 | 在同步未知的数据上验收三维算法 |
| 六路数据使用旧四路合同、系数或解码器 | `FAIL` | 拒绝不支持格式并保存版本冲突；修正后重跑受影响层 | 静默截断/重排，或把格式错误解释为声学误差 |
| 候选基线矩阵秩小于 3 或条件数不可接受 | `FAIL` | 在隔离夹具/模型中调整高度或布局，重跑 G0 | 仅靠单位向量归一化放行 |
| 通道或 pair 屏蔽后有效矩阵秩小于 3 | 当前帧三维无效 | 输出无效原因；只有二维回退合同已单独冻结和验证时才允许回退 | 继续输出看似稳定的三维角度 |
| 原始解模长、闭合误差或几何残差超门槛 | 当前帧三维无效 | 登记第一处失败和相关峰/TDOA，检查标定、选峰与多声源 | 用平滑掩盖不一致结果 |
| 接近正上/正下导致方位无定义 | 向量可有效、方位无效 | 保留单位向量与俯仰，单独标记方位有效性 | 把方位强制写成 `0` 并称为已测 |
| 非共面改装使 V1 水平指标超出冻结退化限值 | `FAIL` | 恢复 V1 物理/配置基线；重新评估候选 | 为三维结果牺牲 V1 而不登记 |
| 合成通过但实录未过门 | `FAIL` at 3D-G1 | 查几何、声孔、固定延迟、反射和选峰；必要时仅离线比较 SRP | 进入三维 RTL 或宣称模型已验证硬件 |
| RTL 通过但资源、时序或板测失败 | `FAIL` at 3D-G2 | 优化系数/位宽/调度，或保留 V1 | 把核心迁到 Python 后称为实时 PL |
| 手动真实三维方向波束没有改善 | `FAIL` at 3D-G3 | 先查阵列、标定、频带和波束方法 | 先归因于自动 DOA |
| 查看验收结果后修改门槛或数据集 | 旧结果失去可比性 | 记录变更理由，重新冻结并在独立数据上重跑 | 选择性保留最好结果 |

所有失败使用现有失败登记模板，至少记录证据 ID、影响范围、首次失败输入、尝试、停止原因和重新开放条件。回退到 V1 是受控恢复动作，不等于删除 3D 失败记录。

首轮应登记的实际软件失败观察至少包括 `band_noise0` 有效率 47%、`interferer0` 有效率 26% 且有效输出错误率 66.67%，以及音频示例 C 的 43.55% 有效率和静态指向限制。分别绑定场景名、配置、脚本/输入哈希及逐帧记录；根因尚未充分分离时标“待核实”。后续目标锁定、质量加权或拒绝策略的改进建议不写成已实现；关闭失败需给出新版同口径统计、独立评价和人工复核，不能只展示好听的 C 音频或较低 P50。

已知异常通道剔除、自动异常识别和物理遮挡分别登记；软件 mask 用例通过只证明该已知 mask 下的行为，不能证明自动识别或遮挡场景通过。六麦单通道剔除后即使仍满秩，若条件数或性能超限仍须拒绝或按已验收合同降级。

## 8. 人工复核要求

AI 可以生成候选、表格、脚本建议和初步检查，但不能批准阶段门。至少需要以下人工复核：

1. V1 负责人确认可恢复基线和三维工作不改变 2026-10-07 交付范围。
2. 硬件与算法成员共同测量声学中心坐标、通道编号、夹具公差和声孔朝向；不能仅用 CAD 名义尺寸。
3. 两人独立核对坐标系、TDOA 符号、`rank(B)`、条件数算法、单位和角度有效性。
4. 在验收录音前批准指标、水平非回退门槛、数据划分、无效分母和错误方向定义。
5. 每个门由指定复核人逐条检查证据 ID、原始记录、版本、命令和限制；指南完成、AI 回答或静态检查不得签成工程 PASS。
6. 任何自动二维回退都要人工批准输出语义、UI 标识、日志、保持时间和安全行为；未批准时三维无效只能明确拒绝。
7. 报告发布前由人类检查：三维是 V2 后续目标、没有距离/位置输出、拟议指标未写成实测、离线实录结果未写成 PL 板测。
8. G0 复核六麦的 pair 相关性、全通道与故障后的条件数/性能及代价、同组六路 A/B/C 结果；评审几何和指标并重估工期，不要求四麦对照，也不自动授权采购。
9. GA 由硬件、采集/RTL 和 PS 成员共同核对扩展事实、合同版本、旧客户端拒绝策略以及分层验证结果；一小时实测和长录音完整性由原始记录支持。
10. 材料包发布前人工复核 2700 帧与 21 自检的含义、复跑记录/哈希、band0 与全频噪声的区别、47%/26% 有效率及统计分母、静态 C 的限制；确认没有把自检或复现一致升级为声学门通过。现行分工与工作包的责任人、缺口及链接由主流程汇总复核。

## 10. 当前结论与停止条件

六麦软件首轮已有 2700 帧、21 项通过自检和报告记载的独立复跑一致证据；本任务仅核对并同步这些结果。带内 0 dB 与等强竞争场景仍有显著失败，3D-G0 未整体通过；模块、六路 PDM 采集、真实声学、定点/RTL、资源/时序、连续跟踪和板测仍缺对应证据。材料包及文档整理不能替代这些验收，也不自动证明通用 Skill 已经通过新的行为测试。

本任务仅授权单文件指南对齐；主流程已获授权的六麦 G0 声学评审与离线软件模拟可现在推进，不以 V1 未验收、指标未冻结或缺少四麦比较阻断预研。六麦几何、指标和预算在 G0 评审中决定；正式进入 GA 仍要求 V1 M0～M6 验收、可恢复基线及 G0 通过。GA 未通过时不开展正式 G1 验收。三维指标及独立数据划分须在正式评价录音前冻结。需要修改[三维方向总计划](three-dimensional-doa-plan.md)、接口合同、现有 Skill 或实现文件的问题，只回报主流程，不在本指南中越权处理。
