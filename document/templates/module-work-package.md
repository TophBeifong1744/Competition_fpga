# 子系统/模块任务模板

状态：活动模板，2026-10-13启用。仅填写本批适用项，普通小修继承父任务。

复制到现有Issue正文或引用已有合同，用于落实[项目开发流程](../project-development-flow.md)、[总体任务分配指导](../team-tasks.md)及[工作人员与AI协作指导](../team-workflow.md#human-ai-collaboration)确定的任务，不另建任务台账。先明确工程成果和依赖，再依据能力、工作量及权限配置人和AI；旧分工不默认继承，项目阶段与技术完成标准不随参与人数改变，已确认且未变化的内容直接引用。

下列完整结构用于新功能、架构调整或重要增量的适用内容。既定范围内的补丁/维护挂在原Issue/PR，继承父任务未变的目标、接口、预算、完成条件、责任和授权，只补“父任务引用＋准确候选/实际差异＋变更点及影响＋实际自测/未测”；不逐项重填，不按行数判风险。关键约定或风险变化补相应设计、检查和范围，必要独立判断与原操作权限保持。

## 设计与验证依据

- 权威接口/配置定义与适用版本，数据单位/数制/位宽/端序、帧/事务ID、握手/背压和配置生效边界：
- 主/生成时钟、跨域/各目的域复位释放、启动顺序、外部IO及必要时序约束：
- 实际IP参数/语义、位宽/缩放/舍入/饱和、实例份数和实现与模型对应关系；缓存映射/端口/所有权和DDR/DMA/PS需求：
- 仅适用时：实际器件/工具/IP版本对应的官方手册、Primitive/IP模板或正式生成配置；已核端口、参数和时钟/复位/使用条件，相关CDC信号语义、初始化/算子支持及剩余未知（沿原任务引用，不另交全量报告）：
- 工作量/共享单元调度、相关并行干扰、最坏处理周期/端到端延迟依据；资源及实时性待综合/实现/板测校正项：
- 超时、非法输入/配置、停止/重启、部分完成事务与陈旧数据/命令处理，适用执行器的停止恢复条件：

## 自测与变更检查

- 从目标及父接口独立列出的关键预期；正常、边界、连续/突发、背压和本批相关故障/恢复用例，输入和独立参考入口：
- 模型/RTL逐级比较规则（严格位一致与有依据的容差分开）、输出/状态/截止时间检查；参考来源及独立预期，同一AI编写实现/参考/检查器时的共同错误排查；首次使用或实质变化的关键检查器对代表性已知错误的检错证据，仍适用结果可复用：
- 本次变更影响的接口/精度/时序/资源/固件/观察点，必要回归与仍适用的复用结果：
- 实际自测、同候选综合/实现/时序及板测判据和原件；首次/本次构建与现场操作按现有授权：
- 未知项、确认人和确认节点（估算、实测、`UNKNOWN`、`NOT_RUN`、`UNVERIFIED`分开）；事实/推测/已确认根因、新执行/复用/跳过及相应证据入口：

## 接入与交付

- 上下游接合对象、就绪条件与负责人；状态/计数/ID及ILA加入/复用/不需要的依据，采样域/触发/观察窗口：
- 重要模块接入后全板资源核对节点，预计与实耗差异、余量及超限时的下一设计动作：
- 集成后组合功能/接口兼容、共享资源/并行干扰和受影响时钟/时序检查：
- 首次/本次上板触发条件、准确加载/应用/配置、实际输入/真值、样本数/时长、正确/错误及拒绝/超时/缺失口径、停止恢复和原件保存点：
- 探索板测仅适用时：临时Bypass/强制信号/刺激、任务分支或实验配置及实际差异、工作区/输出隔离与责任、被绕过范围及结论限制；拟合入时撤除或转为正式设计的内容、受影响检查和直接接收任务（详见[探索板测边界](../team-tasks.md#exploratory-board-tests)，普通有界上板不需另建临时工程）：
- 本批完整工程/依赖/匹配产物及打开入口、实际验证过的运行范围、未测及剩余问题；写入/板卡占用交接状态、进入下一阶段的条件和直接接收角色：

小修复用未变设计并合批，重要模块非作者判断结合接入测试；板上故障返修按现行例外跳过仿真、保留必要构建/时序/安全检查并优先回板。局部技术方法见[模块实施方法](../module-development-flow.md)，结果汇入项目阶段；整机验收仍以系统组合结果为准。
