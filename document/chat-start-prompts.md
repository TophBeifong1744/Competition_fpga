# 任务上下文接入

不规定每人几个聊天，不重建已存在会话。按实际任务配置实现/审查上下文；同checkout一写入方，重要非作者上下文不得完整继承作者对话，也不能审自己实质贡献。

通用接续：

> 使用本项目配置锁定的两层工作流。读取当前AGENTS、配置/锁和指定原Issue，核准确候选、实际输入、允许路径/动作、写入归属、目标/预算/完成条件及下一接收人。复用有效结果，不重扫全仓或新增逐项门禁。必要自测后直接交接，按实际权限处理构建/现场/Git。自动回报原协调一次；工具失败保留简短入口，不循环重发。状态/事实只由有权上下文更新原记录。

当前A侧已核有M、E1、E2、R1及材料/学习/研究上下文；工具notLoaded不等于删除或确认空闲。使用前核实际状态，不向不存在的旧X/R2推定投递成功。新任务不抢做在途正式工作；额外上下文仅在真实并行/独立判断有价值时使用。
