# 三维主用、二维兼容：分体采购与自主适配双轴云台方案 V2.2

状态：基于已提交 f90d608 的 B1/B2 限定修订，待独立复核。采购方式按用户要求改为机构、电机、驱动和反馈分开选择，由团队完成装配、接口适配和调试。保留双轴三维目标及前期四麦二维兼容，不修改六麦声源定位算法。

## 1. 当前方案的明确选择

**购买不含电机/控制器的双轴机械机构或模块，分别购买两台电机、两路驱动、传动件和输出轴编码器，由团队完成电机与云台的匹配。不是采购已整合好的电动云台，也不是只增加一台电机就认为双轴升级完成。**

主路线定为：水平Yaw＋俯仰Pitch的独立承重机构，外置两相步进电机，独立STEP/DIR驱动模块，减速传动，输出轴位置反馈；团队在PS/PL侧实现运动规划、位置修正、模式管理和安全逻辑。驱动模块负责相电流调节，不要求团队从零设计功率驱动器。

首轮传动匹配候选为Yaw 4:1、Pitch 6:1，优先同步带及成品同步轮。它们是待机械接口核对和测试的候选值，不是已选定商品的实测配置。采用42 mm机座电机作为尺寸候选起点，能否使用必须由运行扭矩、转速、安装空间及温升确认；不能只按“NEMA17”或保持扭矩下单。

可以购买成品轴承、支架、电机、驱动器、编码器和制动部件；团队自主工作集中于部件匹配、必要的连接件/安装板、整机控制与验证。现阶段尚未冻结具体SKU，也未生成加工图或实际板上程序。

## 2. 分开买什么，自己完成什么

| 部件 | 采购形式 | 团队负责的适配工作 |
|---|---|---|
| Yaw底座及Pitch托架 | 独立承重、可安装电机的机械机构/模块，不含整套电控 | 核对尺寸、可达角度、载荷、输出轴及安装空间 |
| 两台步进电机 | 分别选购；Yaw与Pitch不强制同型号 | 动态力矩/转速、电流、机座、轴径与随动质量匹配 |
| 两路驱动模块 | 分别购买公开资料的STEP/DIR驱动模块 | 设置电流/细分、驱动使能和故障回读，核对电平 |
| 减速传动 | 同步轮、同步带及张紧件等成品件 | 减速比、带宽、轮孔/夹紧、张紧、回差和共振调试 |
| 两路输出位置反馈 | 编码器及磁体/联接附件分别购买 | 输出轴同轴安装、零位/方向标定、角度读取和闭环修正 |
| 制动与传感器 | 分别选购输出制动件、零位、两轴限位、急停器件 | 保持/释放顺序、失电行为、停止距离、输入保护 |
| 电源与连接 | 成品电源、接线端子、线束及必要接口模块 | 双轴电流预算、回流布置、应力释放与抗干扰检查 |
| 控制软件/逻辑 | 使用现有开发平台 | 两轴脉冲、位置修正、参数辨识、故障优先级和模式切换 |

需要适配安装板或联轴附件时，优先用可核对尺寸的标准件，必要时制作简单连接件；不要求从原材料制造电机或整套云台。不能买只有标准舵机花键槽、没有适配空间的支架后，默认普通步进电机可直接装入。

电机轴不承担整机重量。Yaw承载上层Pitch机构、电机和载荷；Pitch通过自身轴承支承载荷。Pitch电机尽量固定在俯仰轴的静止支架上，避免不必要地计入Pitch随动质量，但其质量仍计入Yaw负载。

## 3. 硬件一次规划双轴，前期兼容二维

| 项目 | MODE_2D：前期四麦 | MODE_3D：后期六麦 |
|---|---|---|
| 机构与两台电机 | 两轴均安装、完成基本调试 | 同一套硬件 |
| Yaw | 跟随方位角 | 跟随方位角 |
| Pitch | 固定0°，可靠保持，不接受声学目标改变 | 跟随有效俯仰角 |
| 两轴反馈/故障 | 两轴均监控，Pitch固定也不能失联 | 两轴均监控并协调 |
| 升级方式 | 接收旧二维数据格式 | 停稳后切模式、校准、重新捕获目标 |

兼容性来自提前完成双轴空间和接口规划。分阶段调试可以先Yaw再Pitch，但不把日后能否安装第二轴留到最后。麦克风阵列和开发板建议固定，云台只转动摄像头或其他朝向载荷；因此从四麦换六麦不会自动增加云台随动质量。

两轴控制的是三维方向，不增加Roll轴，不包含平移或测距。初始工作范围Yaw ±160°、Pitch ±75°，不是完整球面覆盖；若要求Pitch ±90°，须在选机构时增加行程和停止余量，不能只改软件限位。

## 4. 系统输出要求与电机匹配

以下力矩指标均指减速后输出轴端。保留上一版本的系统预算，改变采购形式不会自动改变载荷物理需求。

| 指标 | Yaw | Pitch |
|---|---|---|
| 工作范围 | ±160° | ±75° |
| 机械总行程目标 | ≥350° | ≥180° |
| 限位/最终止挡候选 | ±165° / ±175° | ±80° / ±90° |
| 指令速度上限 | 60°/s，初调20°/s | 30°/s，初调10°/s |
| 指令加速度上限 | 90°/s² | 60°/s² |
| 停止结论的总等效惯量适用区间 | 0.01～0.04 kg·m² | 0.004～0.012 kg·m² |
| 连续可用输出力矩目标 | ≥1.0 N·m | ≥1.0 N·m，核实保持温升 |
| 短时可用输出力矩目标 | ≥1.5 N·m，须说明持续时间 | 同左 |
| 输出位置/重复定位目标 | 校准后≤1° | 校准后≤1° |
| 输出回差目标 | ≤0.3° | ≤0.3° |
| 输出编码器分辨率 | ≥12 bit，优先14 bit | 同左 |
| 对应10°停止预算的动态制动下界 | ≥0.60 N·m | ≥0.80 N·m |
| 故障到制动力矩建立的总延迟 | ≤30 ms | ≤30 ms |

这里“连续可用力矩”对步进电机指实际电源、电流、温升和运行速度下可持续提供的力矩包络，不是静态保持扭矩；短时目标也不能用无期限增大驱动电流获得。现有单轴电机参考的0.18 N·m运行包络不足以直接证明本版输出目标满足。

采用候选减速比N、暂按效率下界η=0.85筛选：`电机力矩≥输出力矩/(N·η)`，`电机rpm=输出角速度(°/s)×N/6`。

| 候选匹配 | Yaw 4:1 | Pitch 6:1 |
|---|---|---|
| 最高指令速度对应电机转速 | 40 rpm | 30 rpm |
| 1 N·m输出所需电机运行力矩 | ≥0.2942 N·m | ≥0.1961 N·m |
| 1.5 N·m输出所需电机短时力矩 | ≥0.4412 N·m | ≥0.2942 N·m |
| 1.8°、16细分的输出命令步长 | 0.028125° | 0.01875° |
| 最高指令速度下STEP频率 | 约2133 Hz | 1600 Hz |

效率0.85、减速比和1.8°/16细分是计算假设。实际电机转速可能受振荡影响高于指令值，需要实测余量；微步分辨率不等于角度精度。提高减速比会增加电机转速、折算惯量和结构尺寸，不能只看到力矩放大。

最大外部载荷为1 kg；Pitch托架附件预算0.2 kg，总随动质量≤1.2 kg，合成重心偏离Pitch轴≤20 mm。换电机、加编码器、制动盘或安装板后，要重新核算质量、惯量和重心，超出预算就调整结构或重算。

## 5. 分体适配必须核对的接口

| 接口 | 下单前确认 | 装配后证据 |
|---|---|---|
| 电机—支架 | 法兰孔距、定位凸台、轴伸长度、机身空间、紧固方式 | 无干涉，电机与轴系不强行错位安装 |
| 电机—主动轮 | 轴径、公差、D形/键/夹紧方式、轮孔 | 正反转不打滑，标记位置保持 |
| 传动—输出轴 | 减速比、中心距、轮宽、张紧行程、轴承能力 | 全行程不脱带、不干涉；记录回差 |
| 输出轴—编码器 | 同轴结构、磁体间距/方向或联轴方式、供电接口 | 多角度校准误差及回读方向一致 |
| 电机—驱动 | 两相绕组识别、额定相电流、驱动RMS/峰值定义、供电范围 | 设置与温升记录；不把相电流和电源电流混为一谈 |
| 驱动—PL | STEP/DIR/ENABLE时序、输入电平或光耦电流、故障输出类型 | 需要时用成品缓冲/电平转换模块并测波形 |
| 制动—机构 | 安装位置、动态制动力矩、保持力矩、释放/接合时间 | 在装配负载下测保持及停止距离 |

不要用减速比正向效率公式直接证明电机端抱闸能在输出端安全停止；反驱路径、间隙和弹性不同。优先以输出端制动性能验收，无法满足现有预算时降低速度或扩大停止余量。

最终电机、驱动和机构型号必须一起核对后冻结；本轮不虚构已经适配的BOM。可以先锁定尺寸图和接口，再买件，避免买齐后才发现轴径、孔距和力矩不匹配。

## 6. 团队控制与调试路线

控制链路：声源方位/俯仰 → PS模式管理与共同轨迹规划 → PL两路STEP/DIR或确定时序的底层执行 → 独立驱动 → 电机/传动 → 两轴输出编码器反馈。方案不依赖购买整套云台控制器。

团队负责共同动作编号、两轴启停协调、速度/加速度限制及位置修正；驱动模块负责电机相电流环。输出编码器同时用于监测传动实际角度，不能仅靠累计步数声称闭环定位。闭环增益、微步、电流和保持策略需要按实际机构调试。

- MODE_2D显式把Pitch目标设为0°；MODE_3D缺失任何角度都拒绝，不静默补0。
- 三维候选帧同时检查两角或方向向量稳定性，并保留整组新鲜度、有限数值及严格时间顺序检查。
- 模式切换先停稳两轴、确认保持和反馈，再重新收集可信目标。
- 任一有效急停、限位或超时优先于其他非法输入；一般无效声学输入在无已确认故障时触发受控减速。
- 两轴都完成命令准备后再同步启动；单轴准备失败不能让另一轴独自运动。
- Pitch固定时仍检查反馈、驱动及保持状态；只有确认可靠保持后才能降低电机力矩。

现有 `validate_control.py` 的556项检查只覆盖单目标门控及故障优先级；上述双轴执行器、输出位置环和协调逻辑尚未实现。此处明确团队要做的开发，不将方案文字写成已完成代码。

## 8. 实施顺序

1. 核对双轴机构尺寸、载荷空间和独立支承；用两轴总体空间约束选电机，不先随意购买整套电动云台。
2. 分别核对电机—传动—驱动—编码器兼容表，确认减速比和可安装性，再采购组件。
3. 先在无负载/低速下调电机与驱动，再接Yaw机构；验证方向、零位、编码器和限位。
4. 接Pitch机构并调整重心，验证保持与制动；不能以直接断电替代保持控制。
5. 在同一双轴硬件上运行二维模式，Pitch固定0°，接入四麦方位角。
6. 逐轴调位置修正与轨迹，再做双轴联合动作和故障联动；六麦就绪后启用三维模式。
7. 保留电机断电、保持、匀速、加减速、停止后五种声学对照，核对电机噪声对定位的影响。

## 10. B1：停止包络修订与保留反例

旧范围并未通过：总质量1.2 kg、偏心20 mm、J=0.003 kg·m²、初速35°/s、助推0.37544 N·m、制动0.8 N·m、延迟30 ms、储能0.01 J、误差1.5°时，需要 **10.983615° > 10°**。旧JSON与新结果中的历史27组及该失败点全部保留。

本次选择收窄适用范围，保持原速度、制动和延迟参数：Yaw总等效惯量 **[0.01,0.04]**，Pitch **[0.004,0.012] kg·m²**。Pitch新下界复算最坏 **9.488788°**，净余量约0.511212°；Yaw最坏 **8.612838°**。不再声称更轻或更小惯量总是更安全。几十克载荷只有在整套轴系总惯量也满足区间时才适用；不要求为此加配重，区间外设备不能沿用本结论，需另行确认参数，本轮不新增实施任务。

总惯量包括机构、负载、平行轴项和传动/电机折算项，采用刚性等效模型。适用条件：载荷0～1 kg，Pitch附件0.2 kg，偏心0～20 mm；故障开始时实际速度绝对值Yaw≤65、Pitch≤35°/s；整个停机期间助推力矩绝对上界分别0.14、0.37544 N·m。Pitch上界含1.2×9.81×0.02重力及原0.06/0.03/0.05 N·m预算项，后三项仍为未实测外力/模型余量假设，不凭空赋予物理测量来源。

从故障出现到有效制动力矩建立的总延迟≤30 ms（包含检测、逻辑、输出及机构接合）；这段时间保守按无有效制动且最大助推加速。随后输出端动态制动持续≥Yaw0.6/Pitch0.8 N·m，直到静止；附加可释放能量≤0.01 J、角度/安装误差总分配≤1.5°，故障开始处到最终止挡剩余空间≥10°。不能把30 ms仅作为继电器参数，不能以“断电”“停脉冲”代替这些力矩条件。

令A为助推、B为制動、t为总延迟、ω为初速，弧度行程为 `(B*ω*t + J*ω²/2 + B*A*t²/(2*J) + E)/(B-A)`，再加1.5°，要求B>A。固定其他参数时为常数＋正J项＋正1/J项，是凸函数，因此整个惯量区间最大值在两端。行程随非负初速、助推、延迟和能量增加而增加，随制动力矩增加而减少；同时检验两端和上述最坏边界即可覆盖连续区间，而非只靠离散抽样。脚本另列48项Pitch和3项Yaw停止组合便于复核。

该紧急停止余量不替代正常轨迹停车距离；正常停车须提前减速，不能等硬限位才按正常减速度停车。反馈未知时无法保证当前位置，应按最近一次可信状态与安全余量保守处理；若不能保证上述初速/空间/力矩/延迟边界，预算不提供安全证明。完整耦合、弹性动力学与实物验证仍未完成。

## 11. B2：Pitch防下落与制动交接原则

轴承承重但不保证角度。Pitch采用**独立于电机驱动力和主软件的失电施加、通电释放制动机制**，须具备动态停止能力及静态保持能力；普通仅允许静止接合的抱闸不能代替。电源/驱动故障时释放电路去能，制动自动施加，急停及关键故障不依赖主程序继续执行。此为既有制动部件的能力要求，不新增采购或控制实现任务。

静态输出保持目标≥0.8 N·m，覆盖最坏助推0.37544 N·m的2倍；动态输出制动下界另为0.8 N·m、总建立延迟≤30 ms，不能互相替代。制动接合状态须有可信确认；“已发接合命令”或单纯计时不等于力矩建立，状态信号也不能替代实施前的力矩能力验证。不能证实时保持未就绪并锁存，依然有健康电机时保持其承载，不关驱动。

| 状态/事件 | 承载与实际动作 | 释放、降流、禁用和恢复互锁 |
|---|---|---|
| 上电/复位 | 默认制动施加、运动禁止；机械制动承担Pitch保持，健康驱动仅可在互锁下建立保持力矩 | 复位不使能运动、不释放制动；先检查制动、反馈、电源、驱动和限位，禁止自动回到掉电前目标 |
| 准备/回零 | 制动保持期间启用电机保持力，确认反馈可信且电流/驱动就绪；力矩交接有重叠，再允许释放制动，确认释放后低速回零 | 回零只解决零位未知，不允许编码器健康未知；制动未确认释放不发运动脉冲，回零异常进入锁存停止 |
| 正常运动 | 制动释放、电机提供驱动和重力补偿/位置保持力，编码器监控实际输出 | 不允许运动中降到不足的保持电流；释放失败禁止用电机硬顶制动器 |
| 正常停车 | 健康反馈/驱动下提前受控减速，停稳后电机继续保持；施加制动并确认建立 | 确认制动承载后才允许降低保持电流或关闭驱动；若不确认则保留电机保持并锁存，禁止新动作 |
| 静止保持/二维Pitch=0 | 已确认制动承担角度保持；未交接时由健康电机持续保持，不能只设目标0 | 降流后仍保留故障监控；再次运动须先恢复并确认电机承载，再释放制动 |
| 反馈失联 | 不再声称可闭环减速；立即停止接收目标、撤销制动释放，独立动态制动吸收能量并保持，故障锁存；停止新增STEP | 健康驱动可保留既有电流作为辅助，但不依赖未知反馈更新目标；制动未证实建立时禁止主动撤去唯一健康承载来源 |
| 驱动故障 | 不依赖电机力矩；独立释放回路去能，制动在预算延迟内接合并承担动态停止/保持，双轴禁止新动作并锁存 | 电气保护可立即切除故障驱动，防下落必须由独立制动接管，不能等待失效驱动完成减速 |
| 急停 | 有效急停优先任何非法字段，硬件路径撤销制动释放，禁止脉冲及重启，动态制动停止后保持 | 急停导致驱动力消失时仍依靠独立失电制动；不能把关ENABLE本身当成制动；急停释放不清故障 |
| 整机掉电 | 弹簧/失电施加机构自动接合，不依赖处理器、电机或正常电源，接合前位移计入30 ms预算 | 不能假定掉电时仍有电机保持；禁止将软件BRAKE状态作为失电保证 |
| 制动未建立/反馈未知 | 有健康电机则维持其承载，撤销释放并锁存；故障驱动不能承担备用保持 | 禁止运动、自动回零、释放、降流和恢复旧目标；若电机与制动同时失效，本方案不证明防下落，保持停用，实施阶段须由独立机械支承后再处理 |
| 恢复供电/清故障 | 启动默认机械保持与运动禁止，故障需显式人工确认；确认制动承载、反馈/限位及驱动正常后才可重建使能条件 | 掉电可丢软件锁存位，但启动互锁必须等效保持禁止；清故障不自动释放或启动，重新确认零位并收集新目标 |

“停脉冲”只停止增加命令；“关闭驱动”移除电机力矩；“保持位置”需要电机或已确认的机械保持力；“动态制动”须消耗运动能量。动作交接按上表执行，不能由BRAKE名称推断硬件行为。该表是方案契约，尚非控制器实现或实物安全验收；单目标556项检查也没有覆盖这些执行机构互锁。
