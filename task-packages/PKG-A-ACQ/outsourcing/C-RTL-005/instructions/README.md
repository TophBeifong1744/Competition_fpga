# C-RTL-005：四通道窗口峰值监测RTL操作单

版本1.0，2026-09-11；本批只有这一项。A保留工程集成职责，C按本单写模块及自检TB，本聊天独立验收，B按原职责正式复核。004-R2已暂缓，不是开工前置。

## 1. 用途和第一步

直接创建 submission/rtl/pcm4_peak_meter.v 和 submission/tb/tb_pcm4_peak_meter.sv，从输入寄存器更新和小窗口测试开始，不先整理旧清单、搭PS或建立新BD。

目标：四路PCM每收到一段固定长度的有效样本，报告各路最大的绝对幅度，供后续界面或诊断读取。当前A采集链已有饱和标志和valid失配处理，本项补充窗口幅度观测，不替换这些逻辑。

这是旁路监测候选模块，不改变音频，不限流，不接AXI/DMA，不修改A的one/四路采集源码或B的算法。输出是原PCM整数码值，不是声压级、RMS、SNR、校准增益或“接线正常”的证明。最终是否接入由A决定，不作为取得首批录音的前置。

## 2. 唯一接口 c-rtl-005-if-1.0

工具Vivado/XSim 2025.2；目标平台沿用xc7z020clg400-2。核心纯Verilog .v，TB可SystemVerilog；所有信号处于同一clk域，无外部IP或001～004模块依赖。

模块名 pcm4_peak_meter，两个编译时integer参数：

- SAMPLE_WIDTH=24，合法2～32。
- WINDOW_SAMPLES=256，合法1～4096；是有效四路样本组数，不是时钟周期数。

| 端口 | 方向与类型 | 定义 |
| --- | --- | --- |
| clk | 输入，1位 | 唯一上升沿时钟 |
| rst_n | 输入，1位 | 同步低有效复位 |
| clear | 输入，1位 | 清除所有状态/输出，丢弃未完成窗口 |
| in_valid | 输入，1位 | 当前沿四路样本同时有效；没有ready |
| mic0_in～mic3_in | 输入，各signed [SAMPLE_WIDTH-1:0] | 四路二进制补码，不缩放 |
| peak0～peak3 | 输出，各unsigned [SAMPLE_WIDTH-1:0] | 最近完整窗口各路绝对值最大值 |
| window_valid | 输出，1位 | 当前沿产生新的完整窗口结果 |

同步优先级 rst_n=0 > clear=1 > 正常工作。复位或clear时内部累计、样本计数、四个peak及window_valid全部清0；同拍in_valid被忽略。rst_n在沿间变化不立即改变输出。

## 3. 每拍行为照此实现

1. 正常工作时，只有in_valid=1才接受一组数据；四路共用一个窗口计数器，不能各算各的样本编号。
2. 各通道计算本组样本的绝对值，并与本窗口已有最大值比较。比较按无符号幅度进行。
3. 接受第WINDOW_SAMPLES组的这个上升沿后，peak0～3同时更新为含“本组”在内的窗口最大值，window_valid=1；内部累计和计数清零，为下一组开始新窗口。
4. 非窗口结束沿，window_valid=0；peak保持上一个完整窗口的结果。in_valid=0期间不累计、不完成窗口；输入数值即使变化也忽略。
5. 窗口不重叠、无空拍要求、无额外流水延迟。WINDOW_SAMPLES=1时每个有效沿都出结果；连续有效时window_valid可连续为1，每个周期代表一个新结果，不强行插低电平。
6. 使用寄存器实现。计数器在WINDOW_SAMPLES=1时也必须有合法位宽，不能出现零位向量。

关键数值：负最小值-2^(W-1)的绝对值是无符号2^(W-1)，必须保留，不能变负、归零或钳成正最大值。比如W=24时0x800000→0x800000，0xffffff（-1）→1；W=32时0x80000000→0x80000000。其余样本正常取绝对值，不移位、不除法、不求平方、不做dB换算。

## 4. 按顺序写和测

1. 先用W=3、窗口3完成零值、正负值、窗口边界；确认第3个有效沿就发布并含末样本。
2. 加入复位/clear优先级、in_valid空隙和连续窗口。驱动放在下降沿，检查放在上升沿后稳定时刻，避免TB竞争。
3. TB用独立整数参考逐组累计最大值、按有效组数判断窗口。W=32参考使用至少64位有符号整数，先符号扩展再取绝对值，不能在32位有符号整数上对最小负数溢出。
4. 必测组合：W=3/N=3、W=2/N=1、W=16/N=16、默认W=24/N=256（默认实例不覆盖参数）、W=32/N=3；再测W=3/N=4096的一次完整窗口确认计数范围。不要求遍历所有参数组合。
5. 每个核心组合覆盖全零、四路不同值、正最大/负最小/-1、连续有效、有效间隙、连续两窗口；加入“最后一组才出现最大值”和“上一窗口峰值不能漏到下一窗口”。
6. 覆盖中途clear丢弃半窗、非零输出时clear、clear与有效末组同拍、复位同时clear/in_valid、沿间拉低复位但上升沿前输出保持、复位后重新累计。N=1用连续有效验证每拍独立出结果。4096组合只需完成边界计数的专门测试。
7. 用!==检查四个peak和window_valid，失败打印参数/用例/预期/实际并$fatal；设超时，全部检查后才打印ALL TESTS PASS。不需要额外随机框架、穷举32位输入或形式验证。
