### 为什么两个端点能覆盖连续区间

本轮独立展开能量式，角度先用弧度：

```text
F(J) = [B·ω·t + J·ω²/2 + B·A·t²/(2J) + E] / (B-A) + δ
F''(J) = B·A·t² / [(B-A)·J³] ≥ 0
```

在 J>0、B>A≥0、其余参数非负的条件下，F 对 J 为凸函数，闭区间最大值在端点。对速度、助推、延迟、能量和误差取上界，对制动取下界，方向正确。例如令制动建立时动能为 K，则固定其他参数时 `∂F/∂B=-(K+E)/(B-A)²≤0`。因此本结论依赖代数包络，不是用离散点数量代替证明。

| 轴 | J 适用区间 kg·m² | 下端点停车预算 | 上端点停车预算 | 区间最大值／扣除误差后的剩余空间 |
| --- | --- | --- | --- | --- |
| Yaw | [0.01, 0.04] | 6.561384° | 8.612838° | 8.612838°／1.387162° |
| Pitch | [0.004, 0.012] | 9.488788° | 6.650210° | 9.488788°／0.511212° |

这里的停车预算已含 0.01 J 和 1.5°分配，剩余空间不能再把同一 1.5°重复计作可用裕量。独立公式与作者公式在 4002 点的最大差约 3.55×10⁻¹⁵°。各 512 个参数内部样本也均不超过边界；这些样本只是交叉检查。

## 6. 方案仍值得改进的地方（用户追加要求）

以下是基于本次预算和实际缺口的工程判断，不要求 C 为本次限定批准全部完成，也不新增采购或开发动作。

### 实施前必须确认，优先处理

1. **先确定实际朝向载荷，再冻结机构。** 摄像头、指示器或其他载荷到底是哪一种，其安装包络、质量、重心和两轴总惯量目前都未冻结。先形成一张参数表，明确假设／资料／测量来源。若实际装置更轻而落在新惯量区间之外，应按真实参数重算，不应为了使模型通过随意加重；固定阵列和 Zynq 的路线保持即可。
2. **Pitch 0.511°余量不宜当作量产式安全裕量。** 在 J=0.004、其他假设全不变的解析示例中，总延迟增加到约 **31.3566 ms** 就用尽 10°，比预算30 ms只多约1.36 ms。这不是允许放宽30 ms，而是提示它对延迟误差敏感。未来依据实物优先降低重力助推／偏心、确认更快接合或保留更多停车空间，再重算；不能单看制动额定力矩合格。
3. **制动器应按接合时速度和能量核对，而不是只按35°/s。** 同一最坏刚性延迟模型下，Pitch 在 J=0.004、35°/s起步时，30 ms后可达到约 **196.33°/s**。这是条件性计算，不是实际转台测量；额外弹性能量的释放还需分析。必须确认真实制动器在相应速度、负载、热状态与重复工作条件下建立所需动态力矩，并区分静态保持额定值。当前“全过程≥0.8 N·m”已经是正确要求，实施时不能缩水成静态铭牌对照。
4. **把状态原则落实为一张可核查的接口／时序表。** 后续确定制动接合与释放确认信号、驱动就绪与故障、编码器新鲜度、回零超时、复位锁存和急停去能路径；给检测、逻辑、输出和机械各分配延迟并核对总和。正常停车另设随剩余距离约束的速度，不把10°硬限位余量混作正常轨迹余量。这里只记录实施前需求，不要求现在写控制器。

- 将区间、速度、力矩、延迟、储能及误差放入一份参数定义，由脚本生成摘要，减少文档、HTML、脚本和清单分别维护导致的漂移；仍保留固定参数的历史结果。
