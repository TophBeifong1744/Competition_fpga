## 3. 阻断方案批准的问题

### B1／高：最大惯量不是该停止模型的最坏点，已有预算工况超出 10°

证据：固定 f90d608 的 `size_dual_axis.py` 第 15～23、29～37 行，`motor_plan.md` 第 54、57、62～63、139～141 行，以及独立结果的 `pitch_failing_corners`。

作者在力矩预算扫描 Pitch 的 `J=0.003/0.006/0.012 kg·m²`，停止预算却只用 `J=0.012`，得到 6.650°并使 `budget_checks_pass=true`。把停止检查扩展至已列入的 `J=0.003`，其他条件不变：

| 参数 | 同一套作者假设 |
| --- | --- |
| 载荷／Pitch 随动总质量 | 1.0／1.2 kg |
| 重心偏心上界 | 20 mm |
| 总惯量 | 0.003 kg·m² |
| 最大重力矩 | 1.2×9.81×0.02 = 0.23544 N·m |
| 助推力矩预算 | 0.23544＋0.06＋0.03＋0.05 = 0.37544 N·m |
| 初速、制动、延迟 | 35°/s、0.8 N·m、30 ms |
| 附加能量、安装误差 | 0.01 J、1.5° |
| 刚性停车行程 | 8.134082° |
| 加入能量和误差后的总预算 | **10.983615°，超过 10°** |

独立能量展开式和分段数值积分得到相同结论。`J=0.003` 也不违反平行轴最低项 `m e²=0.00048 kg·m²`，不能仅以“质量大、惯量不可能小”排除。

令 `A` 为助推矩、`B` 为制动矩、`t` 为延迟、`ω` 为初速，作者模型可展开为：

```text
θ_total(rad) = [B·ω·t + J·ω²/2 + B·A·t²/(2J) + E] / (B-A)
              + radians(1.5°),  B>A
```

式中既有 `J` 项，又有 `1/J` 项。惯量减小会放大制动建立前的重力加速，因此“只用最大惯量”不是保守包络。当前表格只有惯量上界，也没有给停止结论设置有效下界。Yaw 所列 3 点通过不证明任意更小惯量均通过。

必要修复范围：在现有预算脚本内覆盖约定的惯量／载荷／偏心范围及相应停止工况，明确有效区间；修正停止参数或收窄适用包络，使正文、HTML、结果和判断一致。不能只更改结果哈希或隐藏该反例。不要求本轮建立完整双轴动力学仿真，也不指定必须采购哪款制动器。

这证明的是**当前保守预算不能支持所声明包络**，不是预测实际某台设备必然撞止挡；真实重心方向和外力尚未知，不能靠假定有利姿态抵消反例。

### B2／高：Pitch 防下落安全契约尚未闭合

证据：`motor_plan.md` 第 24、38～39、92、106～109、121、132 行。新版提到了保持、失电行为和后续验证，也提醒不能直接断电替代保持，但没有明确以下运行条件下的实际安全动作。

- 上电／复位／回零前，Pitch 靠什么承重；何种条件允许释放制动。旧单轴 INIT 的“驱动禁用”不能不加约束地移用到有重力的俯仰轴。
- 正常停车、保持、驱动故障、编码器失联、急停、整机失电时，电机保持力、独立制动与禁用驱动的先后关系；对无法受控减速的故障，如何在软件或驱动失效时仍约束下落。
- 制动未建立／释放失败／反馈未知时禁止什么动作，恢复电源后如何锁存并禁止自动释放或重启。这里只要求状态／互锁原则，不要求现在完成控制器代码。

“停 STEP”仅停止增加命令；“关 ENABLE”可能移除电机保持力；“保持”需要持续的力矩来源；“动态制动”还必须消耗运动能量。四者不能用一个 BRAKE 字符串代替。独立轴承能承重，但本身不提供俯仰角保持保证。

以作者最坏重力矩 0.23544 N·m、J=0.003 为例，静止时若驱动和制动均无有效力矩，仅重力在 30 ms 内可产生约 2.023°位移。这是局部理想反例，不是实物下落测试；它说明“Pitch 目标=0”不足以证明二维模式可靠保持。

旧 `single_axis_reference.md` 第 7 节已有独立失电制动原则，不能说整个交付毫无安全考虑；但新版没有把该原则明确迁移到 Pitch 的保持、回零及两轴故障联动。必要修复仅限补清该安全状态表与失电安全机制要求，将动态制动额定值、静态保持能力、总响应延迟分开，不必先冻结 SKU 或完成实测才能重审。实际机构验证仍放在实施阶段。

## 4. 已成立的部分与实施前必须确认项

### 已成立但不单独发布为双轴批准的部分

1. “二维只动 Yaw，Pitch 保持 0°；三维接收完整两角并协调”在用途上自洽。两轴硬件只是把朝向载荷指向空间方向，不产生三维 DOA，不增加 Roll、测距或平移。V1 无需等待该机构完成。
2. 阵列和开发板固定、只转动摄像头或其他朝向载荷，可避免把六麦和 Zynq 自动算入随动质量。本文只确认该假设，未替用户确定实际载荷。
3. 电机轴不直接承担整机重量，Yaw 承担上层 Pitch 机构／电机／载荷，Pitch 电机尽量放在不随 Pitch 转动的支架上，承重划分合理。尚无尺寸图，不能确认承载强度或无干涉。
4. 最大力矩算术正确：Pitch `J·π/3+mge+0.14=0.388006 N·m`，乘 2 为 0.776013；Yaw `J·π/2+0.14=0.202832`，乘 2 为 0.405664。每轴 1 N·m 可作为这些假设下的初筛目标，不是已证明的商品能力；1.5 N·m 短时值只是候选余量，未给出经验证的持续时间或双轴耦合工况。
5. 按效率 0.85，4:1／6:1 的运行力矩换算、40／30 rpm、微步和 STEP 频率正确。Yaw 连续电机力矩约 0.29412 N·m，Pitch 约 0.19608；短时约 0.44118／0.29412。提高传动比还会提高电机转速、反射惯量和尺寸，不能当作无代价增益。
6. 原故障优先级没有回退。556 原断言及本轮 24 组独立组合确认：有效急停／限位／反馈超时／心跳超时优先于非法声学输入，并锁存。它们未覆盖双轴联动和真实制动执行。

### 时间戳、坐标与声学边界

新版主要采用固定阵列，历史单轴材料已有音频帧中心时刻的姿态原则，但尚无双轴接口契约。作为实施前确认项处理，不要求本轮实现接口：

- 固定阵列：保留方向、置信度、音频帧中心时间和坐标系标识；由固定的阵列到世界／云台基座标定关系转换，不给阵列 DOA 错加当前转台姿态。
- 运动阵列：必须使用同一时基下该音频帧中心时刻的两轴姿态，明确坐标系、轴正方向、旋转顺序和外参；双轴不能沿用“分别加两个角度”的单轴简式。姿态缺失或过期不得生成可信目标。
- 即使帧中心姿态准确，阵列在一个音频帧内明显转动仍可能破坏静止阵列假设；未证明运动声学性能前保留停稳后重新捕获。固定阵列也要防电机噪声、振动和电源干扰，不因机械固定就省略对照录音。
- 目标丢失可按原门控清空旧票、健康状态受控减速、停稳后收集新帧；安全故障仍必须最高优先。3D 缺 Pitch 不补零，模式切换停稳后重新获取，这两条新版已写明。
