# one-test-source-v1 格式与接口合同

这是用于 PL/DMA 通路学习的合成测试格式，不是麦克风录音，也不是仓库 H1 离线 CSV 合同。H1 的 uint64 编号和 signed24/int32 通道格式与这里不同，后续需要明确转换，不能直接混用。

## 端口

| 端口 | 方向 | 约定 |
| --- | --- | --- |
| aclk | 输入 | 所有传输在上升沿判定 |
| aresetn | 输入 | 低有效异步复位，外部同步释放 |
| start | 输入 | 同时钟域单周期脉冲；仅空闲接受，忙碌时忽略 |
| m_axis_tready | 输入 | 下游当前能接收 |
| m_axis_tvalid | 输出 | 当前有有效拍，不依赖 ready 才拉高 |
| m_axis_tdata[31:0] | 输出 | 当前拍内容 |
| m_axis_tkeep[3:0] | 输出 | 恒为 1111，每拍全部四字节有效 |
| m_axis_tlast | 输出 | 每包最后一拍为 1，背压时保持 |
| busy | 输出 | 正在发送 |
| done | 输出 | 最后一包最后一拍握手后单周期为 1 |

只有 valid && ready 才发生传输。valid && !ready 时，valid/data/keep/last 和位置状态保持。复位可中止传输，是保持规则的例外；中止不产生 done，接收端必须丢弃/标记半包并重新准备，不能把它记为成功。

每次接受 start，采样编号和包位置归零；连续多次运行需要上层记录运行编号。start 保持高电平可能在返回空闲后再次启动，因此要求单周期脉冲。不提供 CDC、按键消抖、麦克风固定采样节拍或溢出队列。

## 一组采样与一包

一组采样是同一 sample_id 下的 ch0、ch1、ch2、ch3，不是某一个通道。每组需要三拍：

| 组内拍 | data[31:16] | data[15:0] | TLAST |
| --- | --- | --- | --- |
| 0 | sample_id[31:16] | sample_id[15:0] | 0 |
| 1 | ch1 | ch0 | 0 |
| 2 | ch3 | ch2 | 仅包内最后一组为 1 |

每组 12 字节，每包 12 × SAMPLES_PER_PACKET 字节；一次运行 PACKET_COUNT 包。参数均须至少为 1，默认均为 2，默认包长 24 字节。

面向后续 32 位、字节通道顺序不变的 DMA 小端内存解析，组内字节偏移为：0..3 uint32 sample_id，4..5 int16 ch0，6..7 int16 ch1，8..9 int16 ch2，10..11 int16 ch3，低字节在前。实际 DMA 配置和内存结果仍须板测确认。TLAST 是边带，不额外占用 data 字节。

拍位置每次握手推进；sample_id 仅第三拍握手后加一，并跨包连续；包位置仅 TLAST 握手后推进。sample_id 为源端生成的 32 位无符号编号，模 2^32 回绕；没有物理采样时钟含义，背压会延缓下一组生成。

## 四通道码型

对编号 n、通道 c（0..3）：

- 相位 p = (n + c) mod 4。
- 幅值 m = 1 + 256c + floor((n mod 65536) / 4)。
- p 为 0、1、2、3 时，输出分别为 0、+m、-m、-32768+c。

通道为 signed16 补码；m 最大 17152，不会有有符号溢出。每组四个值可区分；每连续四组，每通道都覆盖正数、负数和零。码型每 65536 组重复，但完整采样编号继续递增。

| sample_id | ch0 | ch1 | ch2 | ch3 |
| --- | ---: | ---: | ---: | ---: |
| 0 | 0 | 257 | -513 | -32765 |
| 1 | 1 | -257 | -32766 | 0 |
| 2 | -1 | -32767 | 0 | 769 |
| 3 | -32768 | 0 | 513 | -769 |

注意：一次运行少于四组时，不保证每个通道都出现全部符号类别；默认两包、每包两组正好覆盖。
