新模块没有实例化进原设计顶层；本次没有 DMA、BD 连线或 PS 程序变更。比赛仓库未修改，未提交 Git。one.before.xpr 是工程注册前备份，不应在 Vivado 有未保存修改时直接覆盖恢复。

- 首次工程仿真仅运行默认 1000 ns，不能验收；最终脚本已显式 run all，并检查最终通过标记，完整重跑通过。

- 工具还输出安装目录内部分无关 board part 警告；最终工程仿真和指定器件模块级综合正常完成。
- 工具自动保留的 backup 日志包含早期尝试，不作为最终通过证据；以本表列出的最终日志为准。
- 未进行布局布线、约束时序收敛、DMA 收数或板测。done 仅证明流接口接收完，不证明 DDR 写入完成。
