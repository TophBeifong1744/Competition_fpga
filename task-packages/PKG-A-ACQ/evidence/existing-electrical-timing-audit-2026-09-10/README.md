## 需要纠正的时序余量理解

不能直接把半个 PDM 周期减去麦克风延迟，当成当前 RTL 的最终余量。

- 系统周期 T=1/61.44 MHz≈16.276 ns。
- `phase==19` 时产生 CLOCK 下降沿；`phase==9` 时滤波器使用当时的旧 `pdm_sync`。
- 两级寄存器的非阻塞更新关系使该值对应 `phase==7` 对外部引脚的采样。因此有效采样发生在下降沿逻辑发起后约 8T=130.208 ns，而不是 10T=162.760 ns。
- 数据手册 tDV 最大 100 ns；仅作名义预算时，剩余约 30.208 ns，不是 62.760 ns。
- 30.208 ns 仍须容纳 FPGA 时钟输出、板线和线缆往返、数据输入、建立时间与时钟偏差等影响；不能写作最终正裕量。保持时间也须按正确边沿独立检查。

数据手册 tDV 条目的负载条件为 Cload=100 pF、Rload=100 kΩ；其电气特性章节默认条件为 VDD=1.8 V、25°C 等。不得不加说明地把该数字当作任意模块、3.3 V、任意线缆负载下已经验证的系统保证值。IO 报告记录时钟输出为 12 mA、SLOW；这不是违规的直接证据，也不能证明麦克风处的边沿合格。

## 最小剩余工作：先资料，后必要的测量

1. **DC 文档已补齐，兼容性尚未闭合。** 麦克风输入要求 VIH≥0.65VDD、VIL≤0.35VDD，输出规格为 VOH≥0.7VDD、VOL≤0.3VDD。DS187 PL LVCMOS33 输入门限为 VIH≥2.0 V、VIL≤0.8 V；输出 VOH≥VCCO-0.4 V、VOL≤0.4 V，需满足相应负载/驱动条件。名义 3.3 V 下 CLOCK 高/低裕量各 +0.755 V，DATA 高 +0.31 V、低 -0.19 V；麦克风电气特性的测试条件适用性仍须核实。此表是纸面边界比较，不是实物电平测量。不能再把该项写为“缺少 DS187”，也不能写成“已通过”。模块电路和实际负载须确认，处理路径见 CLOSURE.md。
2. **补外部时序模型。** 以此快照的 phase7 有效采样点建立正确的相关时钟/外部延迟约束，纳入器件延迟、负载及线长边界，检查最大和最小路径。此项是后续工程实现任务，本次没有擅自修改约束，也没有执行新的实现。不能靠 false path 隐藏问题。
3. **只补真实欠缺的现场证据。** 优先复用可辨识的接线、模块和板卡照片。若无法从资料确认实际供电/装配，测安全可达处的 VDD/VCCO；若无法从模型约束实际负载、时钟边沿和 DATA 有效窗口，针对麦克风处 CLOCK/DATA 测量，而不是无差别重测全部信号。3.072 MHz 下手册要求占空比 48–52%，上升/下降时间 ≤13 ns（10%–90%）。不得为测量去试探不明测试点或 BGA 焊球。
4. **不自动重录。** 已有短歌曲/静音数据继续作为诊断数据使用。仅在改变采样边沿、时钟、接线或其他影响数据链路的配置，或发现异常时，重新采集相关短样本；四路正式验收另需自己的同步、通道和稳定性证据。
