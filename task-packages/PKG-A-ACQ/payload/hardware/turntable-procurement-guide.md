## 2. 当前推荐方案：买什么类型，为什么

**优先找一套水平单轴成品转台，包含独立承重机构、电机、驱动/控制器及输出端位置反馈。** 尽量购买厂家已配好的整套，不要求 C 自制轴承座、机械臂或驱动 PCB。

默认让四麦阵列和 Zynq 开发板固定，只转动确实需要朝向声源的载荷，例如未来确定的摄像头；摄像头只是例子，目前没有指定型号或新增采购。这样可以减少转动惯量、线缆拉扯和振动耦合，也能简化方向坐标转换。固定安装仍不能消除电机空气声和共底座振动，后续要实测。

```text
固定四麦阵列 → 声源方向计算 → 可信目标筛选与运动规划 → 驱动/运动控制器 → 转动载荷
                                      ↑                         │
                                      └── 实际输出角、限位、故障 ──┘
```

既有模型基线是“4∶1 减速步进电机 + 输出轴编码器”。先按这种成品找；若现货是其他减速比、伺服或直驱一体转台，可以作为备选交给 A，但不得直接套用原仿真成绩。

当前不需要机械臂、俯仰第二轴或无限连续旋转，也不预购滑环。普通仅能连续转动的商品展示台、无法回读真实角度的简单舵机，不是当前完整方案。

## 3. C 先用这张表筛选

“待确认”可以保留在候选表中，不必为询价阶段做额外研究；但资料不足不能写“通过”，明确不符合也不能靠宣传词补齐。

| 指标 | 最低要求或拒绝条件 | 推荐目标及理由 | 找谁要什么证据 |
| --- | --- | --- | --- |
| 产品形态 | 水平单轴、可固定底座、独立承重；不接受把电机轴当完整承重结构 | 厂家配好的转台、驱动和反馈，减少机械装配与接口工作 | 完整型号、实物图、装配图、包含/不包含清单 |
| 载荷 | 按几十克至 1 kg 载荷范围询价；额定工作承重须覆盖载荷及厂家要求计入的附件 | 尽量靠旋转轴安装；说明最大偏心距离及允许倾覆力矩 | 工作姿态、动态载荷条件、允许偏心；只有“承重 1 kg”不足以定型 |
| 可用转角 | 候选至少 270°；小于此范围不作为当前主选 | 基线软件工作范围 ±160°，共 320°，并另留限位和停车空间 | 实际可用行程、限位/止挡位置、线缆约束；270°不能冒充320°方案 |
| 可控动作 | 能指定目标角、方向和速度，能停止；仅匀速自转不合格 | 低速起调 20°/s，目标支持最高 60°/s 指令及平滑启停 | 在目标载荷下的速度范围、加减速配置、定位演示或测试条件 |
| 最终定位 | 整机校准后到位误差目标 ≤1°；仅写微步数或编码器位数不算证据 | 要双向到位资料，并说明回差；此指标不是运动中一直 ≤1° | 定位误差定义、负载、测量方法；没有实测资料则标待验证 |
| 实际角度反馈 | 必须能获取真实输出台面/输出轴角度；目标角、累计步数不算实测 | 输出轴绝对编码器优先；电机端编码器不能单独覆盖传动回差 | 传感器安装位置、分辨率、误差、更新周期、读回报文样例 |
| 控制协议 | 有可获得的命令、反馈和故障说明，能脱离封闭手机 App 控制 | 成品运动控制器负责底层定时，Zynq 发目标；或 STEP/DIR/ENABLE 加独立反馈链路 | 接口手册、引脚表、命令/状态示例、上电和断线行为 |
| 安全停止 | 有限位与独立于普通目标消息的停止通道；能说明通信异常和失电后的行为 | 急停后保持故障，不自动恢复运动；有条件对应负载的停车距离证据 | 急停接线、反馈丢失/断线策略、失电制动方式、恢复条件 |
| 电气兼容 | 电机独立供电；所有控制/反馈端的电平、电流和隔离方式明确 | 使用配套电源和成熟接口适配；优先故障可诊断、接插件不易插反的方案 | 电源额定/峰值需求、输入输出规格、接线图；“可接单片机”不等于3.3 V直连 |
| 噪声与振动 | “静音”宣传不视为声学验收 | 低振动、线缆与固定阵列分开布置，后续能比较各运动状态录音 | 原厂测试条件或样机演示；无统一条件的分贝数字不横向排名 |
| 可采购性 | 型号、配置、交期及整套总价明确；资料与交付实物须对应 | 先一套样机；优先线束齐全、说明完整、可获得售后与易损件 | 分项报价、是否含税运、是否另需控制器/反馈/制动器、保修与退换条款 |

这里的“≤1°”是项目待实测的整机目标，**不能拿来直接宣称整机声源指向误差≤1°**；还要叠加 DOA 误差和阵列—转台零位标定误差。

## 4. 要沿用现有仿真，还需核对哪些条件

本节供 A 做技术适配，C 负责索取现成资料和填写缺项，不要求 C 测量刚度、建立新模型或设计制动器。满足单项数值也不等于整个商品已通过验证。

| 模型条件 | 既有数值 | 采购时如何使用 |
| --- | --- | --- |
| 输出负载惯量 | 扫描 0.00075～0.02 kg·m²，含随动台面及附件 | C 交尺寸、质量、重心偏距；A 算惯量。超过上界或低于已扫范围均需重新核对，不能只按公斤数判断 |
| 减速比与效率 | 4∶1、效率按 0.9 假设 | 优先对应基线；其他架构作为备选，不强制为了“4∶1”购买难配的零件 |
| 电机运行扭矩 | 电机端 ≤40 rpm 时有效运行扭矩包络 ≥0.18 N·m | 索取对应电压、电流、温升和驱动条件的速度—扭矩资料；保持扭矩不是运行扭矩保证 |
| 输出传动总间隙 | ≤0.3° | 要输出侧回差资料；只给电机步距不能替代。更大回差不能继承本次仿真结论 |
| 有效扭转刚度 | 8～40 N·m/rad，属于未测假设 | 通常商家不直接提供；记录未知，A 后续按结构/测试判断，不把它作为 C 找货时的硬性资料门槛 |
| 反馈 | 14 bit 基线；模型覆盖反馈延迟 2/5/10 ms | 询问读数年龄、更新周期和通信延迟，不只问波特率；模型兼容目标总反馈延迟 ≤10 ms |
| 正常停车 | 65°/s 初速、净减速90°/s²、检测延迟10 ms时，建议约27°余量 | 须提前减速或规划起止速度为零的完整轨迹；不能把正常停车空间误写为10° |
| 急停/失电停车 | 采用10°余量时，输出等效动态制动扭矩≥0.40 N·m，完整动作延迟≤30 ms | 仅对应研究中的总惯量0.0201064 kg·m²、初速65°/s、助推力矩0.12 N·m等边界及附加预算；更换参数须重算 |

60°/s 是指令上限；原仿真实际峰值约63.70°/s，所以不能要求商家仅证明60°/s工况就宣布停止边界覆盖。无动态制动或没有等效失电停车证据时，10°停止结论不适用；可交 A 评估降速、扩大行程余量或其他保护方案，不由 C 自行做高速断电试验。

14 bit 的每圈量化间隔约0.022°，不是0.022°整机精度。AS5048A 官方资料确认其为14 bit绝对角度传感器，并给出SPI读数接口；它在原方案中只是功能参考，**不指定必须买这个芯片或某块小板**。[AS5048A 官方产品资料](https://www.infineon.com/part/AS5048A)

TMC2209 官方资料提供STEP/DIR、微步和UART配置能力；UART配置接口不能自动当作整套转台“发送目标角”的运动协议。商品模块的持续电流、散热和输入电路仍须核对，不能把芯片能力直接写成任意小板能力。[ADI TMC2209 产品资料](https://www.analog.com/en/products/TMC2209.html)

制动器应区分“静止保持”与“运动中制动”。厂家确有用于惯性停止、失电时弹簧施加制动的产品；询价须对应动态用途、扭矩、响应时间和允许制动能量，不能只看一个静态抱闸扭矩。[Miki Pulley 动态制动说明](https://www.mikipulley.co.jp/en/electromagnetic-clutches-brakes/offbrakes/braking)

## 5. 先后顺序与待确认事项

### 分批执行

1. **现在：只做采购准备。** C 找2～3套候选，收集完整配置和报价；A 明确载荷、预算、采购条件及候选差异。没有合适成品就交回实际缺项，不转成开放机械设计任务。
2. **获得采购确认后：一套样机。** 优先整套转台、配套控制器、电源与安全附件；先用原厂调试方式验证，不同时购买多套不同电机，不默认连同摄像头、滑环或机械臂购买。
3. **样机核验后：补必要适配件。** 根据真实接口、接插件与线缆确认电平适配、安装件等。已确定必须的安全部件要随首套到齐，不能作为“小风险”留到通电以后。
4. **实物与声学验证后：再接入或扩展。** 先手动角度命令，再接声源方向；有证据后再决定备件、连续旋转、增加自由度或移动阵列。研究通过不替代这些验收。

## 7. 到货后的验收方向（不是本轮 C 的新增任务）

先检查装配固定、供电、接线、限位和安全停止，再用原厂控制器从20°/s、小范围±10°开始，确认方向与真实角度；随后才逐步扩大角度和速度。满载、高速、急停及失电试验必须在已核对风险、固定载荷和防护条件下安排，不能拿停止机构做撞击试验。

记录目标角、输出角、动作时间、限位、故障和停止距离；用独立角度基准核对到位误差，不能用同一个未校准编码器自证精度。接入 DOA 时保存音频帧时间戳、置信度、目标角、反馈角及状态，比较电机断电、保持、匀速、加减速和停稳后的原始四路录音。

当前控制思路是“得到连续可信方向 → 平滑转到目标 → 停稳保持 → 再获取方向”，不是每帧追着噪声摆动。Zynq/PS负责上层目标策略；底层精确定时由PL、实时固件或成品控制器承担，具体实现未冻结。原1 ms控制模型不等于PYNQ/Python已有可靠1 ms实机控制能力。
