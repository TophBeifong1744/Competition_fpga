### 2.2 TBS-K20磁编码360° PWM舵机

用户已确认型号及所选版本，接受其作为本轮执行器，不再推荐SG90/MG90S或另购步进电机。未提供TBS-K20对应版本手册，故以下参数保持未知：额定供电、峰值电流、PWM周期及脉宽范围、角度映射、启动/失信号行为、持续力矩、精度及反馈引出方式。

- “磁编码”表示所购版本的传感方案描述，不能据此推出编码器位数、整机精度或Zynq能回读角度。
- “360° PWM”尚不足以区分全周位置控制与连续旋转调速。应取得该型号映射表，或在固定、卸载/有支承条件下验证：不同合法脉宽是否对应稳定的不同角度。不能套用SG90的0.5～2.5 ms映射，也不能未经手册核对就扫全脉宽范围。
- 若确为360°位置控制，按实测映射设定目标角；若实际只支持调速，当前器件仍可登记为已购并用于转动演示，但“指定方位角停住”的功能需补实际角度反馈与外部控制，或换位置型版本，不能以计时转动冒充定位。
- 舵机内部驱动和传动按成品使用，不接DM542E，不强制外置4:1／6:1同步带。PWM接口匹配实际信号电平、电源和参考地；不预设可直连开发板，不从开发板IO给舵机供电。
- 如无外部角度读回，本轮允许通过独立角度标尺/画面靶标做静态标定；软件区分“目标角”“标定估计角”和“实测角”，不生成假的实时反馈。

## 4. 从旧标准调整到可实现的样机标准

以下是本次需求调整，不是改写器件参数或追认实测通过。数值未有依据的项目采用功能验证，不随意编造新的厂家保证。

| 原标准 | 本轮替代要求 | 改变后的能力边界 |
| --- | --- | --- |
| 独立轴承承重，分体步进架构 | 接受已购简易支架＋成品舵机，只带真实轻载摄像头 | 不承诺工业寿命或重载运行 |
| 外部载荷1 kg，附件0.2 kg | 按实际相机、固定件和随动线缆称量；尽量靠轴安装 | 不做1 kg/5 kg承重验收，不以套件自重代替负载 |
| Yaw±160°、Pitch±75°及规定机械余量 | 不强制原全行程；先小角度逐轴验证，再把无干涉、可定位、不拉线的范围登记为软件工作区间 | 未覆盖方向判为“超出当前工作区间”，不能硬转或悄悄映射为可达 |
| 60°/s、30°/s及固定加速度 | 低速分段目标、停稳再采集；速度/动作间隔按实物调试 | “逐步改变目标”不等于已经证明轴端速度受限；不宣称高速跟踪 |
| 连续1 N·m、短时1.5 N·m | 真实摄像头负载下能到位和保持，无持续堵转、下垂或异常温升 | 15/20 kg·cm宣传值不当作持续力矩；不要求补齐旧力矩曲线后才做轻载演示 |
| 整机≤1°、回差≤0.3° | 不作为本轮购买淘汰门槛；记录双向到位误差和重复性，演示要求停稳后目标仍在实际画面内 | 不宣称精密角度测量；视场内可见不等于定位精度达标 |
| 至少12 bit外部输出反馈 | 不强制外置编码器；先确认舵机内部位置控制和可标定性 | 无回读时只用目标角/标定估计角，不声明外部闭环或实时实际姿态 |
| 动态制动≥0.60/0.80 N·m、≤30 ms、10°停止预算 | 本轮不设工业动态制动采购门槛；限定桌面、低速、有人看护，实物防坠/支承与有限工作区间 | 不沿用旧停止距离、惯量区间及失电安全证明；不承诺断电保持角度或无人值守 |
| 摄像头未列入采购 | 接受已购BL-H6-720p，具备稳定可用图像即可进入演示适配 | 不强制1080p/4K、工业接口、视觉定位、硬件同步或夜视能力 |

四麦阶段只由声学方向控制Yaw，Pitch在经过支承与保持验证的固定姿态使用；六麦输入可靠后再演示两轴指向。始终先用人工角度目标验证机构，再接声源方向，防止声学目标抖动使舵机频繁反转。
