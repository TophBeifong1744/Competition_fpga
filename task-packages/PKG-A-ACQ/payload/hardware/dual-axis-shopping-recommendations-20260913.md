# 双轴云台、TBS-K20舵机与摄像头采购方案

## 1. 方案目标

采用**简易二维云台＋两只TBS-K20磁编码360° PWM舵机＋BL-H6-720p摄像头**，构建轻载、低速、有限工作范围的声源指向演示系统。

麦克风阵列与开发板固定，云台仅带动摄像头及必要安装件。系统接收有效声源方向后转向，停稳后显示或记录图像。四麦阶段控制水平Yaw，俯仰Pitch保持固定姿态；六麦三维方向输入验证后，两轴协同指向。

定位范围以整机标定结果为准。系统用于有人看护的桌面演示，不设重载、精密测角、无限旋转或无人值守运行要求。器件标称参数用于选型，实物性能按第5节验收。

### 3.2 TBS-K20磁编码360° PWM舵机

选用磁编码版本，通过两路PWM分别控制Yaw和Pitch。额定供电、峰值电流、PWM周期、脉宽范围、角度映射、启动/失信号行为、持续力矩、精度与反馈引出方式，需由该版本手册或实物核验确认。

- 指向功能要求能够设定目标位置并停住。“360° PWM”名称本身不能证明是位置控制；取得映射表后，在固定、卸载或有支承条件下验证不同合法脉宽对应的稳定角度。不套用其他型号的脉宽范围，不盲扫全脉宽。
- 若该版本仅支持连续旋转调速，需要实际角度反馈与外部位置控制，或选择对应的位置控制版本，才能实现指定角度停住；不能用计时转动替代定位。
- 磁编码不自动代表编码器位数、整机精度或对外角度回读能力。如无外部读回，通过独立角度标尺/画面靶标静态标定；软件明确区分目标角、标定估计角和实测角。
- 舵机独立供电，PWM信号按实际电平、电源及参考地适配；不从开发板IO供电，不预设信号可直接连接开发板。

## 4. 系统工作要求

| 项目 | 要求 |
| --- | --- |
| 载荷 | 摄像头、固定件及活动段线缆组成的真实轻载；重心尽量靠轴，实物验证到位与保持 |
| 工作范围 | 从逐轴小角度试转开始，将可定位、无碰撞、不拉线的区域登记为软件工作区间；超出范围的目标明确标记不可达 |
| 运动方式 | 低速、分段更新目标，停稳后显示/记录；动作间隔按实物调整，逐步更新目标不等于已经证明实际速度受限 |
| 定位与重复性 | 记录双向到位误差、回差、重复性和停稳时间；指向演示要求目标在实际画面内，不将该条件等同于精密角度验收 |
| 保持能力 | 真实负载下无持续堵转、下垂或异常温升；不以宣传扭矩直接代替连续运行能力 |
| 位置反馈 | 允许静态标定及目标角控制；缺少实时角度反馈时不宣称外部闭环或实时实际姿态 |
| 停止与防护 | 桌面、有人看护、有限工作区间；提供适当支承和防坠/碰撞约束，核查失信号、失电及恢复行为，不承诺断电保持或固定停止距离 |
| 图像 | 能稳定取得可用图像；记录分辨率、格式和帧率，图像清晰度满足演示目标识别 |
| 声学联动 | 先验证人工目标指向，再接声源方向；只使用有效方向输入，避免目标抖动引起频繁反转 |

## 5. 验收方法

以下是验收计划，不是已完成的测试记录。每项记录实测条件、结果和必要的限制。

| 检查项 | 方法与判定 |
| --- | --- |
| 身份与接线 | 核对云台、两只TBS-K20版本、相机身份和附件；确认供电、引脚、电平和PWM参数后接线 |
| 位置控制 | 在已知合法信号范围内验证多个目标能否停在对应位置，标定零位、方向及角度映射 |
| 装配与行程 | 固定相机后逐轴小角度试转，检查舵盘紧固、相机干涉、绕线；登记允许角度和禁入区 |
| 带载到位与保持 | 在工作区间内从两个方向接近目标，记录到位误差、停稳时间、重复性、下垂、噪声和温升；持续抖动/堵转时调整重心或缩小范围 |
| 失信号与失电 | 先提供机械支承，在低风险条件下检查停止、俯仰下落及恢复行为；恢复时避免突然跳到旧目标，不做高速断电试验 |
| 摄像头取流 | 连续5分钟预览无断连作为初检，再在舵机运动中复查；记录实际格式、分辨率、帧率。该初检不替代长期稳定性测试 |
| 指向演示 | 已知目标方向→云台转动→停稳→目标在实际画面内；记录方向输入、机械指向与标定误差，结果只覆盖已验证区间 |
| 录音影响 | 比较舵机断电、保持、运动及停稳时录音，确定等待时间与方向更新节奏；磁编码不作为静音证明 |
