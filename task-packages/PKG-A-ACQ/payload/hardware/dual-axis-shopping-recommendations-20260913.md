## 1. 建议购买的整体形式

首套采用：**无电控、独立承重的双轴机构＋两台两相步进电机＋两路STEP/DIR驱动＋两套同步带减速＋两路输出轴绝对编码器＋两轴制动与完整保护附件**。由团队完成匹配和控制开发，不默认采购封闭电动云台。

- 三维声源方向对应Yaw方位和Pitch俯仰两个自由度，不需要Roll第三轴、平移机构或机械臂。
- 默认六麦阵列与Zynq固定，云台只转动已明确的朝向载荷；摄像头只是可能用途，不列入订单。六麦方案沿用IM73D122V01/PDM，本清单不追加麦克风采购。
- 四麦二维阶段Yaw跟随、Pitch保持0°且持续监控；真实六麦三维输入通过验证后再启用双轴协同。双轴硬件不代表六路采集或三维声学能力已通过。
- 如果改为六麦阵列随台转动，先重算质量、重心、惯量、布线与音频帧中心时刻姿态关联，不能直接套用固定阵列方案。
- 先配一套样机，不同时囤两套电机方案。正式采购仍对应M5声学依据、明确朝向载荷和预算/下单确认；提前购买研究样机须另有明确依据。本次清单生成不等于下单授权。

## 3. 电机与机构必须满足的设计目标

下表是方案目标和计算前提，不是候选商品的实测参数。连续和短时输出力矩均指减速后的输出轴。

| 指标 | Yaw | Pitch |
| --- | --- | --- |
| 工作范围 | ±160° | ±75° |
| 机械总行程目标 | ≥350° | ≥180° |
| 限位／最终止挡候选 | ±165°／±175° | ±80°／±90° |
| 初调／最高指令速度 | 20／60°/s | 10／30°/s |
| 指令加速度上限 | 90°/s² | 60°/s² |
| 连续／短时输出运行力矩 | ≥1／1.5 N·m | ≥1／1.5 N·m |
| 候选减速比／暂定效率下界 | 4／0.85 | 6／0.85 |
| 最高指令对应电机转速 | 40 rpm | 30 rpm |
| 电机连续运行力矩门槛 | ≥0.2942 N·m | ≥0.1961 N·m |
| 电机短时运行力矩门槛 | ≥0.4412 N·m | ≥0.2942 N·m |
| 校准后最终定位及重复到位目标 | ≤1° | ≤1° |
| 输出回差目标 | ≤0.3° | ≤0.3° |
| 输出编码器 | 至少12 bit，优先14 bit | 同左 |
| 总等效惯量适用区间 | 0.01～0.04 kg·m² | 0.004～0.012 kg·m² |

计算采用T_motor≥T_out/(N×η)、rpm_motor=ω_out×N/6。商家应提供实际驱动、电压、相电流和温升条件下覆盖工作速度区间的运行曲线；静态保持力矩、微步数、空载视频均不能代替。运行中的实际转速可能高于指令值，需要核验余量。短时力矩须注明允许持续时间与冷却条件，不以无限制增流取得。

载荷前提：外部载荷≤1 kg，Pitch随动附件预算0.2 kg，合成重心距Pitch轴≤20 mm。Yaw还承受上层机构、电机与附件。Pitch电机尽量固定在俯仰静止支架，其质量仍计入Yaw。加入制动器、编码器及安装板后重算两轴总惯量；超出区间须调整结构或重算，不能随意加配重来满足区间。

## 4. 制动器下单前的硬条件

普通“带抱闸步进电机”不能自动通过。Pitch防下落须独立于主软件和电机驱动力；Yaw也要有失电停止路径，不能只停止STEP。

| 10°停止预算的共同前提 | Yaw | Pitch |
| --- | --- | --- |
| 故障发生时实际速度上界 | 65°/s | 35°/s |
| 全停止过程助推力矩上界 | 0.14 N·m | 0.37544 N·m |
| 建立后持续输出动态制动力矩下界 | 0.60 N·m | 0.80 N·m |
| 静态保持要求 | 按真实负载核对 | ≥0.80 N·m |
| 故障到有效力矩建立总延迟 | ≤30 ms | ≤30 ms |
| 附加可释放能量／角度与安装总误差 | ≤0.01 J／≤1.5° | 同左 |
| 故障位置距最终止挡可用空间 | ≥10° | ≥10° |
| 条件性最坏停止预算／剩余裕量 | 8.612838°／1.387162° | 9.488788°／0.511212° |

同时满足第3节惯量区间及[双轴指南第4节](dual-axis-turntable-procurement-guide.md#4-制动器本次下单前最重要的核对项)全部前提，才能讨论沿用上述预算。Pitch在最低惯量的最坏刚性延迟模型下，接合瞬间约196.33°/s，不能只按35°/s询问允许接合速度。该数值仍为条件性计算，不是实物上限保证。

要求厂家逐项说明：动态/静态力矩、允许接合速度、单次/累计制动能量、工作频度、温度和磨损降额、线圈供电、去能到有效力矩时间及接合/释放确认。整链路30 ms包含检测、逻辑、输出和机械接合；产品单一响应参数不能代替。线圈抑制电路也可能延迟制动。

BXW［L］仅因原厂明确动态制动用途而列为询价系列；网页的静摩擦力矩栏不能直接填入本项目动态力矩保证栏。不能用电机端抱闸力矩乘正向减速效率推导输出安全保证。若候选不能满足，应调整偏心、速度、停止空间或制动配置并重算；原低惯量失败反例继续保留。

正常停车另需提前减速轨迹。制动承载确认后才可降流/关驱动，释放前先建立健康电机承载；状态信号不等于承载力矩测试。急停、失电和恢复不自动释放或重启。制动与电机同时失效不在现有证明范围内，处置前需要独立机械支承。
