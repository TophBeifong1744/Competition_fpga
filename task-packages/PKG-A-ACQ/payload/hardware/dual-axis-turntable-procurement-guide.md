# 双轴转台采购指南｜找货指标与下单前检查

更新：2026-09-13。给 C 与拓芙用于候选筛选、询价和配置核对，不指定店铺或商品 SKU，不是下单、装配、接线或电机动作授权，也不追加 C 的任务或交期。

依据：[C 双轴方案](../../outsourcing/motor_control_plan/motor_plan.md)的准确提交 `407849e3d18e0a6e98a2716c7e5342afb1ea8581`、[独立复核](../../outsourcing/review-status/motor-407849e/README.md)。仅条件性停止预算与防下落原则获批准；真实双轴动力学、保持/制动能力、控制器及实物闭环未验证。

本指南是双轴采购的当前入口。[旧单轴指南](turntable-procurement-guide.md)保留原文与历史依据，其中“买整套单轴”“不需要第二轴”及旧惯量/制动参数不再用于本双轴方案；旧文中的任务安排不重新生效。不要把旧149项单轴性能或556项门控检查套为双轴成绩。

## 1. 推荐采购路线

买**一套无电控的独立承重双轴机构＋两台两相步进电机＋两路 STEP/DIR 驱动＋两套减速传动＋两路输出轴编码器＋配套制动与安全附件**，由团队适配，不购买机械臂，不默认改为整套封闭电动云台。

- 水平 Yaw 跟随方位角；四麦二维阶段 Pitch 保持0°并持续受监控，后续有真实三维方向输入才允许两轴协同。两轴硬件不等于六麦三维声学能力已完成。
- 阵列与 Zynq 默认固定，只转动已明确的朝向载荷。摄像头只是候选用途，不在本次采购中自动加入。
- 42 mm机座只是外形筛选起点；Yaw 4:1、Pitch 6:1同步带传动是匹配候选，不是强制 SKU。更改架构/减速比需重新核对空间、惯量、动态能力与停止预算。
- 采用分体件的理由是保留团队机械适配、反馈和控制开发空间；不是假定分体件已兼容或一定更便宜。

正式采购仍执行[项目采购总则](../../../../hardware/procurement-specifications.md)：M5真实声学收益、明确朝向载荷以及拓芙的预算/下单确认。若提前买研究样机，须由拓芙另外明确；本次发布指南和方案不解除该条件。

| 两相步进电机 | 2台 | 实际速度、电源、相电流、温升下的运行力矩达到第3节；只报保持/堵转力矩不够 | 可不同型号；Pitch电机尽量装在俯仰静止支架，其重量仍计入Yaw负载 |
| STEP/DIR驱动 | 2路 | 与绕组电流和供电匹配，明确RMS/峰值、散热、输入时序及故障诊断 | 有公开模块原理/接线说明与可靠连接器；不把芯片参数当小板持续能力 |

| 输出轴编码器 | 2套 | 真实输出轴读数，至少12 bit，包含磁体/联接和安装附件；步数累计不能替代 | 优先14 bit绝对角度反馈，明确精度、读数年龄和接口；电机端反馈不能单独覆盖传动回差 |

## 3. 电机与机构筛选指标

以下是方案目标或计算前提，不是现成商品已达到的参数。按**输出轴端**比较，不能拿电机端扭矩直接填表。

| 指标 | Yaw | Pitch |
| --- | --- | --- |
| 工作范围 | ±160° | ±75° |
| 总机械行程目标 | ≥350° | ≥180° |
| 限位 / 最终止挡候选 | ±165° / ±175° | ±80° / ±90° |
| 指令速度上限 / 初调目标 | 60°/s / 20°/s | 30°/s / 10°/s |
| 指令加速度上限 | 90°/s² | 60°/s² |
| 连续输出运行力矩目标 | ≥1 N·m | ≥1 N·m |
| 短时输出力矩目标 | ≥1.5 N·m，需注明持续时间和冷却条件 | 同左 |
| 减速比 / 暂定效率下界 | 4 / 0.85 | 6 / 0.85 |
| 指令上限对应电机速度 | 40 rpm | 30 rpm |
| 对应连续电机运行力矩 | ≥0.2942 N·m | ≥0.1961 N·m |
| 对应短时电机运行力矩 | ≥0.4412 N·m | ≥0.2942 N·m |
| 最终输出定位、重复到位目标 | 校准后≤1°，需独立基准测量 | 同左 |
| 总等效惯量适用区间 | [0.01, 0.04] kg·m² | [0.004, 0.012] kg·m² |

公式为 `T_motor ≥ T_out/(N×η)`、`rpm_motor = ω_out×N/6`。必须索取实际驱动/电压/电流条件下覆盖工作速度区间的运行曲线，而非只有端点或空载演示。≥1 N·m是方案选型目标，不是每个负载都需要的最小物理力矩。既有解析最坏运行需求含2倍余量后为Yaw约0.40566、Pitch约0.77601 N·m；它们依赖假设，不可证明任一“NEMA17”满足要求。

载荷预算：外部载荷≤1 kg、Pitch随动附件预算0.2 kg、合成重心离Pitch轴≤20 mm。Yaw还须承受整个上层机构、电机与附件，不能把“承重1 kg”作为Yaw整机承重验收。惯量包括机构、载荷、平行轴项、折算电机/传动，不是只称重量；区间外必须按真实参数重算，不能为了通过而随意加配重。

14 bit每圈量化步长约0.022°，12 bit约0.088°，均不等于整机精度。1.8°、16细分候选下，两轴STEP分别约2133 Hz/1600 Hz，模块要覆盖脉宽、DIR建立/保持和启停时序；这些数值不冻结PL引脚，也不证明双轴协调已实现。

## 4. 制动器：本次下单前最重要的核对项

不能仅搜“带抱闸步进电机”就认定安全。Pitch必须独立于主软件和电机驱动力，**失电施加、通电释放**，兼具动态停止与静态保持。Yaw也必须有符合停止预算的失电停止路径，不能只停STEP。

沿用已批准10°预算必须同时满足：

| 条件 | Yaw | Pitch |
| --- | --- | --- |
| 故障发生时实际速度上界（不是指令上界） | 65°/s | 35°/s |
| 全停止过程助推力矩上界 | 0.14 N·m | 0.37544 N·m |
| 建立后的持续输出动态制动力矩下界 | 0.60 N·m | 0.80 N·m |
| 故障到有效力矩建立总延迟 | ≤30 ms，含检测、逻辑、输出与机械接合 | 同左 |
| 附加可释放能量 / 角度与安装总误差 | ≤0.01 J / ≤1.5° | 同左 |
| 故障位置距最终止挡的可用空间 | ≥10°，并满足第3节总惯量区间 | 同左 |
| 连续区间最坏停止预算 / 剩余裕量 | 8.612838° / 1.387162° | 9.488788° / 0.511212° |

Pitch助推上界包含 `1.2×9.81×0.02=0.23544 N·m` 最坏重力矩，另加0.06/0.03/0.05 N·m假设项；这些外力项、温度与实际延迟仍需核对。静态保持0.8 N·m覆盖2倍0.37544，但不自动证明动态制动。

询价必须问允许接合转速、单次/累计制动能量、工作频度、磨损/温度降额、线圈供电、去能接合时间与接合/释放确认方式。按最坏刚性延迟模型，Pitch最低惯量时接合瞬间约196.33°/s，而非35°/s；这是条件性预算，不是实测或包含所有弹性影响的上限。必须核对相应能量/速度下能力。不要用正向传动效率直接推导电机端抱闸的输出端制动保证。

Pitch只有约0.511°裕量；在最低惯量且其他假设不变时，约31.3566 ms即用尽10°。**这不是放宽30 ms的许可**。若实际部件不满足，应调整偏心、速度、停止空间或制动配置并重算，而非删除失败工况。原J=0.003、10.983615°失败反例继续保留。

正常停车另需提前减速的轨迹和距离。接合状态信号不是力矩测试；降流/关闭驱动必须在确认制动承载后，释放前先建立健康电机承载。急停、掉电和恢复不允许自动释放/重启。具体互锁遵循方案第11节；制动与电机同时失效不在本方案安全证明内，处理前需独立机械支承。

原厂资料仅用于辨析用途：[Miki Pulley动态制动型失电制动器](https://www.mikipulley.co.jp/en/electromagnetic-clutches-brakes/offbrakes/braking)说明其用于惯性/失电急停、弹簧施加及通电释放；不据此批准任何SKU达到本项目0.8 N·m/30 ms条件。

## 5. 接口、电源与安装的拒绝条件

- 不允许凭“兼容单片机”直接接Zynq。需确认真实PL Bank VCCO、可用引脚及复用占用，逐项核对STEP/DIR/ENABLE、驱动故障、制动命令/确认、两轴反馈、零位/限位和急停输入。当前没有冻结引脚表；不能抢用四麦时钟/数据或板载接口。
- 光耦接口要核对输入电流、极性和驱动能力；5 V/24 V反馈不能直接送PL。编码器协议、电平、更新周期、诊断与时间戳一起核对。两路SPI可否共用时钟/数据取决于实际器件与布线，不预设接法。
- 驱动相电流不等于电源输入电流；电源预算应包含双轴并发、电机保持、线圈持续耗电、转换效率、启动与回灌。制动释放回路默认去能，线圈抑制电路不能未经验证拖慢接合。
- [ADI TMC2209官方资料](https://www.analog.com/en/products/tmc2209.html)用于理解STEP/DIR、UART配置与相电流调节；UART配置不是目标角闭环协议，“静音”不是录音验收。具体模块、连续电流、散热及故障可读性均待核对，不指定购买TMC2209。
- 图纸须覆盖整套尺寸、孔距、轴径、两轴交叠/遮挡、全行程线缆弯曲与夹点、制动器/编码器安装空间。禁止强行配孔、悬挂未固定载荷或用线缆当限位。不预购滑环；当前不是无限旋转方案。
