## 配置与标度确认

FFT v9.1 / 1024 点 / Radix-2 Burst I/O，输入输出每个实虚分量 29 位，旋转因子 24 位，convergent rounding，自然顺序，nonrealtime。配置字 `0x0AAAAB`：前向、十级各右移 1 位，共 10 位。`configuration.json`、生成 XCI、IP 属性报告和 VHDL wrapper 相互对应。

直接读取 B NPZ 的 `windowed` 整数码，精确乘 16 后打包进 S29，虚部零；未重算声源、PCM 或窗。C 模型 API 归一化为除 `2^28`，不是应用小数位 27；二者均与 B 实现一致。输出 raw FFT 的每个码直接比较，**不先缩回 S25 来掩盖差异**。

六通道公共最小右移及最近偶数舍入到 S25，用独立软件整数实现复算，所选 60 帧一致；DC/交替正负 `r=2`、900 Hz `r=1`、零 `r=0`。该适配未实现 RTL。B IFFT 仍是原 25 位，不是统一 29 位链。完整解释见 `reuse-and-schedule.md`。

## 明确结论与阻断项

1. **可以进入后续研究**：所选 60 帧 forward29 的位精确和独立核资源预算成立，当前未发现阻断这项限定交付的问题；待 B 复核后才能接入批准范围。
2. **不能替换默认配置**：剩余 136 帧与更广输入未做新 RTL；公共指数选择/缓冲/RNE/标度传播还没有 RTL 与集成验证。
3. **不能宣称单 IP 混合位宽复用成功**：固定 29 位核不能通过配置方向变成原 25 位核。保留数值合同要双 IP，统一 29 位 IFFT 则须重新验证模型、舍入、相关峰、位宽及整链调度。
4. **不能据此关闭 H2/H3 或声学验收**：尚缺集成后时钟/I/O/整机时序及资源、完整定点链、真实幅度数据与误差限验证。未增加四麦采集硬件或扩通道。
