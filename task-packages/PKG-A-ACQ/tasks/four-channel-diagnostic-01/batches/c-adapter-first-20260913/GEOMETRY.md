# C板实物几何与声源描述

来源：拓芙在本任务提供标注mic0～3的整体装配照片、四条边实测40mm，并明确“标准平面正方形，麦克风在四个顶点”。两段间阵列未移动。不是从设计名义40mm或照片比例倒填的实测值。

## 坐标

mic0声孔中心为原点；+X为mic0→mic1，+Y为mic0→mic3，+Z为右手法则的法向。H1的forward/left指本次新坐标轴命名，不能混用此前口语中的前/右。

|数据列|照片位置|坐标(mm)|对应DATA/引脚|CLOCK/引脚|
|---|---|---|---|---|
|mic0|左上|(0,0,0)|DATA1/J4-17/Y9|CLK1/J4-21/V11|
|mic1|左下|(40,0,0)|DATA2/J4-19/W10|CLK2/J4-23/Y13|
|mic2|右下|(40,40,0)|DATA3/J4-33/W14|CLK3/J4-29/U14|
|mic3|右上|(0,40,0)|DATA4/J4-35/V15|CLK4/J4-31/V12|

CSV按mic0～3，不换列。JSON单位为米：[[0,0,0],[0.04,0,0],[0.04,0.04,0],[0,0.04,0]]。

这些坐标是“操作者报告的实测边长 + 正方形/共面声明”的几何模型。仅四边相等不足以数学上证明正方形；直角和共面依赖操作者额外明确确认，尚未独立检验。工具、量法细节、误差和对角线未提供，保持null，不写±1mm或计算对角线为实测值。无需为本轮诊断补精密仪器门槛。

## 声源

最终口语定义为mic1→mic0是右方、mic2→mic1是前方；用户报告声源在mic1左前方约10cm、几乎45°、与声孔大致同高，Run前已持续发声。转换到新坐标轴，**从mic1指向声源约为+X/−Y，方位约−45°，相对高度约0**。

距离和角度以mic1为参考，不是以mic0或阵列中心。不给原点mic0的方位真值，不将粗略估计转成多位小数的“实测声源坐标”。声源具体设备/人声方式、尺量方法和角度误差未说明。安静段不填人声段的声源位置。

本次geometry_version为c-adapter-user-square40-mic0-origin-20260913-v1。H1 config_version因几何字段变化升级为four-channel-c-adapter-v1-usergeom-20260913-v1；runtime firmware_config_version仍是four-channel-c-adapter-v1，不改固件或串口原文。
