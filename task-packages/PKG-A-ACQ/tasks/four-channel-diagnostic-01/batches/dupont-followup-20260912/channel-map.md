# 实物麦克风与数据列对应表

状态：模板已准备，实际映射未确认。物理编号由拓芙在原摆放上固定；
P0～P3 是实物身份，不是预先指定的 mic0～3，也不是算法坐标。

## 固定观察方向

在桌边选定一个观察方向并描述：待拓芙填写。
如现有摆放便于按下图编号，可在不移动麦克风的前提下使用：

```text
        桌面远侧
       P0 —— P1
       |      |
       P3 —— P2
        拓芙观察侧
```

这是编号示意，不是尺寸图。约 40 mm 同平面正方形只是用户此前的摆放描述；
四个声孔的实测坐标均为 null。若实物已经有固定标签，优先保留并记录转换关系。
不要为贴标签盖住声孔或改变朝向。

## 现有工程的电气对应（不是实物位置证明）

下表来自实际生效 XDC 与顶层：J4 数字是板端连接器针号，字母数字是 FPGA 封装球号。
不能将两者混用；沿已接 DATA 线核对，不靠视觉猜插接方向。

| 数据列 | DATA 端口 / J4 / FPGA 球号 | CLOCK 端口 / J4 / FPGA 球号 |
| --- | --- | --- |
| mic0 | pdm_data[0] / 17 / Y9 | pdm_clk1 / 21 / V11 |
| mic1 | pdm_data[1] / 19 / W10 | pdm_clk2 / 23 / Y13 |
| mic2 | pdm_data[2] / 33 / W14 | pdm_clk3 / 29 / U14 |
| mic3 | pdm_data[3] / 35 / V15 | pdm_clk4 / 31 / V12 |

四 CLOCK 为同一 PDM 时基的独立输出，不得短接输出。
实际身份由 DATA 输入决定；若实际 CLOCK 线对应与表中配对不同，照实记录并核查，不暗改记录或带电交换线。
沿用已核对的 3.3 V 与共地；J4-38 为 3.3 V，37/39 为 GND，40 为 5 V，不作麦克风 VDD。
LR 沿用接地，NC 保持原未接状态。J4-29/31/33/35 不得与相机等另一输出源争用。

## 结果填写规则

每轮比较原幅度响应及错误状态，结合 DATA 追线确认；
四轮分别激励不同实物，应形成能解释的物理 ID—逻辑列对应。
无需设定未经验证的“必须大几倍”阈值。

- 追线明确且局部激励响应支持：写明两类证据后标“本批物理映射已确认”。
- 只看到某列最大、只看到相关性高，或声源同时覆盖多只：保留“未确认”。
- 追线与响应冲突：先保留原始材料，不先交换列、改标签或软件重排来消除矛盾。
- 每只实物的刺激能在相应逻辑列体现，才支持本批独立输入检查；
  不由此推出零偏斜、增益一致、相位标定或定位准确。
