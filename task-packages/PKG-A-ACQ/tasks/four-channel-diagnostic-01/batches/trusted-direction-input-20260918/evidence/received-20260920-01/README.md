每段均只有mic1/mic3有非恒定PCM，不能作为四路方向或目标停声诊断的完整有效输入。背景同样全程饱和，不能把问题仅解释为播放声太大；尚不能据此判定坏麦、具体接线故障或PL故障。

源码状态位定义来自 `continuous-prototype-01/rtl/pcm4_continuous_axis.v`：bit4是clip_seen。此次SOURCE=C100001A比旧C100000A多0x10；drained位仍置位，overflow/sync位未置位，DMA_SR=00001002。旧严格检查器因不等于固定C100000A而报 `Source/DMA not safely drained`，**该笼统文案不构成排空失败证据**；本次确定问题是剪裁/恒定满量程，与原始flags及通道数值交叉吻合。

主机当前ELF、bit、launch.json哈希与准备时一致；这是主机版本核对，不是实际FPGA回读。两个正常变化通道找到首尾标记候选，间隔分别4.2510/4.24954秒，推算源文件落在采集约0.741～5.542秒内，因此现有播放启动时机基本可用。此为候选声学对齐，不是精确活动/方向真值。

下一阶段只排查输入异常，不录其余角度：先断电，检查C板插接及mic0/mic2分支的供电、地、CLOCK、DATA连接/焊点是否松动、偏位、短接，与最后可用状态有何改变；不热插拔、不短接CLOCK、不修改采样代码或降低增益掩盖故障。无明确短路等危险且检查完成后，由操作者按原入口重新上电抓一段无播放背景，另存新后缀。若仍异常，再依据真实板图确定单变量交叉诊断，不未经核实让用户换接不同针脚。
