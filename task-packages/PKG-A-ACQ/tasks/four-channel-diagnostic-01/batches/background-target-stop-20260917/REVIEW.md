## 可移植离线复跑

从本目录执行，Python 需 numpy，无须 Vivado、F 盘工程或板卡。结果路径必须不存在。

```powershell
python -B ./verify_delivery.py ./b-check-new.json
python -B ./run_export_tests.py
```

前者复用原解析/关联检查、主线 ELF 解析器及 B 读取器；是工作执行复查工具，并非独立算法实现。后者自动创建新证据目录，不覆盖原日志。B 可按风险独立补查，不需重跑未受影响的旧 DDR/E1。
