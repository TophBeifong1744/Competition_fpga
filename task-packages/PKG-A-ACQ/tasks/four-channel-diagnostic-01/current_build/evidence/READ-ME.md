# 本轮证据说明

本目录保留当前入口的自检、失败尝试和隔离构建报告，不替代独立复核或实板验收。
原来的 189 文件冻结清单和历史脚本不改写；本目录是新增材料。

- run01～run04 的子目录来自各自独占的隔离构建目录。失败记录不回写为成功。
- logs/reports、result.json、preflight.json、artifacts-sha256.json、实际运行入口快照按原字节复制；
  这里的产物清单包含完整隔离目录中 artifact 的哈希，不代表那些二进制全都复制进本目录。
- 控制台安全测试和命令帮助日志为工具响应文本存档；仅对换行做统一保存。
- 当前输入清单包含本机绝对路径，用于明确实际来源；构建程序本身不依赖这些个人路径常量。
- 本目录 .log 是有用证据，局部 .gitignore 显式取消全局 *.log 忽略；不由本任务提交 Git。
- 最终 ENVELOPE-SHA256.json（若已生成）索引本入口和新增证据，排除清单自身。

完整隔离目录及对应产物、实际结果和仍未完成项见 ../RESULTS.md。
