# H3 算法侧增量合同：请 A 裁决工程映射

复用父目录 NUMERIC.md、INTERFACE.md、SCHEDULE.md 和准确28d5c77；旧默认reference25、run05整数链不改。下列明确区分本轮已执行的浮点候选与可执行整数合同草案，**没有生产最终数制已冻结的结论**。

## 存在候选的数值与语义

输入仍为4路signed24装int32，48kHz、N1024/H512。原ID/flags保留；本轮运行入口只接受本批干净、连续、配置匹配的8个Run，遇非零flags或不连续拒绝整个输入，不冒充已有流式错误恢复。流式输入仍按父合同在错误/clip/重启处分段、清重叠/门/跟踪/TTL。

浮点C3：每帧各路减均值，乘对称Hann，1024点rFFT。bins7..72对应328.125～3375Hz；功率 P=2×Σ|FFT[k]|²/(1024×Σw²)，单位PCM码²；不把 FFT bin 功率直接当输入 RMS。至少3路超过开启/关闭门，开启连续3帧、关闭连续3帧。端点码/错误作无效，不缓存旧gate跨Run。

背景前561帧逐通道功率95分位（NumPy linear分位法）为 [984270.410683,1040621.675771,965553.392361,946105.143507] 码²。noise=max(该值,512²)；开启≥4×noise，保持门为≥2×noise。阈值和标定源随config/calibration哈希绑定，不从probe/目标段重估。这是背景标定，不是在线更新噪声；环境漂移、持续非语音干扰均可能失败。

帧判定在frame_end才可用。3帧均满足最早经历1024+2×512=2048样点≈42.667ms；另有原tracker五帧稳定要求及共同音频8样点，不能称42.667ms就是端到端延迟。关闭最多三个判定间隔以及淡变/旧TTL均须在实现中计入。

输出三个不同概念：`band_activity`为候选布尔；`speech_present=unknown`；`target_identity=unknown`。方向稳定不补足身份判断。当前只在研究栏提供候选，不发布正式direction_accepted=true。

## 新整数 gate golden 合同

source/integer_gate.py为逐码可执行草案。RNE为最近偶数舍入，均采用宽整数计算后明确格式边界；没有静默回绕。传输字宽由A裁决。

|阶段|格式/规则|
|---|---|
|均值|1024个S24相加用S34；RNE除1024得S24均值|
|去均值|S25F0，不夹到S24；相减可能超过原signed24幅度|
|窗|父包同一U18F17 Hann；S43乘积暂存，RNE右移17→S25F0|
|前向|精确左移4→S29F4（以原始PCM码为单位；归一化满量程解释为F27）；portable radix2十级各移1、Q30旋转因子、RNE|
|适配|固定RNE右移4→S25F0半谱；overflow使帧无效，不采用未定的共同指数路线|
|频带和|bins7..72，re²+im²用宽无符号整数；最多66项；分子2×sum×1024×2^34用U104，Hann码平方和分母用U45|
|功率|RNE整除后U64F0，单位原PCM码²；阈值标定值向上取整到U64；乘4比较扩至U66，不能64位溢出|
|状态|开启/关闭计数各饱和到3；错误立即reset；至少3路满足；非支持配置拒绝|

8个新实录探针从200ms候选区间首个完整512边界取帧，背景取首个完整边界；无挑最好帧。每段15数组（共120）含gate各级、旧DOA链各级和共同裁剪DAS，见evidence/golden02。重复同一探针3次仅为合成持续时间状态检查，不冒充三帧真实时序。

整数与浮点频带功率存在差别，8探针32路最大相对偏差约0.389%。这是均值/窗/FFT/适配量化差别，不是逐码等价通过；全八段整数门、阈值边界及AMD24位旋转因子的对应仍需后续验证。本轮不以8探针推广全流/全幅动态范围或部署准入。

## 方向、波束与逐级复用

方向开发结果用原浮点PHAT：bins7..85、相对幅度mask0.02、至少12bins、残差≤0.5样点、投影模0.1..1.3；原阈值未调。独立比较原±30°及±60°扇区，捕获5帧/8°散布、20°跟踪步长、200ms HOLD均复用。新门关闭时显式reset候选tracker，自动回退单麦；不把HOLD当新测量。

整数探针另沿run05原窗→FFT29→固定右移4→PHAT S25F23→IFFT25→lag Q12→DOA Q20/角Q8执行，参见父NUMERIC.md。PHAT相对mask用2500×互谱模平方≥band最大模平方，至少12bin；零互谱拒绝。未变化的run05跟踪/断流/整数淡变golden仅引用，不重复跑。当前新音频用浮点线性DAS/冻结Crossfade，候选角度量化5°，24bit WAV RNE、固定共同增益；不是一条已位精确统一的生产链。

## 计算需求：A 负责完整预算

当前候选gate的去均值FFT与原DOA的未去均值FFT不能未经等价验证共用。因此本轮离线研究每帧最坏 **8次前向1024FFT + 6次逆向1024IFFT**。背景门拒绝并未在本轮跳过方向计算，不能提前扣除周期。

- 去均值：4×1023次加法、4次RNE均值、4096次减法；新gate窗4096次实乘。
- gate功率：4×66=264复数bin，528次平方乘、每路累加/一次定点归一化，再4路阈值与常量长度状态机。若常数除法转乘倒数须重新证明舍入。
- 原DOA每帧6×79=474个带内互谱候选；当前软件实际处理半谱513各点的互谱，硬件是否稀疏化由A决定。归一化开方、倒数/两轮迭代、lag搜索、DOA/CORDIC等不能漏算。
- 每输出hop512样点，固定一个DAS方向至少4路线性插值和求和；淡变需覆盖旧/新方向并存，不能只算单beam。离线预计算方向bank和全段权重矩阵不作为FPGA缓存设计。
- 只将旧槽数代入得到8×7366+6×7406=103364周期，**仅历史测试槽算术**；100MHz配置下1.03364ms不是本轮WCET。hop整数预算1066666周期，其余拷贝、窗、PHAT、归一化、状态、DAS、仲裁/背压/CDC/输出都需有限上界。

保守缓存增量：若不能共享gate/DOA半谱，额外4×513×8=16416B；父91080B算术变107496B（不含全部IP内部RAM/软件/描述符真实布局）。gate均值可在已拥有帧上两遍扫描，不新增整帧副本；是否能复用FFT工作区需A给生命周期证明，不能擅自扣减。原250组双槽、1024/512跨包golden仍引用28d5c77，不重复执行或假称新的实时适配器。
