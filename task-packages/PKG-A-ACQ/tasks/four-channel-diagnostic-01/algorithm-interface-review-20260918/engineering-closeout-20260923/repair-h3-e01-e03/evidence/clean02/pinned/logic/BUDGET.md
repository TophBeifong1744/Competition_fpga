# 增量调度/缓存预算：REALTIME_BLOCKED

依据B f5a4cea 的SCHEDULE/回复；只读算术与生命周期规划。100MHz、48kHz、H512：严格周期限额floor(100000000×512/48000)=1066666。原记录32B/组=1536000B/s；不是仅PCM的768000B/s。

## 必须满足的依赖顺序

DMA结束→校验/复制→释放RX→独立可背压重放/分帧→READY；算法消费者按四路Hann/FFT→所有谱及status齐→六对互谱/PHAT/IFFT/lag→DOA/跟踪→WAIT_STATUS→原子提交。DAS消费已有效结果，切换时双束计算；不能因FFT等待而持有已FREE的RX指针。

共享乘法器/除法器/RAM/AXI的最终选择未定，因此此图只说明依赖，不宣称各节点并行或给出争用上界。串行累计式只有在每项服务上界、执行次数和阻塞归属全部固定后才成立，不能把互相重叠时间重复计数或把等待省略。

## 缓存的分配与释放合同（尚不分配新地址）

| 缓冲/逻辑容量 | 分配者与生产/消费 | 释放/最坏积压 | 物理状态 |
|---|---|---|---|
| DMA两槽16128B | 现有PS；DMA→CPU检查/复制 | 复制成功才FREE，禁止占用已释放地址；算法积压不能借此隐藏 | 当前RX保留区，未改 |
| 四路双帧32768B | 拟算法所有者；FILLING→READY→IN_USE | 消费及其所需状态完成才FREE；队列满停会话/报错；上界未定 | 仅规划，不分配DDR |
| BRAM单缓存1024×196bit | 既有独立候选 | 复用512重叠；输出背压阻塞输入 | 历史5RAMB36+1RAMB18；不与双帧方案盲加 |
| Hann4096B | 只读系数 | 常驻 | ROM/DDR选择未定 |
| 四路半谱16416B | 四FFT结果/status | 全六对读完才释放 | DDR/BRAM未定 |
| 单对PHAT4104B、IFFT8192B、相关4096B | 六对顺序复用 | 对应消费及lag复制完成后复用，禁止同时覆写 | 是否原地及RAM端口未定 |
| 音频历史160B、mono双hop4096B | DAS→外部输出 | 消费完成释放；外部设备未定则积压无上界 | 仅逻辑清单 |
| 描述符1024B | 调度器与事务身份 | 无旧事务在途才回收映射键 | 预留估算，非ABI |

上述B列举项共91080B，未含全部IP内部RAM、乘除/队列和状态；BRAM候选不能直接再加到此数宣布资源。S1的9600128B有限归档不作为连续环形算法容量。

若生产者不能暂停且消费者可能无限停顿，则任何有限缓存都不足。有限队列须给出最大服务停顿T、恢复后的持续服务率和突发模型，再推所需空闲容量（至少覆盖停顿期间产生的记录/帧并含在途余量）。当前T未知，容量与WCET明确未闭合；禁止随意扩DDR。
