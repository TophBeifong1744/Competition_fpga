# 条件化工程预算：可执行，但完整实时上界仍阻断

配置100MHz、48kHz、N1024/H512；hop=512/48000秒，严格整数限额1066666周期。首次可成帧需1024样点≈21.333ms；新gate三帧最早2048样点≈42.667ms，另加计算/交接/跟踪，不等于端到端延迟。

推荐路线见ROUTE.md。`source/engineering_model.py::budget`将工作量排到单一串行共享资源上，按依赖顺序计算开始/结束；不把同一RAM/ALU的使用重叠隐藏。它是**操作槽设计模型**，不是仿真测得RTL周期，不是ARM WCET。

## 操作数及模型公式

定义m25、m51、mw为一次指定宽度乘法含结果回收所占的模型周期；示例A为25/51/75，代表保守逐bit移加迭代；示例B为1/4/9，代表需设计与实现证明的并行乘法服务。它们均未由XSim/时序证明。每个服务调用串行，模型内II等于该调用完整占用时间；没有暗计零启动延迟的无限流水。若真实核有额外启动/排空，须加入公式，不得沿用示例直接放行。

| 环节 | 可推导工作量/条件周期式 | 尚缺证据 |
|---|---|---|
| 复制/检查 | (250+512)×8×4；按每LE32四操作，覆盖每hop最多750组的包相位工作 | PS指令数不等于周期；cache miss/总线等待未界定 |
| accepted-row/组帧 | 512×8+1024×8操作槽 | PS逐行分支/重叠复制WCET |
| 新gate均值 | 4×1023加法、4×10除2幂槽、4096减法 | 可在已拥有帧两遍读，不新增整帧副本；CPU/PL实现未定 |
| 两套window | 8192×(m25+2) | 共享乘法/ROM访问并行度和宽加法实际时序 |
| forward FFT | 8×7366历史槽 | 原DOA与新gate变换不能直接共享；槽不是新增核服务WCET |
| 固定4适配 | 8×513×2×2 | DDR读/输出桥带宽 |
| gate功率 | 528×(m25+1)+4×(66+104)+32 | U104/U45整除每bit一步的硬件；PS大整数代价未知 |

| 模平方/mask | 3078×(2m51+1)+474×13+6×78 | U102/常量乘比较实际实现 |
| PHAT归一化 | 最坏474×[75×3+2×(2mw+4)+2mw+8] | U150开方75次三操作迭代，倒数两轮宽乘/最后两分量；真实核心延迟及状态屏障 |

| IFFT | 6×7406历史槽 | 独立25位核，不能把29位核runtime切宽 |
| lag | 86×2+6×(2×64+6+mw) | 峰值扫描；插值及margin两次64步除法预算，真实除数范围/核心验证 |
| DOA | 6×(4mw+64+20)+2×(mw+64)+24×4+2mw | 方向/残差/模长/CORDIC操作槽，推荐先PS；非ARM实测 |
| DAS方向延迟 | 2×24×4+8×(mw+18) | 旧/新方向sin/cos与Q12延迟生成，24步假设待实现 |
| 双beam DAS+fade | 2×512×4×(2m25+4)+512×(2m25+4) | 不能只算一个beam；输出等待无界时阻断 |

| CDC、队列 | 14×8、1024操作槽 | 8周期仅空载握手设计假设，不是异步FIFO满/复位/仲裁等待上界 |
| 外部等待W | 明确输入，None立即阻断 | PS/DDR/仲裁/config/status/CDC/output所有等待的有限总上界尚无证据 |

精确本轮算术输出在run03的budget-serial.json和budget-parallel-assumptions.json；每个环节都有begin/end及依赖。两例都返回`total=REALTIME_BLOCKED`。保守串行例明确超限；较快乘法示例在W=50000周期时有条件满足，但这50000是敏感性试算参数，**不是测得/证明的等待上界**。读取器或评审不得只看conditional_deadline_met就放行。

旧73900仅4FFT+6IFFT；新B合同最低8FFT+6IFFT历史槽算术103364，也不是全链。为证明有实际内容，本包模型会断言：串行超限、较快条件例未超限、未给有限服务必须阻断；并运行逐arrival队列，消费者略慢于到达率会真实达到QUEUE_FULL。

## 缓存/资源不可混算

run03/memory.json给出每一块64B对齐的候选相对偏移、end、用途和总字节，含两RX槽、8包环、两32B/组帧区、两套半谱、单pair计算区、插值邻域、输出hop、描述符。范围越界、重叠、错对齐有预期拒绝测试。总逻辑空间小于1MiB仅是可行容量：**不构成实际DDR地址/程序边界绑定**，尚未修改任何链接配置。

本路线PS组帧，因此不再加BRAM分帧主缓存；若改PL组帧，须重算生命周期，不能把91080B或107496B与5 RAMB36+1 RAMB18直接相加。上述内存未计所有IP内部RAM、程序栈堆、PS cache；不能换算为器件总BRAM占用或说资源已通过。

2frame容量包含IN_USE，不是2个等待+1个处理。8packet队列包含未消费头包；满队列不覆盖。离散模型检验同刻完成先释放、满队列拒绝、共享RAM串行、前驱未完成不能启动；实际PS检查/CPU缓存维护需另测。RAM端口、DDR总线和乘法器同一时段不能重复承诺吞吐。

## 下一项最小工程工作（本轮未操作）

1. PS独立语义桥C实现，按f879及本包状态/队列golden测；为ring/frame实际地址与程序边界建立合同。
2. 测PS校验/拷贝/组帧及DOA worst-case路径，定义队列满fail-stop与定时锚的可观测量。
3. A/B定数制后才设计PL数值核心；逐个给服务延迟/II和共享端口仲裁上界；历史FFT证据只复用未变化部分。
4. 收齐DDR、CDC、配置/status/输出等待上界及队列初始占用条件，再跑全链调度与容量测试。没有这些，total继续REALTIME_BLOCKED。

以上需拓芙选择原工程/副本并按整阶段操作单执行；本轮不做综合/实现、实际工程接入或上板。
