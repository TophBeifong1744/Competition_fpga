最短实施顺序：集中确认profile → 冻结对应golden与受影响输入 → 在独立仿真候选中补Hann/fixed4/后级 → 获B限定复核 → 用户执行获准工程接入并提供结果。没有前置时不创建生产RTL凑完成率。

本表区分9/18本轮“缺项计划及已有软件证据整理”和后续“实际AMD/RTL/板级实施”。后者未执行继续记录，但不要求为交付本表立即上板；不新增M1/Skill或C门槛。

每个新增对照须保存：配置和源码准确身份、原始输入码、golden来源、实虚码/顺序/缩放/overflow、第一处差异、命令/原日志、覆盖数和未覆盖域。失败输出保留；允许的数值误差与文件字节差异分别判定。

层次标签固定：软件整数一致 / AMD IP仿真一致 / 自研RTL一致 / 综合估算 / 布局布线 / 实板。当前本轮仅来源和预算模型检查，不勾选后五层。正式H3、精度、音频收益、完整M1均不在本稿批准申请。
