## 精确输入与时钟

复用父包的 center、quiet 各 32000 行四路实录及 61 帧记录；两段分开处理，quiet 只作为不同批次背景诊断。方向入口只接已生成的投影，不传入录音名称或手动 +X 信息；同一时刻重放后的状态／拒绝值严格比较、浮点值按既有 atol/rtol=1e-10 检查，本机差为 0。父包本来没有可靠存在门，本轮没有声称补齐。

三路共用参考行 **[8, 31992)**，每路 **31,984 样点、0.666333 秒、48 kHz／24 位／单声道**。中心录音参考编号 17421～49404，quiet 为 17246～49229；编号用十进制字符串保存。原单麦与原始 PCM 裁剪逐码相同，中心手动与已获 A 批准的手动 WAV 对应裁剪逐码相同。

相对 mic0 的补偿定义仍为 `y_i[n]=x_i[n-d_i]`。由于某些方向有负 d，三路统一记 **8 样点**的保守音频可用延迟：参考 n 的输出可在 n+8 到齐后获得，所有读取抽头不晚于该时刻；三路 WAV 的第一样点对应同一个参考编号，未插入各自不同的前导静音。该 8 样点只是离线索引合同，**不是完整系统实测延迟**。

方向仅从整帧末尾可用的参考样点开始应用，不把该方向倒用于原分析帧。新方向的首个切换样点保留原权重，之后淡入。使用样本编号相对时钟与零计算耗时假设，尚未实现真实逐块调度；离线预计算的 22 路候选波束缓存不能当作 PL 资源预算。

每个 clean interval 重新建状态；不跨错误行、缺样或录音拼接。定位不足整帧的干净尾段仍保留声音，并按最后方向期限逐样点处理；很短、无法满足共同裁剪的区间会报错，不补零伪造输出。

## 实际结果与局限

最终 `evidence/run02/`：**21 项音频测试 + 21 项既有四路跟踪入口回归 + 8 项原手动渲染回归 = 50 项通过**。12 个 raw／preview WAV，共 **383,808 个 PCM 码值**逐个重算一致，0 个溢出／饱和样点，0 个提前使用或过期方向的非零权重。还有基于整数输入与有理数求和的抽样 golden，覆盖首次捕获、切换与尾段。没有重跑六麦研究或 FFT 定点全链。

| 实录 | 自动路纯单麦样点 | 单麦／波束混合样点 | 波束部分权重合计为 1 的样点 |
| --- | ---: | ---: | ---: |
| center | 12,281 | 479 | 19,224 |
| quiet | 31,984 | 0 | 0 |

“波束部分权重合计为 1”可包含两个旧／新方向的交叉淡化，不等于全部正确定位。中心首次新鲜方向在录音起点后 256 ms，自动波束首个非零权重在参考样点 12289。quiet 自动输出与单麦逐码相同，原因仍是既有候选落在允许范围外；不能据此证明存在门或各种场景无误锁。

三路 raw 增益均为 1；三路 preview **统一增益 32**，沿用本批既有试听尺度，不分别响度归一化。中心 raw 峰值：单麦 0.007499695、手动 0.007011414、自动 0.007018277。自动与单麦的 RMS 差异只说明波形发生变化，不是 SNR 或降噪收益。线性分数延迟仍有频率相关衰减。

### 修复与失败证据

初次 `run01` 的 48 项测试及短实录核对通过，但后加的两项测试暴露“淡出期间换方向／释放时重复乘淡出量”，构造例中的权重突变为 0.25。原始失败保留在 `evidence/expiry-regression-before-fix.log`，准确命令见旁边 JSON。修复后仅施加从当前淡出状态开始的后续衰减，两项新测试及全部相关回归在 run02 通过。

`history/before-expiry-fix/` 保留旧 mixer 和旧 19 项音频测试源码。它们是在收尾时按已记录变更逆向恢复，并与 run01 已保存源码 SHA-256 严格匹配，来源如实记在 `RESTORATION.json`，不冒充当时另存的快照。run01 的其他源码仍与当前对应文件相同。

`evidence/saved-run-comparison.json` 单独比较修复前后两段短实录的 WAV 字节、混合数组及报告数值。短录音未触发上述临期重定向边界，修复前后录音输出相同，不能用它们替代新增边界测试。生成 JSON 因源码记录不同而字节不同，输入哈希、逐码核对和 JSON 字节分别记录。尚未在 A 的 CPU 上复测。
