## epsilon 与掩码

基准 six_mic_baseline_core.py::gcc 使用 z=Xi*conj(Xj)，amp=abs(z)，掩码 band & (amp >= .02*max(band_peak,1e-15))，不足12频点拒绝麦对；归一化 z/max(amp,1e-15)。频带 300..4000 Hz，在48k/1024条件下为索引7..85，共79点。原文件 SHA 见 sources.json。

当前 IP 前向 DFT/1024，互谱缩放2^-20。FFT 分量按S25F23解释，整数乘法互谱有46小数位，故 epsilon 在互谱整数码单位为：

`1e-15 × 2^-20 × 2^46 = 6.7108864e-8 = 2048/30517578125`。

这是精确保留的有理数，**不把它量化为0，也不替换成1码阈值**。每个非零整数互谱的模至少1码，因此非零分支必大于epsilon；零值通过显式无效/掩码排除。至少12点的规则保持不变，无效麦对输出携带 valid=false 和原因，不能把全零数组当有效相关或零时延送给跟踪器。

带内峰值非零时，2%掩码可精确转为 `2500*(re²+im²) >= band_max_square`；全零时必须额外判零。这保留1/50的数学边界，不依赖近似平方根。基准NumPy二进制浮点在任意极端临界点的逐位行为不由数学等价保证；本批次临界案例和随机对照无差异，后续仍需逐帧检查。相关峰抛物线分母使用的另一个1e-15是相关域判定，不能套用本互谱epsilon缩放。

## 模长与倒数设计

1. 互谱整数平方和，计算 `round_even(sqrt(square × 2^(2F)))` 得到带F位小数的模长码。当前研究候选 F=24，旧 F=16 对照保留。
2. 用最高有效位求指数e，将模长归一到[1,2]附近的U32F30尾数；256项区间中点倒数表初始化，随后两次整数Newton迭代 `r <- r*(2-m*r)`，每个乘法回缩均最近偶数舍入。
3. 原互谱分量乘倒数、恢复模长指数，最终舍入到S25F23；不额外乘/除1024。不把供应商IP overflow当作内部饱和；上游overflow使整帧无效，本麦对入口拒绝。内部输出若超S25范围显式抛错，不悄悄回绕或当有效值。

Python math.isqrt 是精确整数规格模型，不是已综合平方根实现；查表及Newton也仅有软件整数模型。此处没有宣称 PHAT RTL 位精确完成。

## 保守位宽与预算草案

| 节点 | 保守候选 |
|---|---|
| FFT输入分量 | S25F23 |
| 互谱分量 | S51F46（相对缩放后的物理量） |
| 平方和 | U102，按互谱整数码平方 |
| F24模长开方被开数 | U150（平方和左移48） |
| 模长码 | U75，24位小数相对于互谱整数码 |
| 2%比较左侧 | U114，乘2500后比较 |
| 归一尾数 / 倒数 | U32F30 / U31F30 |
| Newton乘积 | 最多U63，回缩到30小数位 |
| 互谱乘倒数 | 保守S83，按指数回缩 |
| 最终PHAT分量 | S25F23 |

256×31位倒数表为7936bit，打包992B，按32位字存1024B；不代表一个BRAM的实际映射。若串行保存513个频点，模长缓存 ceil(513×75/8)=4810B，互谱两分量 ceil(513×2×51/8)=6541B，掩码65B；可选带内处理/重算/复用，但不能直接加到旧预算后宣称完整RAM足够。
每个保留频点包含平方根、归一化、查表、4次Newton乘法及2次输出乘法，另有互谱4乘2加、平方和2乘1加及mask比较。U150逐两位平方根若采用一轮/周期迭代结构需75轮，尚无RTL周期承诺。周期、DSP、BRAM和整机余量保持待定；必须与A共享FFT剩余898666周期/hop的预算做后续调度和综合，不能沿用1.56ms当整链时间。
