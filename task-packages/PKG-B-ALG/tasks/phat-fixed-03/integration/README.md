## 本次完成

`chain.py` 串接 PCM S24F23 → U18F17 Hann 加窗、最近偶数舍入 → S25F23 FFT → 整数 PHAT 模长 F24/倒数候选 → 共轭补全 → S25F23 IFFT → 相关峰及 Q12 分数时延。FFT/IFFT 使用 AMD 位精确 C 模型，两者均每级右移 1 位，共 10 位；C API 以码值除以 2^24 传输，应用层以 S25F23 解释，不额外左移。

峰搜索保持原始顺序及首个最大值规则；抛物线插值使用最近偶数整数除法，限制在 ±0.5 采样。时延物理边界仍用原浮点几何计算。方向仅调用原浮点最小二乘作诊断，不是定点方向解算。

`protocol.json` 在实验前记录两种种子、三个轴向方向及六种场景。每个场景仅取一帧，共 36 帧、540 麦对；场景之间共用源信号，900 Hz 纯音和零输入有重复，不能称 36 个独立样本。普通输入采用每帧共同峰值 0.5，弱输入共同峰值 2^-20；这是测试增益，不是实际采集增益约定。tone900 是纯音声源，不是宽带目标叠加单频干扰。

每帧同时比较原浮点输入、PCM 量化后浮点基线和整链候选，保存逐麦对掩码、有效性、相关峰、时延及各级数组。浮点对照的时延还逐帧与原始 `gcc` 函数检查一致。

弱输入六帧 PCM 最大值均为 8 码，加窗后最大值为 6～7 码，FFT 输出全部为 0。PCM 量化后的浮点基线仍接受全部 90 麦对，说明输入 PCM 量化不是全部失效的充分解释；本候选 FFT 逐级缩放及量化消除了剩余频谱。相对 PCM 浮点对照仍有 6386 个掩码频点差异。不能靠修改 PHAT epsilon 恢复已经丢失的信息，也尚未测定最低可用幅值。

5 项峰符号/插值/同峰选择检查完成；上游无效标志注入使全部 15 对无效；+1 输入的 6144 个样本正确饱和到 8388607。正常场景 IP overflow 为 0，IFFT 虚部最大残余 1 码。注入试验不是实际制造硬件 overflow；IFFT overflow 分支尚无专门故障注入测试。

## 预算与剩余边界

最坏每帧仍为 6 次 FFT、15 次 IFFT；A 的约 1.56 ms 仅是 21 次变换预算，未包含 PHAT、峰搜索和数据搬运。每麦对搜索 `2*ceil(物理界限)+1` 个相关点，另读相邻点并至多做一次 Q12 除法。当前六麦有 12 对界限约 5.60 采样、3 对约 7.92 采样，分别搜索 13、17 点，15 对共 207 个搜索点。实际缓存、除法延迟与调度尚待 RTL 实现，不将 Python 数组内存当作 BRAM 预算。

相关输入 S25F23 时，抛物线分母保守需 S27；差值左移 11 位的分子保守需 S37，不能直接沿用 25 位算术。Q12 时延连同有效性判断前的 ±8.5 采样中间结果保守用 S17 承载，但作为参数化接口仍须随最大麦距检查。Python 整数模型不证明这些位宽的 RTL 已实现。
