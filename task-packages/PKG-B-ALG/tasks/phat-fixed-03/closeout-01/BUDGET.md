# 格式、计算与缓存预算草案

本表针对已有六麦1024点软件研究，Fs=48kHz、hop=512；不推导四麦实录性能。除明确引用A证据的单核数据，其余是规格/估算，不是RTL综合或时序承诺。

## 格式与异常合同

| 节点 | 格式/行为 |
|---|---|
| PCM | S24F23，输入浮点×2^23最近偶数，夹到[-2^23,2^23-1]并计数；实录读取器不在本轮 |
| Hann/窗乘 | 对称1024点U18F17；保守S42乘积，右移17最近偶数、夹到S24、符号扩展S25，不左移 |
| reference25 FFT | 应用S25F23；C API code/2^24；前向DFT/1024，十级各移1 |
| wide29 FFT | 窗码精确左移4，S29F27应用解释；C API code/2^28；十级各移1 |
| wide29适配 | 全6×1024复分量共同最小右移r、最近偶数回S25；解释为F(27-r)，不能丢指数 |
| PHAT互谱 | 保守S51，两乘相加/相减；reference25有46小数位；wide29随指数改变，不能仍固定F46解释 |
| 平方和/掩码 | 保守U102；乘2500比较用U114；band索引7..85共79点；全零无效、至少12点 |
| epsilon | 10^-15×2^[2(W-2-r-s)]，保留有理数；本批0<epsilon<1支持显式零/非零分支，未来配置需重查 |
| 模长 | F24规格：U150被开数→保守U75；math.isqrt为整数规格，不是RTL |
| 倒数/归一化 | U32F30尾数、U31F30倒数、256项表、2轮Newton；最多U63乘积；互谱×倒数保守S83；最近偶数回S25F23 |
| IFFT | S25F23 PHAT输入，513点共轭补全1024；C API code/2^24；十级各移1对应标准IFFT，不再除1024 |
| 峰值/Q12 | 实相关S25；首个最大值；分母S27、分子S37、一次带最近偶数的整数除法，分数夹±2048；时延中间S17Q12 |
| 边界/下游 | 物理边界和LS诊断仍浮点；S17范围需随阵列最大麦距重查；跟踪、音频未实现整数链 |

任一前向FFT overflow或上游无效使整帧麦对拒绝，任一IFFT overflow最终使整帧无效；共轭取负/PHAT输出越界抛错而非静默回绕。PCM削顶仅计数，当前并非自动整帧拒绝，系统接受策略待约定。IFFT虚部保留在证据，实相关使用实部；历史观测最大1码，不构成通用上界。整帧提交需在所有IFFT状态完成后，不能先发部分有效结果再忽略晚到错误。

## 每帧运算

令P=15、B=79、K≤P×B=1185为被保留且进入归一化的频点总数。

| 项目 | 数量/周期模型 | 证据层次 |
|---|---|---|
| 加窗 |6144个24×18乘法及舍入|软件实现；一结果/周期才是6144周期，未综合 |
| 变换 |6 FFT + 至多15 IFFT=21；输入/输出各21504复样点|数学链规格；无效对跳过IFFT |
| Python当前互谱 |15×513=7695点；30780实乘、15390加减|源码直接计数，尚未只计算带内 |
| Python当前平方和 |mask阶段15390实平方；normalize另2K实平方|重复计算确实存在，不按优化后伪报当前工作量 |
| 带内硬件候选 |1185互谱点：4740乘、2370加减；2370平方+1185加；若缓存平方和则免normalize重复平方|可行优化草案，未实现/逐码验证；带外输出固定零 |
| 掩码 |每对79点求max及第二遍2500倍比较；需保留至少12点计数|比较/常量乘架构待A/B实现 |
| 每保留点模长/倒数 |1次U150开方、归一化移位、1查表、4次Newton乘法、2次输出乘法；必要时2次平方|K次；迭代开方假设75轮/点则≤88875轮，不等于总周期 |
| 共轭/IFFT装配 |每有效对送1024点，含带外零和负频共轭|至多15360拍，若被FFT实测装载计时包含不可重复加算 |
| 峰搜索 |12对×13点+3对×17点=207点；最多192次择大比较；每对再读邻点，最多15次Q12除法|由既有几何得到；回绕负lag需缓存/流式尾部方案 |
| wide29公共指数 |6144复点/12288分量检查，再对全部分量或保留513点/通道舍入|额外读取/写回和屏障；未计为免费操作 |

100MHz、512/48000秒/hop可用约1066666周期。A的`ac0ff38`配置证据为21次变换155526周期=1.55526ms，规划168000周期后余898666周期；单核OOC为6DSP、6RAMB18=3Tile、1292LUT、2148FF。这些仅属于25位FFT候选，不是29位或整链测量，也不是本轮新综合。

串行保守估算写作：

`T_hop = T_window + 6*T_F(W) + P_valid*T_I(Wi) + T_adapter + T_cross_mask + K*T_norm + T_peak + T_external_move + T_stall`。

`T_norm`含开方、位移、查表、Newton和输出乘法的实际多周期延迟；宽乘法可能拆多个DSP/周期。25位可用A准确调度替换变换合计项，但不能把每job平均时间套入29位。若变换时间已含I/O装载，`T_external_move`只加未覆盖的搬运。流水重叠需要RAM端口/仲裁实证才能从串行总和扣除。75轮开方总数看似低于余量，也不能证明PHAT满足时限。

## 缓存与调度

裸位宽下6×513复谱25位为19238B、29位22316B，增量3078B；全1024点为38400B/44544B，增量6144B。ceil取整，未含字对齐/端口/双缓冲。按每分量32位存两种均是24624B半谱或49152B全谱，故“位宽增加4位”不必等于软件字槽容量增加，但硬件实际BRAM映射仍可能变化。

以下为一个可实现前的**保守外部缓存配置估算**：保留wide29全谱支持公共指数检查，再写半谱S25；逐麦对处理，IFFT双缓冲；不把Python同时保存15对整数组当实现要求。

| 缓存 | 槽位假设 | 字节 |
|---|---|---:|
| PCM采集乒乓 |2×6×1024×32bit|49152|
| 单通道窗暂存 |1024×32bit|4096|
| Hann表 |1024×32bit（18bit裸2304B）|4096|
| 原始前向全谱 |6×1024×2×32bit|49152|
| 适配后半谱 |6×513×2×32bit|24624|
| 单麦对互谱 |513×2×64bit容纳S51|8208|
| 单麦对平方和 |513×128bit容纳U102|8208|
| mask |513×8bit，非位打包|513|
| 当前模长 |1×128bit槽容纳U75|16|
| IFFT输入/输出双缓冲 |2×1024×2×32bit|16384|
| 倒数表 |256×32bit|1024|
| 时延/标志结果 |15×16B预留，协议未冻结|240|
| 合计 |不含IP内部RAM、FIFO、宽算术寄存器、DMA/系统缓存、跟踪/音频|165713|

合计只是上述配置的逻辑容量，不是整个系统内存上界，更不能直接除以BRAM容量当综合占用。公共指数及frame/config/error元数据另需接口定长。reference25不需wide29适配副本；串行复用可以省缓存，但此表保守保留独立槽。带内79点存储或边流边峰可进一步节省，需另验证实现及端口。

推荐评审的串行顺序：采集乒乓隔离→六通道加窗/FFT→检查所有FFT状态和公共指数→半谱适配→逐对两遍掩码/归一化→共轭装配/IFFT→峰值→所有状态结束后提交整帧。下一hop采集仅与处理重叠；FFT、PHAT、DMA同时访存尚未承诺。软件公共指数遍历完整1024点；只存半谱时仍需检查丢弃部分的最大值，不能无验证省掉。

## 与A的参数化方案

| 路线 | 必要差异 | 资源/周期状态 |
|---|---|---|
| A原25位同核FFT/IFFT |保持原配置，B新增窗/PHAT/峰/外部缓存|仅单核已有上述OOC/调度证据；B模块未RTL化 |
| 29位FFT + 25位IFFT双IP |wide29适配及公共指数；两核独立配置|资源为R_F29+R_I25+R_adapter+R_external；29位项全部待A，25位仅同参数时可引用旧核证据；并行速度收益待调度 |
| 统一29位FFT/IFFT单IP |IFFT输入S25F23如何映射29位、输出如何回相关域、舍入/虚部/epsilon/overflow均需新合同及golden|资源为R_shared29+R_adapter+R_external；周期6T_F29+15T_I29及其他；尚未实现，不能称单IP复用已解决 |

本轮不新增RTL路线研究。A返回29位准确配置、XSim/资源/时序后补表；B据此验证适配/数值和完整调度，再作包级方案决定。
