## 四路计数与参数预算（估算，非综合/时序通过）

Fs=48000，N=1024，H=512，帧率93.75 Hz，帧窗口21.333 ms，hop10.667 ms；100 MHz每hop约1066667周期。当前前向/逆向共最多10变换，不沿用六麦6+15。

- 窗：4096次24×18乘/帧。
- 当前Python PHAT：6×513=3078互谱点，12312实乘、6156加减；mask阶段6156次实平方，另normalize最多2K次平方，K≤6×79=474。每有效点1次整数开方、4次Newton乘法、2次输出乘法。将只算带内作为未来优化，不假报已经实现。
- lag搜索：4×13+2×17=86点，80次择大比较，最多6次插值除法；±8加±0.5的Q12中间范围34816码，需至少S17，合法最大7.9163样点的输出不能反推中间S16足够。
- A29同TB无背压4前向服务槽估算=4×7366=29464周期（0.29464 ms），不是本次四路测量。reference25借A既有21变换155526周期线性估10变换约74060周期，仅规划参考；前/逆配置和阻塞仍需实际调度测量。
- 全链需满足 `4*T_fft + 6*T_ifft + T_window + T_phat + T_lag + T_doa + T_das + T_memory + T_switch <= 1066667`；若重叠流水需给真实依赖图，不能既减重叠又漏缓存/装载。没有全部T，不计算虚假的安全余量。

采用每实部/虚部32位存储的保守逻辑工作集（不叠放生命周期，未优化）：PCM双帧32768 B；4×513复数频谱16416 B；单对PHAT4104 B；单对完整复数IFFT8192 B；单对实相关4096 B；1024个U18窗系数使用32位槽，为4096 B。合计69672 B，另加PHAT中间平方/模长、多轮缓存、掩码、状态、DMA描述符、音频、IP内部存储。该数不是总BRAM。Python NPZ保留所有帧属审计存储，不是硬件缓存预算。

PCM输入带宽4×48000×4=768000 B/s；若每重叠帧重读整窗，读1536000 B/s。若10个变换输入输出均经32位实虚总线转存，10×1024×8×2×93.75=15360000 B/s，另加上述PCM、PHAT及音频传输。若流接核可减少DDR搬运，须由A调度确认。不得将32位槽估算当25/29位打包后的实际总线利用率。
