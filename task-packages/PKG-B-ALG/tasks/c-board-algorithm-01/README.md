## 诊断发现与失败边界

人声浮点各对中位时延，顺序 01/02/03/12/13/23，为 +3.655/−0.730/−3.535/−3.983/−7.603/−3.192 样点。`X_i conj(X_j)` 正 lag 表示 i 比 j 晚到；平面远场方程用 `(p_j-p_i)·u * Fs/c`。符号以直接序列延迟和几何代数测试核查，没有新增四麦声学模拟，也没有宣称实物映射已校准。

人声 mic1–mic3 浮点 48/61 帧、定点 49/61 帧整数峰位于边缘；两链均有 16 对 TAU_BOUND、6 对不足 12 个频点，但有效性并非逐对全一致。全局整数峰超出连续物理界限不等于最终插值非法；所有原始峰和判定都保留。边界量化翻转和弱信号相对掩码是后续重点，当前不修改保护阈值“消除差异”。

安静段 366 对均合法，平面一致性浮点 35/61、定点 33/61；这不是声源存在率或正确率。相对能量掩码没有绝对声源存在门，安静环境背景也可能有相关结构。峰裕量只是诊断量，尚未标定为置信概率；不新增一个拍脑袋阈值宣布问题已解决。人声两链平面一致性均 54/61 也不能作精度通过。

几何依操作者 40 mm 正方形声明；约 10 cm、−45°以 mic1 为参考，不是阵列中心远场真值。平面阵列无法凭这些数据唯一恢复上下半空间；近场/校准误差可能使远场平面拟合失配。所有 `direction_accepted=false` 是明确的诊断权限限制，与 `advisory_consistent` 数值一致性分开。
