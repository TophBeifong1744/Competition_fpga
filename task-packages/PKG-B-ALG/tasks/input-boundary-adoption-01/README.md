## 候选数制

记 S/U W F 为有/无符号总宽 W、小数位 F；不是 RTL 冻结。

| 量 | 增长参考候选 | 缩放存储候选 |
|---|---|---|
| 输入/窗 | S24F23 / U18F17 | 相同 |
| FFT 分量 | S34F23，总右移 0 | S25F23，总右移 10 |
| 互谱分量 | S69F46 | S51F46 |

候选舍入为最近偶数，溢出饱和并计数，不回绕；无效候选用有效位。LS、模长/倒数工作区与分级移位仍待定。FFT 缩放必须跟踪物理指数；原 PHAT epsilon=1e-15 需要映射，不能任意改阈值。IFFT 物理归一化必须保持 1/N，避免 IP 与软件重复缩放。

## FFT 需求与计算预算

当前六麦离线参数 Fs=48000、N=1024、hop=512，93.75 帧/秒，每 hop 10.6667 ms。每帧 6 次实 FFT、最多 15 次实 IFFT；513 个单边频点，定位带内 79 点。硬件若只提供复 FFT，需明确实序列映射、共轭补全、数据顺序和变换数，不能直接把 NumPy 调用数当 IP 周期。

每帧窗乘 6144、互谱复乘/模长/复数除实数各 7695、峰值时延候选 207；最多两次秩检查和一次 LS 另计。音频上界 66 MAC/样点，即 3.168 M MAC/s，另有淡入淡出乘加与权重检查。FFT 折算输入点吞吐 2.016 M 点/s，不是 FPGA 每秒周期需求。

若共用串行 FFT 引擎，预算式为 6*C_FFT + 15*C_IFFT + C_其他 + C_停顿 ≤ f_proc*512/48000；允许重叠时另做调度图。100 MHz 仅来自现有 BD 配置，对应假设预算约 1,066,667 周期/hop；actual processing_clock_hz 保持 null。不能以此声明实时通过。
