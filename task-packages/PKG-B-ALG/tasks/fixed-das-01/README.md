- run_task.py：运行真实测试、生成独立解析输入与试听 WAV、计算已知分量功率指标、保存来源/环境/哈希。

这是独立 NumPy 原型，无硬件或 scipy 依赖。六麦坐标沿用已验基线，48 kHz，声速假设 343 m/s。方向为阵列指向声源的单位向量，x 前、y 左、z 上；坐标固定，不能静默接四路数据。

## 延时和有效区间

平面波在通道 m 的相对到达偏移为 `-r_m·u * fs/c`。补偿使用 `d_m = L + r_m·u * fs/c`，本阵列 L 固定为 4 个采样点，以保证补偿不需要未来输入。

令 `k=floor(d_m)`，`a=d_m-k`：

```text
z_m[n] = (1-a) x_m[n-k] + a x_m[n-k-1]
y[n]   = sum_m z_m[n] / 6
```

整数延时跳过第二个 tap。分数延时采用两点线性插值，存在幅频衰减和近似相位误差，并非理想全通延时。本例 +x 指向下，在 300–4000 Hz 内计算的最小单通道插值幅度约为 -0.191 dB；它不是对所有方向的总波束频响保证。

相对阵列中心理想信号的公共延时约 4/48000 秒，即 0.0833 ms；这不是程序实测延迟，不包含采集缓存、块等待、定位或跟踪等待。最大历史长度随方向为 7 或 8 个样本；本例为 7。前 history_samples 个输出带 valid=False，零历史初始化只服务处理器启动，不能当作有效观测评分。

输出采样编号对应当前处理时间；对应源中心时间近似为编号减 4。输入 N 点即输出 N 点，不自动 flush 尾部，因此末端延迟后尚未到输出的源样本不会被补出。有限录音末尾必须在比较中排除，本例使用相同内区间 [256, 143744)。后续若需要完整文件尾部，另行明确延时尾部输出约定。

**不要把重叠的 1024 点定位帧逐帧送进此处理器。**定位可以每 512 点更新一次，但音频每个采样只能输入一次；本例每次送 512 个新采样。重复、跳号或倒序会报错；收到实际间断后，由调用者记录间断并显式 reset，不把缺口补零伪装连续。

## 如何运行和调用

从本任务包目录，使用 Python 3.12 / NumPy 2.3.5：

```powershell
python -B run_task.py --out evidence/my-run01
```

输出目录必须不存在；不要覆盖已经交付的 run01。所有原输入和输出的规范 float64 SHA 记录于 metrics.json，源码和默认模块哈希记录于 run.json。试听 WAV 使用共同增益并量化为 16 位，六通道 WAV 是试听副本，不是浮点输入的精确替代；准确浮点输入由 run_task.py 中的解析源生成器重建。本任务没有跨环境严格输入复现的验收声明。

最小调用例子（在本目录导入模块）：

```python
from fixed_das import FixedDAS
beam = FixedDAS([1.0, 0.0, 0.0])  # 固定朝正前方
y1, valid1 = beam.process(samples_time_by_six[:512], first_sample_id=0)
y2, valid2 = beam.process(samples_time_by_six[512:1024], first_sample_id=512)
```

一个实例只服务一个固定方向的连续区间。当前没有更新方向 API；调用 reset 会重新启动有效性预热。自动跟踪、方向切换和未锁定/HOLD/失锁的音频策略留给下一任务实现，不能通过偷偷修改对象内部方向来代替。

## 实测开发结果

- 8 项新增测试通过。1024/512 等各种块划分与整段处理逐值一致；例子中 137 点和 512 点块输出也逐值一致，排除由分块本身引入的接缝。
- 本例为 3 秒六通道解析平面波，目标来自 +x、干扰来自 -x，两者都是多音合成信号，不是自然语音，没有房间反射。
- 固定取 mic0 作为单麦参考，共同延时 4 点后与 DAS 输出对比；无分别归一化，全部 WAV 用共同增益 0.2965853682443831。
- 在共同有效内区间内，单麦目标/干扰功率比约 0.00008 dB，固定指向后约 2.73168 dB，改善约 2.73160 dB。
- 目标和干扰分量分别通过相同线性处理器，用于计算已知分量功率，另验证两者输出之和等于混合输出（浮点容差 2e-15）。这不是从混合录音盲估 SNR，也不是独立验证集性能。
- 两路输出均 144000 样本、48 kHz；写入前共同缩放，峰值不超过 0.8，不发生 PCM 削顶。原默认模块 5 个源码哈希在运行前后相同。
