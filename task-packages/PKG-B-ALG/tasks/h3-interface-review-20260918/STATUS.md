## 当前可先评审的最小模块

**四路纯分帧适配合同与golden**：输入已校验32字节组，输出4×1024原PCM及描述符，hop512，跨包/跨槽，错误/重启切段，不加窗、不估角、不修改PDM/CIC或DMA包长。A可批准该合同用于下一步PS/PL候选实现；本次没有可直接下载的适配器，不申请实际工程接线。

其实现最低验证仍缺：真实ready/valid背压稳定、缓存满/消费者超时、槽提前释放/重用、CDC和复位交错、晚到FFT状态使帧原子失效。离线槽回放测试只覆盖复制与索引，不代替这些测试。

下一最小链可考虑整数窗→已准配置前向FFT诊断；必须先裁决默认25或研究29、核对实际IP输入码与状态映射。PHAT/IFFT/DOA/存在门/DAS及板端输出均暂不准入生产链。

1. 最终四路数制/共同指数或固定4路线、epsilon与缩放绑定、AMD逐级golden尚未冻结验证。
2. 完整帧适配器、FIFO/CDC与输出包硬件ABI未实现/评审；本包INTERFACE为提案。
3. 每模块最坏周期和有界背压/内存争用预算缺失，不能证明持续实时。
4. 存在门缺独立活动标签验证；位置/声学收益缺可信真值和参考；S1不能填补。
5. 实际板端输出硬件、端到端计时、欠载/复位恢复与整机资源/时序未验证。
