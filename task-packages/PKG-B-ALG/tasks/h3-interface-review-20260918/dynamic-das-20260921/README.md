## 动态控制合同与明确代价

1. PCM 输出索引为物理 emit 时钟。源样点 n 在 n+8 输出；每次 push 处理收到的样点。启动前 8 点为 0，final 显式冲出尾部 8 点，只有录音真实边界外补 0。
2. 延迟界 ±8 样点。插值系数为 0 时不读取右邻点，因此恰好 −8 的延迟不再额外要求第 9 点。PCM 历史最多 17 行，每行四路；这取代前一独立固定延迟候选的保守等待方式，但不修改旧文件。
3. fresh 控制必须给合法四延迟及未过期整数 valid_through。HOLD 不改方向/截止时间。过期判断为 emit > valid_through；同一时刻的新控制先处理，再判 TTL。原 tracker 的 ready、valid_through 均加 8 映射到 emit 时钟。
4. 480 样点淡变期间不再开启第三个波束：最新请求覆盖 pending，当前淡变完成后才使用仍有效的最新请求。已有方向重复 fresh 只刷新 TTL。两个波束端点加单麦足够，无无限增长的波束缓存。
5. **这是新策略，不是旧立即重定向语义的逐码替换。** 稳定存在的新请求等待下一次淡变起点不超过 480 样点；再经 480 样点完成。期间可能被更新请求覆盖，不能保证每个请求都会执行。
6. **TTL/SEARCH/STOP 触发回退后，旧波束仍可在有限淡出期有权重。** 串行策略最坏需 960 样点完全回单麦（48 kHz 为 20 ms），而不是 TTL 当拍立即归零。STOP 在此只是音频平滑回退请求，不是采集紧急停止/事务撤销。若 A 要求更短截止或硬停，本候选不可直接采用，须另改优先级并增量验证。未隐瞒为已满足旧合同。
7. 调用者必须在控制可用时刻处分块；同 emit 重复控制拒绝。没有跨 session/interval 身份管理；新 session 应实例化新对象，不能把此对象代作生产事务握手。元数据与时钟上界由 A 集成合同约束。

动态检查包含 32 组事件×分块对照、18 个端点/短记录、800 次密集更新、17 个小淡变停止偏移、两项未来控制/PCM不影响过去的反例，以及非法状态/TTL/延迟/PCM检查。数学 PCM 不是新声学模拟或录音；没有听感/音频收益结论。

## 延迟 ROM 的来源与边界

固定 40 mm 方形坐标 (0,0),(1,0),(1,1),(0,1)，48 kHz、343 m/s，角度域 [-180°,180°)，1/256° 步进。以长常量 π、四分之一周期 Decimal Taylor 级数和象限对称计算；60/90 位独立精度运行一致，最近半码距离约 8.80518e-6 码。不是调用旧 sin/cos 生成期待值，也不把两种精度一致叫形式化超越函数误差证明。

最大绝对延迟码 32,425，三路非零参考延迟均可由 S16F12 存储，mic0 隐含 0。完整 ROM 净载荷 552,960 字节（540 KiB）；`.npy` 另有容器头。运行入口严格验证 SHA、类型/形状与规范角度，不在运行时生成浮点三角。+180° 需上游明确规范化，不能静默接受越界码。

## 位宽结论及限制

详见 `validation/portable01/widths/widths.md`：拒绝前 xy **S23F20**；LS 缩放分子 S37；预测分子 S46；残差平方和 U35；模平方 U43；CORDIC xy 保守 S25、角累计含象限偏置 S26、角输出 S18；DAS 四路加权和 S38、双端点淡变和 S36。

分析为全输入区间包含关系，DOA 按固定子集先合并线性系数再取界；不是拿测试最大值当证明。PHAT 用 S51 互谱容器保守域，补全 mask、开方比较、两轮 Newton 乘积与归一化乘积界；FFT 表仅为每级饱和后的有界输入提供乘/加/舍入前宽度，**不证明所有输入均不会溢出**。RNE 除法实现须为余数翻倍/进位另保留位，不能只抄最终商位宽。

旧表保守 S42/S43、U104 等仍可使用，本表较小界不是自动缩窄部署授权。除法器内部结构、IP scratch、DMA/地址/session计数器、实际缓存布局/资源及时序仍由所选实现决定；错误输入必须先验证，域证明不是原函数已经拒绝全部畸形值的证据。CORDIC 位宽可容纳不代表其全域角度误差已证明，小向量原缺口仍保留。
