# 给 A：正式证据缺口的最小输入操作单

现八段已接收，不要求重录它们。以下是正式方向/音频证据所需的**条件化最小试验**，先核对现有设备能否提供同步重复播放和完整留存；不默认采购、改工程或要求 C 参与。若条件不具备，回报具体缺项即可，9/23如实保留未通过。

## 共同条件与每段内容

- 固定四路原始编号/flags/BIN/UART/metadata和原增益；不逐路归一化，不拼独立Run。当前6秒完整留存能力可用，不要求新连续一小时方案。
- 保持阵列、目标/干扰扬声器、音量和环境不动，记录实际坐标及测量工具/不确定性。目标距阵列中心约1.5m、同高；mic0与中心不同。目标0°，干扰+60°作为这张操作单的预设试验场景，不代表已有真实坐标。
- 每段约6秒：保留标记/稳定时间，使用未参与本轮设计的固定约2.4秒目标语音；建议播放源语音区间1.0～3.4秒，标记与正文分开，尾部留静置。实际阵列声学活动边界由参考/标注确定，不照抄播放时刻为真值；混响未退尽的尾部不叫纯背景。
- 保存播放源、触发/回录时间、重复方式、关闭或未知AGC/DSP项。若两台独立手机自由运行且无法对齐/证明稳定，不能承诺分量参考可用。同步电信号回录只提供时基，不直接提供阵列处干净声音。

## 音频分量：先做6个完整Run，不泛泛“再录一批”

固定上述一个场景，以两次独立启动重复下列三种，每种保留完整四路BIN：

|Run类型|目标|干扰|用途|
|---|---|---|---|
|T-only×2|相同固定语音|关|阵列处目标响应与重复性|
|N-only×2|关|固定非同源干扰|阵列处干扰响应与重复性|
|T+N×2|相同固定语音|相同干扰|真实混合响应、叠加/时基/AGC核查|

目标/干扰必须可重复并时间对齐；仅“播同一文件”不足以证明跨Run波形相同。B核对源时基、重复传递变化、底噪以及 x_mix−(s_T+n_N) 残差，传播参考误差到收益区间；不把时间拟合后的残差隐藏掉。T-only仍含环境底噪，N-only同样如此，二者直接相加会重复计底噪；需利用段前暂停区估计随机底噪/误差，不能简单逐样本扣除独立随机噪声来造干净参考。

只有上述稳定性/同步/残差足以支持目标与干扰分量时，才按 FORMAL-EVALUATION.md 报附带参考不确定性的收益。若不成立，6段仍可用于三路诊断和主观对照，正式SNR仍不可测；可另外把分离实录数字叠加，仅能证明“数字混合真实分量”场景，不能冒充真实同时播放收益。近讲目标麦可辅助活动标注，不等于阵列干净参考。

这是最小分量可行性试验，不保证现有播放设备满足正式指标，也不新增固定残差阈值作为阶段门槛。请先回报播放/同步能力，B据实际可测参考决定是否值得执行。

## 方向最小补充

上述两次T-only提供0°初步重复。再加−45°和+45°各两次独立Run，共4段；目标位置需实测，方向/时间真值及不确定性与原始数据一起交付，背景/暂停时段保留。合计最多10段、约60秒原始数据，足以先判断参考链和失败类型，**不是宣称两次/角度已足够泛化P95验收**。若已有满足这些条件的未用材料，优先引用，不重复录制。

正式活动评分需独立标注：结合同步近讲参考（仅用于活动）与阵列波形，记录起止不确定区，排除标记和混响边界。数据在算法冻结后收集并保持评估隔离；若B再据此调参，立即降为开发集，另设真正未参与设计的数据。最小试验数量不替代原定正式判据。
