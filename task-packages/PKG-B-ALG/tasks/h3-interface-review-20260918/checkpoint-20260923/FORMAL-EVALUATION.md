# 正式评价合同与当前缺口

当前八段只能开发诊断。原始目测0/±45°和≤5cm估计不作为精密真值；源映射起止、200ms掩码不等于阵列处语音活动真值。现有结果中的 nominal_deviation 不更名为正式角误差。

## 方向

预先登记每个独立Run的场景、阵列中心相对mic0平移、声源位置、活动区间和时间不确定性。用坐标测量得到方位 θ=atan2(y_source-y_center,x_source-x_center)，报告测量工具及δθ；粗略位置界δr/r的角度界可辅助，但不能把估计当已校准误差。声源嘴部/扬声器声学中心的偏差单列。共面阵列只能在明确水平假设下评价方位，不签仰角。

只把完整1024样点位于已确认活动内、且不与标记/保护/混响不确定区相交的帧纳入真值评分。提前固定边界处理和错误方向容差τ，不能按评分结果改。当前诊断 τ=15°只是公开的描述阈值，不是更改原阶段准入阈值。100/200/300ms敏感性是开发观察，不从三者挑最好的冒充正式标签。

令 N 为所有符合评分区间的计划输出时刻，包括拒绝；V 为 fresh_valid 输出数，不以 stale/HOLD 填补；W 为 V 中误差超过τ的数。误差 e=|wrap180(θhat−θ)|。

- P50/P95 在 V 个有效误差上计算；V=0 时为 null，不报0°。
- 有效输出比例 V/N；拒绝比例 (N−V)/N，两者同时报告。
- 错误指向比例 W/V；同时报 W/N，防止通过全部拒绝美化错误率。V=0时W/V不可定义，W/N=0不能表示算法正确。
- 有界真值误差时给出每帧误差区间 [max(0,e−δθ),min(180,e+δθ)]，相应分位数上下界。阈值跨界者列为不确定；活动边界不确定同样单列排除数。现八段δθ未知，所以不能计算可信正式上下界。
- 按Run、角度、背景条件分别报告，重叠帧不是独立试验。不能把同一长Run的几百帧当几百次独立观测；置信区间如需估计按Run重采样，只有两次Run时明确证据弱，不捏造泛化区间。

当前方向估计数值通过≠目标锁定。声音活动、语音类别和目标身份是三个不同判断；只有后两者及空间/任务条件明确才可称目标存在。C3没有语音分类或说话人身份能力。

## 音频

同一四路输入 x、同一mic0参考时间、同一输出增益，比较单麦、预先指定手动方向、因果自动方向。自动控制只由混合输入生成，禁止向前回填角度。当前软件共同延迟8样点、计算延迟假设0，不是实际整机延迟。

若有可信阵列处同步目标分量 s_i 与干扰分量 n_i，并满足 x_i=s_i+n_i+已量化残差，对同一混合输入生成的固定时变控制 L_b 分别作用到分量：s_b=L_b(s)，n_b=L_b(n)。**不能对分量重新运行自动方向/门，否则改变被测系统。** 固定共同mask M 后：

SNR_b=10log10(sum_M s_b² / sum_M n_b²)，ΔSNR_b=SNR_b−SNR_mic0。

同时报告目标传递增益10log10(E_s,b/E_s,mic0)、输出削顶、共同延迟、有效时长、拒绝/回退占比和残差。降低目标幅度与降低噪声不是同一回事。手动对比单麦反映给定方向下波束算法限制；自动对比手动反映门/方向/跟踪/切换的额外影响，不能把二者混成单一“增强收益”。

source/reference_metrics.py 给出固定尺度分量公式，合成正交噪声测试得到理论6.0206dB，只证明公式，不是当前实录收益。播放源WAV、近讲麦或另一位置的参考未经声学传递验证均不能替代 s_i；严禁用任意增益/时间拟合把混响阵列信号当干净目标。当前 ΔSNR/SI-SDR/清晰度提升一律 NOT_MEASURABLE，试听待用户反馈。

若要评价目标失真，需同一阵列参考与已验证时变处理的基准；没有相应参考时只报告波形差、谱/幅度变化、削顶和主观反馈，不报虚假指标。
