## 必须反馈 A 的数制修订事项

当前合同曾将xy列为S22F20候选。S22码范围[-2097152,2097151]，但各pair时延分别合法仍不保证彼此符合一个声源：656个顶点中8组的拒绝前xy超界，最大绝对码2531477。

对固定方形几何和每对合法Q12时延范围，每一分量在每个有效pair子集内是线性最小二乘解再RNE；RNE单调，故各输入区间顶点给出该分量全盒的极值。这一分析支持**拒绝判断前xy至少S23F20**。残差/范数通过后的分量因范数≤约1.3可容纳于S22，但不能先收窄再做拒绝，否则会改变判断。原Python宽整数没有此硬件截断问题。

范围结论不覆盖新的几何、非法tau注入、LS乘积/分母/CORDIC中间寄存器。那些仍须逐项推导，不能由“xy用S23”直接宣布整级位宽冻结。此次只记录合同修订建议，没有修改原证据或实际RTL。

## CORDIC小向量缺口

atan2_q8(±1,0)返回±25570码，理想±23040码，差2530码（约9.883度）。很小的整数向量在迭代算术右移后失去有效位。现有DOA范数门不允许这样的向量成为有效方向，因此不是已证明的正式输出错误；但通用atan2接口没有声明或强制最小数量级，不能任意复用。

本轮不静默改CORDIC迭代或前置放大。后续若要通用接口，需要确定输入归一化/保护及其独立测试；当前报告只批准已测数量级的离线结果。

## 跨块差异与候选含义

原das_block是单块模型：超出本块的索引补0。将97点数学PCM夹具按13点切块逐块调用，会在人工块边界丢掉相邻样点；四组延迟合计159个PCM码不一致。这不等于原整段渲染错误，也不等于实录已有159个断音。

stream_das.py的StreamDAS保存必要历史，并在负延迟需要未来数据时延后产出。它只支持固定四路Q12延迟，范围±8样点，严格S24输入；四种chunk长度1/7/13/64均通过。流末显式flush时才以0补实际记录之外的尾部。

候选为保守访问额外保留一个样点，lookahead依延迟最多可到9样点。**不能直接称它满足旧固定8样点可用延迟合同。** 本轮比较最终PCM，不批准输出时钟/延迟ABI。缓存还包括本次输入chunk，不把历史长度当总缓存上界。

未覆盖：变化方向、HOLD/TTL、同时多beam、连续重定向权重bank数、有限ready服务、stream reset的工程接口、真实输出介质。新候选不替换旧因果混合器或run05，不把固定延迟测试当全部动态路径通过。
