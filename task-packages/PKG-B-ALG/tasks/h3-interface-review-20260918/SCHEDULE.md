# 缓存生命周期、复用调度与最坏预算

N1024/H512/48kHz，窗口21.333ms，hop10.666667ms；100MHz下严格整数预算上限取1066666周期/hop。原始32字节组1536000B/s，纯int32 PCM768000B/s；不能漏掉ID/flags后按一半输入流量估计DMA。

## 候选调度（尚无集成实现）

1. DMA完成→校验/复制→释放RX；组进入四路帧缓存。形成完整1024帧后附描述符进入READY，保留512重叠；不能等待FFT一直占用RX。
2. 同帧四路依次FFT，所有路状态正常后再做PHAT；如走共同指数研究，必须等待四路最大值屏障并附同一指数。本版portable候选固定右移4，不假装已有自适应屏障。
3. 六对依次互谱/PHAT→补共轭→IFFT→lag；一对缓存只在其lag结果已复制后复用。所有pair状态齐后DOA/跟踪，最后按结果包规则原子提交。
4. DAS和输出缓冲与方向事务分离，使用已可用且未过期的方向；reset/gap立即作废旧TTL。消费完单声道hop才释放其缓冲。
5. 29位前向和25位逆向是两种归档IP候选；不能假设一个IP可运行时切宽。可选双核或统一位宽重新验证，但本包不选择或生成IP。

## WCET结论

历史槽：4×7366+6×7406=73900周期（配置100MHz算术0.739ms），剩余992766周期只是一条预算差值，不是可用算力证明。不存在已实测完整WCET。

`T_total = 4*Tfft + 6*Tifft + Twindow + Tphat + Tlag + Tdoa + Tdas + Tcopy + Tconfig + Tstatus + Tstall + TCDC`

实时准入需证明每项有限上界且总和<=1066666周期，并给队列容量/最长服务延迟/持续突发条件。Tphat开方除法、DOA角度、DAS、DDR争用、配置切换和背压无可信周期上界，**当前total=null / REALTIME_BLOCKED**。外部ready若无服务上界则理论最坏等待无穷，不能宣称满足hop。

本包实际重算仅调用未改的上游budget.calculate，冻结输出golden/budget.json并核对。50ms/8样点/10ms淡化等数值不能替代全链延迟；5帧捕获最早64ms只是收集时间，不含处理和输出。
