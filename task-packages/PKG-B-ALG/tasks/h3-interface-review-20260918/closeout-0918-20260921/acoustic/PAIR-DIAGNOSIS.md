# 自动回退的连续帧诊断结论

本轮完成“137个捕获帧及其相邻帧的六对相关峰/时延/残差分析”。来源固定为 B `fe67547635ff254f9f91c7f917e8dedb6daf3363`。未改变待审代码、研究阈值、几何、录音或输出音频；这不是新算法通过或9.18完整验收通过。

## 结论先行

自动输出一直回退单麦，与现有跟踪规则一致。更直接的阻断在时延候选和跨帧稳定性：**并非只因活动门太严格，也不是有锁定却未送到音频端。** 关闭活动门的既有 ungated60 分支同样没有 fresh；当前分支最高捕获计数3，尚未达到5帧且两两角距不超过8度的条件。

六对独立取峰所得时延经常无法共同解释为一个方向；部分单帧虽通过几何检查，下一帧的峰发生变化，方向就大幅跳动，捕获重新开始。物理原因尚不能从这些结果唯一判断：混响、多分量竞争、通道固定时延/标定、频带信息不足都需要针对性证据，不能本轮直接归咎于某一项。

## 为何已有137个候选仍锁不上

发现27次捕获离散度重启，全部伴随相邻帧至少一对整数峰位置变化。新方向相对于当前捕获历史的最大角距：P50=20.7449度、P95=73.7914度、最大85.1377度，超过现有8度条件。整数峰变化是伴随证据，不等于“每次取峰变化都错误”，亚采样、有效pair集合和小范数也会影响方向。

一个可直接复查的连续例子：`trusted_p045_20260920_01` 的第232→233帧，起始行为118784→119296，相隔512样点/10.667ms。两个单帧均有6个合法pair且都通过投影，但方位从−32.5239度变为+52.6138度；捕获必须重新开始。

| pair | 第232帧时延/样点 | 第233帧时延/样点 |
|---|---:|---:|
| mic0–mic1 | 1.219 | 1.342 |
| mic0–mic2 | 0.160 | 2.794 |
| mic0–mic3 | −0.314 | 1.113 |
| mic1–mic2 | −0.943 | 1.606 |
| mic1–mic3 | −2.995 | 0.668 |
| mic2–mic3 | −2.043 | −1.255 |

5对整数峰改变，最大时延变化3.6622样点。残差却从0.4401降至0.2303样点，说明“单帧拟合残差更小”不等于跨帧方向稳定。两帧范数约0.340/0.347；向量较短时同等时延扰动可对应更大角度变化。范数偏小不能单凭平面模型断言声源方向错误，实际高度/三维分量和声场信息未充分确认。

## 相关峰质量与符号检查的边界

137个捕获帧共822对：777对VALID、39对有效bin不足12、6对TAU_BOUND。其余合法pair足以使这些帧通过现有投影，不能把局部pair失败误写为整帧全部失败。

分离竞争峰margin（排除主峰±1样点后比较）在捕获组中位数0.0586，邻近投影拒绝组中位数0.0722。**本批统计不支持直接用更高的单对margin门槛来解决问题**：拒绝组并没有简单地表现为更低margin；需要多对关系与时序证据，不能只追求更尖的单峰。相关搜索曲线、全局峰位置、物理边界、循环时延闭合差、逐对拟合残差都已保存，未新增门槛。

源码互谱为 Xi·conj(Xj)，配合 `(position_j-position_i)·u/c` 的符号关系在数学上相容。统一翻转所有时延或镜像坐标只会映射方向，不会改善上述残差/范数拒绝；代数检查已覆盖298帧。因此**不能靠统一改正负号关闭主要投影阻断**。这不等于实物接线/通道顺序已校准，任意接线错配或固定通道延迟仍未被本轮排除。

1. 保留原PHAT与5帧/8度规则。先在已选择的连续片段上研究“多对时延联合一致性”的候选选择：同时记录合法候选、闭合关系、投影残差和时序连续性，不能只逐对选最高峰后放宽跟踪门。
