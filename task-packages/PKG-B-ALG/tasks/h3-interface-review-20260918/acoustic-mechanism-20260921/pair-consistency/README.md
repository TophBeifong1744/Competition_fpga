# 多对局部峰闭合候选：未恢复锁定，不采用

2026-09-21。沿 acoustic-mechanism-20260921 继续，复用同一冻结320帧相关曲线。独立选择偏向原137捕获锚点及邻帧，不含背景覆盖，不能当完整八段候选验证或独立验证集。

候选固定为：保留原有效pair集合与原峰亚采样值；补充合法物理范围内的内部局部峰，每对最多3个；穷举组合，以原峰高均值选取通道差闭合RMS≤0.5样点的最佳组合；精确同分拒绝。**选峰时不按几何范数、允许方向或标称角度加分**，随后仍执行原平面残差≤0.5、范数[0.1,1.3]拒绝。截断曲线端点之外没有邻点，因此不虚构其亚采样次峰。未改PHAT、Tracker、阈值或原录音。

## 结果

- 320帧中22帧有效pair不足；其余298帧中281帧完全没有次峰，仅17帧存在至少一个备选。
- 原单帧投影有效186，新候选187；只改变1帧，无原有效帧丢失。
- 77帧找不到闭合合格组合；34帧仍被平面/范数条件拒绝。
- 唯一新增放行位于 trusted_000_20260920_01，start=120320、非标记帧：改选1个pair后闭合RMS从3.0718降至0.1920，平面残差0.2675，方向却为−107.381°，仍在±60°范围外。相对录音0°标称方向偏离很大，但标称角度不是精确真值。
- 所选320帧的“投影通过且在±60°内”布尔值完全不变。故仅在这批选择帧替换候选，不能为原跟踪器增加可捕获输入；未声称对全八段执行了此候选或完成新的背景误锁测试。

**不采用此候选。** 不能把闭合变好、增加1个单帧输出叫定位正确或锁定改善。大部分曲线在合法窗口内没有次峰，说明当前已存曲线上更换局部峰的可用空间很小；不证明窗口外、其他频带或其他场景也无备选。
