# 联合方向辨识力：异向解也能保留接近最优的分数

2026-09-21，作者诊断。前置提交3ea70b035de62ddff691330aea288d111af3f0e8。本轮沿用joint-arrival，未修改任何已有算法、阈值或输入。原证据保留。

## 固定方法与覆盖

同一191个非标记、六对全有效的偏置选定目标帧；同一0.25采样/57489点图到达差网格及原归一化相关目标。复用并校验旧源码SHA，逐帧匹配前轮最优tau、分数和几何有效状态，191帧全部通过。FFT/IFFT均0，不新增声学模拟。

仅对前轮最优解几何有效的178帧寻找竞争者，竞争者也必须满足原平面RMS<=0.5、norm在[0.1,1.3]，与最优解圆周角距离>=15度。15度来自checkpoint原诊断尺度，本轮运行前固定，不从结果挑阈值。搜索整个方向圆周，不使用标称目标角度或允许范围筛选。13个原最优无效帧保留无效，不改选次优作为恢复；分录音/逐帧结果含norm和残差。

分差=最优分数−竞争者分数；相对降幅=分差/最优分数。不设置“接近”判定阈值，不把分差变成捕获门限、概率或校准置信度。该离散网格比较不是连续角分辨率证明。

## 结果

| 按原闭合状态分组 | 不失败组 | 失败组 |
|---|---:|---:|
| 总帧数 |143|48|
| 联合最优几何有效/无效 |137/6|41/7|
| 有>=15度有效竞争者 |137|41|
| 相对得分降幅Q25/中位数/Q75 |0.105% / 0.192% / 0.359%|0.084% / 0.418% / 0.768%|
| 竞争角差中位数 |18.435度|16.144度|

前轮“41个失败帧恢复几何有效”的候选同样存在高分异向解；较高相关支持和强制闭合不能提供方向唯一性。原不失败组也如此，不能只挑恢复帧批评或把分差单独当真假标签。没有独立真值、背景对照和完整时间线，本结果不证明这些竞争方向正确，也不证明最优方向错误，更不能量化锁定性能。
