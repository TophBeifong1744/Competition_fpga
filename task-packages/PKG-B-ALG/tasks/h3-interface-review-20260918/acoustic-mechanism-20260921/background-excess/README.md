# 前背景参考的频率增量：有信号差异，仍未恢复锁定

2026-09-21，作者离线研究，非正式验收。沿已有acoustic-mechanism任务继续；本轮扩展至八段**全部4488帧**，不再只在320个选定目标帧上试候选。全部录音此前已查看，仍是开发/开发探针，不能改称独立验证集。

## 固定方案及防泄漏

只用 trusted_bg_pre_20260920_01 的561帧建立四通道各bin的功率95百分位参考N95。采用与原DOA一致的未去均值Hann1024频谱；不是挪用gate去均值频谱。后背景、目标录音和标称角度均不进入参考或参数选择。前背景本身属于标定内检查。

每通道权重为 `clip(1-N95/P,0,1)`，每对取两通道权重的几何平均，再乘原7..85bin、2%幅值mask。原PHAT除数epsilon保持；增加“正权重bin至少12”的候选保护。原活动门、原5帧/8度捕获、±60度范围及HOLD规则不改。没有扫percentile、比例或捕获门限。

参考写入pre-noise-p95.npy并绑定SHA，执行结束核对未变。权重只是当前谱功率相对记录背景的增量估计，不是已证明的干净目标功率或SNR；不能当语音/身份识别。

## 实际结果

| 范围 | 原几何有效 | 新几何有效 | 新增/损失 | 最终fresh |
|---|---:|---:|---:|---:|
| 前背景561帧 |242|0|0/242|0|
| 后背景561帧 |458|37|1/422|0|
| 六目标录音200ms保护区，共440帧 |202|171|19/50|0|

这里“几何有效”统计在活动门之前，所以202不等于前轮**活动门之后**的174。目标440帧仍是候选评价区间，不是440帧人工真值语音。100/200/300ms和全录音分别留存。

背景几何输出700→37，但原校准活动门本来就是0背景放行，本轮仍为0；这不能写成系统误报率从700降到37。后背景残留37，说明前背景参考不能自动消除之后的全部变化。

目标200ms区间“活动且允许方向内”为89帧（原87），但完整时间线最高捕获计数仍只有3，八段全部0fresh。新增两个可捕获输入不等于正确方向或稳定性改善，不采用本候选替换默认链。

三路以上超过前背景参考的bin数中位数：前背景1、后背景3，六目标区间各24–30；达到4倍参考的bin数中位数：前后背景均0，六目标区间11–15.5。说明在这批录音中能观察到背景之外的谱功率，但没有证明这些信息足以恢复一致时延。加权后的每对有效bin数中位数约12.7–15.6，仍接近最低支持要求，不能从权重较大就推断角度可靠。

## 结论与后续边界

“相对前背景的增量”比绝对相位高一致性更能表达这批录音中的活动变化，但该固定谱权重仍损失较多原有效帧，没有关闭9.18锁定要求。停止在同一数据上连续调小门限或只选择好例子；本轮作为负结果入库，不宣称性能改进。

接下来应结合全帧残差/方向失败证据与A现有通道映射、坐标/源高度、固定延迟依据，优先明确哪些输入/几何前提可被证实。若继续新算法实验，需先给出能区别于上述负结果的具体机制及固定评估条件，不直接扫一组新权重。现有资料缺口一次交A，本轮不给C新增录音任务。
