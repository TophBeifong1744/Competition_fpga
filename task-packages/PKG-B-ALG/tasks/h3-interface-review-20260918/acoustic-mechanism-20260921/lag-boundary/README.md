## 覆盖和结果

- 全部4488帧的逐对拒绝原因可用：63帧含 TAU_BOUND，共71个通道对；其中背景14/1122帧，目标非标记区33/2724帧，目标标记区16/642帧。
- 目标非标记且活动门通过536帧，其中16帧含 TAU_BOUND。这里是全录音非标记区，不是之前440帧的200ms目标候选区，不能混用分母。
- 闭合残差缓存仅覆盖1122背景帧和此前偏置选出的320目标帧（原捕获输入及邻帧），不是全4488帧闭合统计。1420帧有可计算残差，303失败，其中295不含 TAU_BOUND。
- 选定目标非标记237帧中222可算闭合残差，53失败，**53全部没有 TAU_BOUND**；背景225个闭合失败中219也没有 TAU_BOUND。
- 整数搜索边缘峰缓存只覆盖320目标帧：1739个有峰值证据的通道对中16个贴边，其中12个 TAU_BOUND。非标记子集1293对中9个贴边、6个 TAU_BOUND。贴边不等于越界，也不能将两种计数互换。

因此，“原候选因越界被拒”并不伴随大多数已观察的闭合失败；目前没有依据把直接放宽窗口作为首要修复。该观察不是扩大窗口实验，不能证明窗口外不存在另一个峰，也不能否定未缓存帧或未来校准的价值。TAU_BOUND 的 tau 数值不得当有效对参与拟合。没有缓存/无法拟合的残差仍为 null，不计为通过。
