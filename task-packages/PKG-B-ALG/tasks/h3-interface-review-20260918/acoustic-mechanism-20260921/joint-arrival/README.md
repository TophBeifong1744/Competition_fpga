## 固定方法

只分析原缓存非标记且六对全部有效的191帧，沿用此前相同支持集合。mic0到达差固定0，其余三路采用固定0.25采样网格，要求六对全部在原连续合法范围内（距离*48000/343，加原peak合法性容差0.05）。共57489个合法网格点。未改变物理范围，不取窗口外信息，不保留原已拒绝通道对。

对缓存整数相关值作线性插值，每对除以其原整数最大峰高，再取六对均值最大值。非正/非有限峰高拒绝。目标函数不含标称角度、允许方向或平面残差；并列按网格字典序首项，不把并列解称唯一方向。固定网格穷举，不是连续全局最优证明；三维图到达差自由度不同于二维平面方向。

随后用原平面投影矩阵及RMS<=0.5、norm在[0.1,1.3]诊断几何有效性。未做活动门/方向范围/跟踪回放。图残差约0是参数化构造的必然结果，绝非额外通过证据。相关支持比以原整数峰为分母，不是SNR、概率或性能提升。
