# 固定频带诊断：不采用单子带或固定删带

2026-09-21，作者诊断增量；沿同一 acoustic-mechanism 任务继续。原默认PHAT/Tracker/门限与冻结实录未改。

## 设计与实际执行

在读取各帧结果前固定三段：low bins7–32（328.125–1500Hz）、mid33–58（1546.875–2718.75Hz）、high59–85（2765.625–3984.375Hz）。比较full、三个only、三个drop，共7种。

所有变体沿用**full频带计算的原2%幅值mask**，不各自重归一化；保留至少12bin要求及原亚采样/物理界/投影阈值。每帧共享同一四通道前向谱，只改变保留的bin。窄带失败可能来自bin不足、峰更宽等，不能宣称该频带物理上没有信息。

输入为冻结320个选定目标录音帧，另加两段背景全部1122帧，共1442帧。背景覆盖是本轮新增；目标320帧仍是原捕获锚点及邻帧的偏置选择，不是整段目标验证或独立测试集。未改门、未重标背景、未使用标称角度选最佳方案。

实际新增5768通道前向FFT及48194个pair逆变换用于本频带对照，不是重跑旧研究套件。full对照1442帧的有效性、pair原因严格匹配归档，角度/范数/残差按既有rtol1e-12、atol1e-10复现；输入BIN/元数据、逐帧文件及源码依赖均核对SHA。没有生成音频或执行AMD/RTL/实板。

## 结果：237个所选非标记帧

这237帧包含15个原有效pair不足的帧，不能与前轮仅222个可分析帧混用分母。表内“范围内”还要求原活动门放行。

| 方案 | 投影有效 | 相对full新增/损失 | 活动且范围内 | 闭合RMS>0.5 |
|---|---:|---:|---:|---:|
| full |146|0/0|106|53|
| only low |134|42/54|60|11|
| drop low |48|11/109|35|29|
| only mid |26|8/128|21|37|
| drop mid |119|27/54|65|37|
| only high |4|1/143|3|6|
| drop high |122|7/31|85|64|

**闭合失败减少不等于方向改善。** 比如only low的闭合失败53→11，但活动且范围内106→60；共同有效的38对相邻帧中17改善、18变差、3不变，角跳动中位数从33.45°到46.59°。不应只用闭合失败数量挑方案。

**drop high没有可靠稳定性收益。** 共同有效61对相邻帧：10改善、10变差、41不变；逐对跳动差中位数0。237帧仅133帧实际删除了原mask中的高频bin，另外104帧不能当有效扰动后的稳定证据。两个独立中位数略有下降不能代替逐对差的结论。

only mid共同有效相邻帧仅3对、only high仅1对；样本缩减后的小数值不是可信改进证据。全320帧及各方案实际bin不足数量、改变有效bin的帧数均另存结果。

## 背景侧副作用

背景1122帧的投影有效数：full700、only low719、drop low582、only mid530、drop mid514、only high222、drop high791。drop high相对full新增203、损失112。full背景465对共同相邻有效方向的跳动中位数约5.94°，可见稳定几何方向不代表目标存在。

冻结校准活动门在背景仍全拒绝，所以各方案“活动且范围内”为0；不是新实现了背景门，也不是证明任一频带方案无误锁风险。没有完整目标时间线的新Tracker或音频收益复验，不宣称恢复锁定。

## 判断与下一步

本轮不采用任一only/drop方案，不推荐更改默认频带。当前证据不支持把问题唯一归因于一个“坏频带”。后续若研究加权，应在共有有效频率上检查相位/幅值与多对时延可信度，预先定义规则，再做原门不变的对照；不要继续穷举带宽并仅报告最好结果。A已有通道/几何资料核查可并行，本轮不给C新录音任务。
