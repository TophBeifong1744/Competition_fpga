## 结论与行动

**背景问题需区分旧默认和已有候选。** 同一1122背景帧中，旧RMS门放行1119；只去DC仍放行1116；绝对频带门放行1122；校准频带持续门放行0。不能再把它统一描述为“当前所有门仍背景误放行”，也不能将开发背景0放行当正式误报率0。前背景被用于标定，后背景虽未用于标定但此前已查看，不是独立验证集。

背景每帧每通道DC功率占比的中位数：前背景约7.96%，后背景约14.62%；去DC后仍大量过门，故“只去DC”不足。校准候选比较的是相对背景频带功率与持续性，不能据此宣称识别了语音或目标身份。

**目标主要阻断在活动门之后。** 六段200ms内缩、排除标记的候选评价区间共440帧：活动门放行370，投影通过174，范围内87，fresh=0。这些区间没有人工逐帧真值，不能称440帧全是目标语音，或把370/440叫正式召回率。100/200/300ms三套保护区与全录音分别留存，分母与旧summary严格核对。

**不采用本轮五帧平滑。** 只取连续五个活动且投影有效的过去方向，失效立即清空，原5帧/8度捕获与±60度范围不改。全八段仍0 fresh；16次前缀截断重放一致。该候选会增加预热，需要连续有效输入，并未修复相关峰/投影断续；不据此否定所有时序估计。

反事实只用于拆阻断：将方向虚拟替换成恒定+X但保留原活动/投影有效性，六段200ms区间可产生57次fresh；若连投影拒绝也假定已解决、只保留活动门，则314次。**这是不可部署的理想干预，不是候选性能、正确锁定数或严格最优性能上界。** 说明继续降低活动门/捕获门限不是唯一也不是当前证据支持的直接修复。

## 新发现：多数所选残差失败无法仅靠静态通道延迟纠正

对既有320帧证据中298个可分析帧，用所有有效pair拟合三个自由通道到达时间差。任意单一到达时间模型都应满足 `tau_ij = arrival_j - arrival_i`（符号与原模型约定一致）；这是比二维平面方向更宽松的模型。原平面矩阵的列空间包含于通道差矩阵列空间，所以可分解：

`原残差平方 = 通道差闭合残差平方 + 额外平面约束残差平方`。

| 范围 | 可分析帧 | 原残差>0.5样点 | 更宽松通道差模型仍>0.5样点 |
|---|---:|---:|---:|
| 既有选择全集 | 298 | 102 | 78 |
| 其中排除标记 | 222 | 70 | 53 |
| 原捕获锚点 | 137 | 0 | 0 |

上述选择来自原137捕获帧及邻帧，**不能推广为全录音失败比例**。7帧没有冗余闭合约束，零残差本身无证明力；非标记子集其中5帧。

给每个通道加任意固定时延，只会给tau增加一个通道差矩阵列空间中的向量，不会减少正交闭合残差。因此所选78帧的独立pair峰不可能只靠静态通道延迟校准、换坐标角度或重新命名通道就满足原0.5样点残差界。更换pair有效集合/重新取峰则是不同实验，不能套用此结论。直接近场传播同样对应一组通道到达时间；结论不排除混响/多分量导致不同pair选中了不同路径，也不证明硬件异常。

**接下来优先研究取峰前的多对联合时延一致性，而非仅平滑输出角度。** 旧平面网格候选把低范数解推到约束边界的负结果仍保留，不能直接复用为改进。下一候选应先满足通道差闭合，保留“无可靠单一到达模型”的拒绝，再评价几何/范围/时序；需同时报告新增放行、错向稳定和背景误锁，不能只报fresh增长。
