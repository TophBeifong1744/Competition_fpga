## 固定定义与覆盖

归一化峰顶曲率=(2*y0-y前-y后)/y0，只对正峰且缓存包含左右邻点计算；边缘峰曲率未知，不能填0。半峰高连续区宽度按离散采样点数记录；触及缓存左右边缘就标记censored，表示窗口内截断的宽度下界，不能当完整FWHM或时延方差。所有统计先按每帧有效对取中位数，再报告帧间四分位数，不将通道对或相邻帧当独立样本。

选定非标记且有图残差的222帧用于描述；主比较限定六个通道对全有效的191帧，保证双方相同对支持及相同闭合约束数。该批是既往137捕获锚点及邻帧的偏置选样，不覆盖全部目标帧，也无独立目标方向真值。闭合不失败不等于正确方向。

## 结果

| 六对全有效 | 闭合不失败143帧 | 闭合失败48帧 |
|---|---:|---:|
| 帧曲率中位数 |0.03131|0.04125|
| 曲率Q25–Q75 |0.02122–0.05196|0.03174–0.05638|
| 窗内半峰宽中位数（含截断） |12点|11点|
| 宽度被截断的通道对 |587/858|202/288|

失败组曲率并未更低，分布重叠明显。不能用本结果支持“峰越尖越可信”的新拒绝规则，也不能反向声称尖峰导致错误。宽度约七成被截断，其11/12点不是完整峰宽对照，不据此确定两组真实宽度排序。完整分录音描述结果已记录by_capture，无阈值扫描、显著性或泛化声明。

222帧全支持混合统计同样为失败组曲率中位数0.04161、不失败0.03115；它仅作覆盖说明，不代替191帧相同支持比较。原53个非标记闭合失败没有因这次描述分析变成有效方向。
