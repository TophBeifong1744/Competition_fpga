# 共有频率相位拟合：不能直接作为目标置信度

2026-09-21。仅作者离线研究。沿本任务frequency-diagnostic同一1442帧（320所选目标录音帧+1122背景帧），不改原门、PHAT、Tracker、几何或录音；不是独立验证集。

## 方法与陷阱

同一FFT帧的 `Zij=Xi*conj(Xj)` 天然满足三角相位闭合；归一化后 `U01*U12*conj(U02)=1`。因此本轮先用任意复谱反例验证该恒等式，**不将相位闭合当质量判据**。这与前轮“各pair独立取峰后的时延不闭合”不矛盾：峰位置是非线性提取结果。

固定原7..85bin、原每对2%幅值mask，取全部六对共同有效频率；至少12个共有bin且原时延足以拟合才评分。保留全部未评分数量，不能将其当零得分。

比较三个时延模型：全零时延、用原pair峰拟合的通道到达时间、原二维方向拟合。评分为 `mean(real(Uij*exp(+j*omega*tau_ij)))`，范围[-1,1]；另固定权重为六对各自按full-band最大幅值归一化后取最小值。不学习门限，不按标称方向选权重，不用逐频率闭合恒等式“增强”得分。

## 主要结果

| 分组 | 总数/可评分 | 通道拟合不加权中位数 | 加权中位数 |
|---|---:|---:|---:|
| 全背景 |1122/1114|0.8502|0.9346|
| 所选非标记、原投影有效 |146/120|0.8675|0.9254|
| 所选非标记、原时延闭合失败 |53/46|0.7158|0.8202|

各分组5%–95%分位显著重叠，原几何有效组不是“定位正确”真值。背景零时延评分也很高：不加权中位数0.7731，加权0.9170。通道拟合相对零时延的逐帧得分增量中位数，背景0.0350、目标录音有效组0.0174，亦不支持把这个增量直接当目标置信度。

幅值加权的有效bin数 `sum(w)^2/sum(w^2)`：背景共有bin中位数32，加权有效数约10.10；目标录音有效组共有23、有效数约9.24。此有效数只是权重集中程度，不等于独立频率自由度。评分上升不是新增信息，也不能证明噪声被抑制。

## 本轮决定

不采用单帧相位闭合、相位拟合绝对得分或这组幅值权重作新的放行/锁定条件。没有声称修好了背景门或恢复锁定。背景高一致性可能来自多种声学/采集机制，**本轮不唯一归咎共模电噪声、串扰或通道接错**；现有标定门背景拒绝结果保持。

不删除零时延/共同分量：真实目标在某些几何下也可能具有小或零时延，数据缺少充分独立真值，不能按此清除。下一轮若继续，应固定只用前背景的参考，检查目标活动期间是否有区别于背景的增量频率信息，并把后背景漂移作为反例；不先猜硬件原因或继续扫绝对置信度阈值。A已有几何/通道资料核查仍可并行，不新增C任务。
