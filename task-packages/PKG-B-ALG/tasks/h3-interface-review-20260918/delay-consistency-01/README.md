## 固定问题与方法

检查当前缓存是否支持把偏差简单视作固定通道对常量。复用已批准320帧缓存中的非标记、六对全VALID子集191帧，六份录音分别描述，不按结果挑通道。以原投影约定tau=(pos_j-pos_i)·u*48000/343，计算逐对tau减名义0/±45度期望的残差；只统计各录音中位数、Q25/Q75及同方向两次中位数差，不拟合、不补偿、不重取峰。

名义方向只是目测描述，不是准确真值；残差含声源方向偏差、空间反射、取峰变化、通道可能偏置及选样影响，不能解释为实测校准值。每对中位数不必构成一个可闭合到达差向量；本轮不对中位数强制闭合，也不把它转成通道延迟。数据均已开发使用，相邻帧不独立，不作显著性或独立性能结论。
