# 单声源方向诊断：现场准备与条件化操作单

来源：用户转述A能力回复，B整理。当前仅支持方向诊断准备，不支持客观SNR收益；不是现在开始补采的指令，不启动旧最多10段方案，不要求C执行。

## 已确认与未知

无已确认合格未用录音；已有八段及旧中心/近场/歌曲材料不构成独立精确真值。确认一台Xiaomi15Pro，可播放/暂停同一WAV、85%音量、可见音效关闭。尺/卷尺实际持有与分辨率、手机固定方式、第二声源、独立活动参考均未确认。采样编号和首尾标记只是候选时基，播放采集同步误差未知。A本次只查资料，无补采、重跑或工程修改。

## 当前只做准备

现场确认尺/卷尺和稳定固定手机的方式，记录工具最小刻度；不要求购买专业设备。若无法固定或无法测量，直接记录限制，不填虚构误差，也不立即开录。B负责提供坐标表和分析，现场人员负责读数及实际操作。

位置表采用阵列中心原点，+X沿mic0到mic1，+Y沿mic0到mic3。记录手机实际发声孔（不是手机中心）相对阵列中心的x/y/z、单位、测量方法、工具刻度、重新读数差异、固定方式和朝向。阵列中心可由现有四麦名义方阵定义，但阵元尺寸误差保留。不要将尺最小刻度直接当总测量误差；对中心定位、垂直投影、读数和固定晃动分别说明。

准备记录模板（未知留空）：
- 操作者/日期：
- 工具/最小刻度/测量方法：
- 阵列和手机固定方式：
- 手机声孔坐标x/y/z及单位：
- 重复读数/误差来源：
- 手机朝向/播放器/实际播放文件SHA核验：
- 采集配置/geometry版本：沿已批准入口，实际值由A记录。

B按atan2(y,x)计算名义方位；只有给出有依据的x/y误差界后才传播方向区间，不能先指定“精确0度”。若误差已接近拟检验方向差，结果仅作粗方向诊断。

## 条件确认后的最小试录（尚未执行）

优先一个位置：阵列中心+X、约1.5m、尽量同高，记录实际读数而非只写目标值；阵列/手机在段内保持不动。沿已有四路6秒完整采集入口和既有播放文件先作一次检查，再在相同设置独立启动第二次；不同时换频带、音量或算法。不以这两次试录验收泛化P95。

每段保留完整raw/BIN、编号、flags、UART、metadata、实际主机版本绑定及播放文件身份；不拼接独立Run、不按方向挑帧。沿已有标记/正文/暂停布局，不要求现场估计精确样本边界；标记及混响尾不当纯静音。操作者只记实际播放/暂停/意外声响，未知时刻注明未知。

两次均先定义为新开发诊断材料：既有算法已多次使用旧播放内容，不把相同内容重录冒充严格独立验证；一旦用来选算法或阈值，更不能转为验收集。第二次可检查重复性，但不是独立性能保证。没有另行明确实施安排之前不要开始录制。

## B收到后的固定检查与输出

1. 复用既有读取器核验文件身份、完整性/flags及配置，不重写采集工程。
2. 输出原默认分支的逐对合法lag、拒绝、方向和原跟踪状态；原帧长/hop/阈值不变。联合候选不作为默认替换。
3. 用波形与试听辅助人工标注确定目标活动核心/明确暂停/不确定边界；标记者先不看DOA或gate输出，保存方法与边界区间。候选标记只用于导航，不能直接制造真值；无法独立确认则仅描述输出、不算正式漏检率。
4. 比较两次录音方向分布和失败类型，给出实际坐标误差限制；不将每对偏差直接估成固定补偿，不报告客观SNR收益。
5. 若单一已测位置仍无法解释方向，先评估是否需要独立声学映射或其他位置诊断，不能自动升级为十段重录。以后正式指标需另定算法冻结与独立评价方案。

成功完成本步是“获得来源清楚、位置可核查的方向诊断输入及可复现分析”，不是保证锁定通过。真实诊断失败同样保留。H3工程线并行推进，不等待SNR参考能力建立。
