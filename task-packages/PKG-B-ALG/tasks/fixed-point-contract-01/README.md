## 3. 两套候选数制

S(W,F) 表示 W 位有符号、F 位小数；U(W,F) 表示无符号。所有项仅为候选，selected_candidate=null。

| 级别 | GROWTH_REFERENCE | SCALED_STORAGE |
|---|---|---|
| PCM | S(24,23) | S(24,23) |
| Hann | U(18,17)，可表示 1 | 同左 |
| FFT 实/虚分量 | S(34,23)，不主动总缩放 | S(25,23)，候选总右移 10 位 |
| 互谱实/虚分量 | S(69,46) | S(51,46) |
| PHAT 实/虚分量 | S(25,23)，可表示 ±1 | 同左 |
| IFFT 内部 | S(35,23) 为宽参考起点 | 未确定，取决于逐级缩放/IP |
| IFFT 相关输出 | S(25,23)，回到 1/N 定义 | 同左，指数必须校正 |
| 时延 | S(18,12)，范围 [-32,32) | 同左，可参数化小数位 |
| 方向、LS 中间量 | null | null |
| 幅值工作区 | null | null |
| 音频权重、alpha | U(24,23)，0/1 可表示 | 同左 |
| 音频通用累加 | S(54,46) 保守起点 | 同左 |

窗乘法先保留乘积再舍入，不能默认低位截断。互谱两个 W×W 乘积先保留 2W 位，再为加减增加一位。模平方/求和/开方的工作位宽不等于互谱位宽，故明确留空。音频 24×24 乘积保留 48 位，最多 54 项累加暂留 6 位增长；实际非负权重和接近 1 可进一步论证缩减，但本轮不做资源承诺。

GROWTH_REFERENCE 用于先把整数舍入点与浮点参考对齐；不意味着全部宽算子都应进入 FPGA。SCALED_STORAGE 降低频谱存储，但总右移 10 位并不能确定每级缩放位置、舍入误差和溢出安全，逐级日程仍为 null。块浮点是可选方向，指数宽度/范围和共享方式未定。

## 4. 物理标度和指数账本

每个级别都应记录 W/F、单位、累计指数、量化点及饱和计数。禁止仅保存 mantissa 而丢弃指数。

若窗口后浮点 FFT 为 X，存储谱满足 Xstored≈2^(-s)X，则 pair 互谱满足 Zstored≈2^(-(s_i+s_j))Z。两个通道指数不同也必须正确处理，不能默认 pair 都有同一缩放。

原幅值保护 1e-15 在该标度下应映射为 2^(-(s_i+s_j))×1e-15。仅补指数仍不能找回量化已丢失的信息；这个保护通常小于一个 LSB，需设计零值与欠分辨率路径并按原判决验证，不得直接替换成“一 LSB 就等价”。输入额外增益的平方也会作用于互谱绝对阈值。

PHAT 理想上对共同幅值缩放不敏感，但低能量量化、2% 掩码、保留频点数和幅值保护会破坏这种简单等价。若改为平方幅值比较，阈值随之为平方关系，而且舍入位置改变，必须专门对照。

原 NumPy IFFT 包含 1/1024。若硬件未归一化逆变换总右移 t，则其结果相对原相关序列约为 2^(10-t)；比较前应恢复标度或映射阈值，二者只能按明确约定做一次。抛物线分母 -1e-15 也必须处于同一相关标度。单凭峰索引相同不足以证明插值时延一致。

## 5. 每帧运算与缓存

每帧 6 次 1024 点实 FFT、最多 15 次实 IFFT；6144 次窗乘；7695 次复数互谱乘法与幅值计算；最多 7695 次复数除实数；207 个物理 lag 峰位置；最多 15 次峰插值、2 次秩检查和 1 次最多 15×3 的 LS。音频滤波按当前实现保守上界 66 MAC/输出点，另计两路过渡混合、alpha 和控制开销。数制改变不会自动减少这些操作数量。

单引擎串行变换的候选周期表达式为 `6*C_FFT + 15*C_IFFT`；每 hop 可用周期为 `Fclk*512/48000`。当前三项均未定，评估结果均保留 null。即使代入数值，也还要计其他运算、流水线、AXI 等待和串并行排程，不能直接判实时通过。

本轮按候选位宽重新计算已确定缓存，不沿用旧“32 位分量”的粗表冒充实际格式：

| 候选 | 位紧凑打包小计 | 元素按字节对齐小计 | 8/16/32/64/128 位容器小计 |
|---|---:|---:|---:|
| GROWTH_REFERENCE | 84551 B | 92572 B | 132837 B |
| SCALED_STORAGE | 75317 B | 84364 B | 100005 B |

这是**不完整小计**：包含输入环形区、hop 双缓冲、频谱、单 pair 互谱/PHAT/相关、mask、时延、窗、音频历史/权重及输出双缓冲；明确缺少幅值工作区、FFT 内部 RAM、LS 工作区、指数数组、AXI/DMA FIFO 和日志。位打包是理想下界，不表示 BRAM 可按这个字节数无损装满。宽互谱的软件容器与 DSP 映射差异很大。

六路原始 PCM 搬运仍按实际容器位宽 b 计算 `6*48000*b/8 B/s`；定位重叠帧逻辑读取是其两倍，不一定都经过 DDR。缓存共享、端口数量和对齐需 A 排程，不能简单合并成总线实测带宽。

## 6. 舍入、溢出与饱和约定候选

- 默认候选为最近舍入、恰好半 LSB 时取偶数；所有算子使用同一明确规则，负数也要验证。
- 所有乘法/求和先扩位，量化输出时再检查范围、舍入和饱和。若舍入本身越界，也必须计入饱和统计；禁止有符号回绕。
- 输出音频允许候选“饱和并上报计数”，但定位中间级一旦溢出不能只夹紧后假装正常候选，需明确该级/该 pair/该帧无效传播策略，等待 A 确认。
- 无效 pair 使用独立 valid bit；数值 0 是合法时延，不能替代 NaN。矩阵秩不足和有效 pair<5 继续拒绝。
- 权重和、0/1 端点与 480 点过渡终点必须明确。系数逐项舍入可能破坏单位增益，不能通过未说明的归一化暗改算法。
