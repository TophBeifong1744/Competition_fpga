# THREE-WAY-AUDIO-01：同组六麦输入的三路音频对照

状态：B 本地开发与验证完成，待试听及 A 复核。分支 task/member-b-h3-preparation，基线 e3f49050cb695beaa8e2ea869ae365a8135a6750。仅新增本任务包，未推送、未合入；fixed-das-01、tracked-audio-01 和原算法均保留。不是 H3、实板或完整 PKG-B-ALG 验收通过。

## 三路分别是什么

| 文件 | 分支 | 控制来源 |
|---|---|---|
| single.wav | mic0 单麦参考，补 4 点公共处理延时 | 不做方向选择 |
| manual.wav | 连续固定方向 DAS | 场景生成器明确给出的真实方向 |
| auto.wav | 原定位/跟踪器控制的连续音频 | 仅六麦输入，不传入真实方向 |

三路使用完全相同的六麦浮点混合输入、相同长度、48 kHz，并共享同一 PCM 缩放因子。没有分别归一化、削顶、互相关移位或事后挑选对齐位置。单麦也补 4 点处理延时，但其麦克风本身的传播偏移仍存在；公共处理时间对齐不等于三路声学相位完全相同。因此与 manual 的波形差异不是纯粹的声源重建误差，尤其不能把单麦的相位差当作音质较差。

真实方向分支从起始就有理想方向，不等待捕获；自动分支保留捕获、HOLD、单麦回退和 10 ms 过渡，这些都会体现在整体对照中。真实方向分支是诊断参考，不是数学上必然最优的波束或严格性能上界。这里只使用固定场景方向，没有动态真值轨迹。

## 场景、来源和指标

前三个场景直接读取 tracked-audio-01/evidence/run03 的原输入，没有再生成或改写；自动分支量化前浮点输出 SHA-256 与前一任务分别完全匹配。每个 result.json 记录输入来源及哈希。

- stable：正前方单声源。自动分支经历捕获后跟踪。
- drop-return：正前方声源，输入中人工静音后恢复。旧元数据没有全段有效真值，本任务依据冻结生成器的固定 +x 几何构建手动参考，并在评分时排除静音和恢复后的滤波历史预热；没有把静音期间记为有真实方向。
- outside：声源在 +y、范围外。手动分支刻意指向这个真实声源作为诊断，自动分支按已选策略始终使用单麦。两者不同是范围策略的预期，不能记作自动捕获失败。
- directional-interference：新生成的球面传播合成宽带场景，目标 +x，干扰 +y，干扰源幅度系数 0.5，seed=2026092001。沿用原周期渲染器，生成 147456 点，截取 [1536,145920) 内部区间；没有房间反射，没有自然语音。源参数、输入哈希及目标/干扰浮点分量存入 result.json、input-components.npz。

每场景保存 evaluation-mask.npy。评分共同排除前后各 256 点及无效预热；drop-return 另外排除原始采样编号 [16000,30008) 的静音/恢复历史区间。不会各分支单独挑选成功片段。WAV 保留全段供试听，不把静音掩码应用为音频剪辑。

所有场景均记录 RMS、峰值、与 manual 的波形 RMS 差和归一化平方差；这些是诊断数，不是 STOI/PESQ、听感评分或信噪比。前三个场景未提供噪声分离依据，因此不报告音频 SNR 收益。

定向干扰场景有显式目标/干扰分量，因此另计算目标/干扰功率比（TIR）：

| 分支 | TIR | 相对单麦变化 |
|---|---:|---:|
| 单麦 | 6.023 dB | 0 |
| 真实方向 | 9.096 dB | +3.073 dB |
| 自动跟踪 | 8.701 dB | +2.678 dB |

本例自动比真实方向参考低约 0.395 dB。该差距综合了定位误差、捕获等待、保持/回退和过渡，不能将其全部归因于定位角度误差。该批是四个教学/诊断场景，不是独立验证集，也没有统计置信区间或泛化结论。

分量评价对自动分支采用“混合输入先定位/跟踪 → 冻结事件序列 → 将同一控制逐采样重放到目标和干扰分量”。没有对干净目标重新定位；检查分量输出相加等于混合输出，容差 3e-15。评价用真值分量不回流自动控制。

## 代码与验证

- compare_audio.py：三分支组合、固定方向参考、冻结控制重放和公共掩码指标。
- run_task.py：引用前三组冻结输入、构建定向干扰数据、运行测试、生成 12 份 WAV、保存跟踪事件和哈希。
- test_compare.py：5 项测试。手动真值改为错误方向时，manual 输出改变而 auto 输出和跟踪事件逐值不变；检查手动分支块长一致、重放与原输出一致和分量线性、单麦延时/长度、共同掩码评价。
- evidence/run01/：5 项测试通过，四场景均完成；含原始 float 分量、输出 WAV、评价掩码、事件和运行来源。

在任务包目录，使用 Python 3.12 / NumPy 2.3.5：

```powershell
python -B run_task.py --out evidence/reviewer-run01
```

输出目录必须不存在。任务依赖前两个同级任务包，交付时一并保留；前三组输入按前任务路径引用，不重复大文件。files.json 是本任务 SHA-256 清单（自身除外）。本地输入哈希一致不构成所有 CPU 环境的严格再生成保证。
