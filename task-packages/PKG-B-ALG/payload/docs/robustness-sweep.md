# 固定候选的适用范围验证

本轮已完成，不修改 β=0.75、5/12 捕获规则或默认算法。结果与全部副作用见 `evidence/robustness-report.md`，原始结果在 `evidence/robustness-run-01/`。

## 你现在可以怎样复核

1. 先读报告的36个范围内条件。正确率分母包含拒绝帧；不要只看有效误差P95。
2. 对照12个范围外条件与真正缺席统计；原始候选误输出和最终跟踪误输出分别看。
3. 看每条件6次发声的捕获成功数及配对延迟差。失捕不是零延迟；HOLD不是新的定位成功。
4. 最后核对适用边界：同频带噪声有收益，单频噪声靠近锥边缘会退步，长尾声下的低覆盖仍未解决。

## 在任务包根目录复现

```powershell
python -B run_validation.py --out evidence/reviewer-robustness-tests
python -B payload/model/python/robustness_sweep.py --out evidence/reviewer-robustness-run
```

输出目录必须是新的，已固定结果不可覆盖。仅依赖本包NumPy环境；全量生成和定位需要数分钟。
`audit_robustness.py`独立复核原固定批次，已有审计输出时拒绝覆盖；可用 `python -B -c "import audit_robustness as a; print(a.audit())"` 只读复核。
`report_robustness.py`从已保存结果渲染报告；可用其 `render()` 返回值核对报告而不写文件。

## 实验链路

预先固定配置 → 新种子生成探测声/噪声 → 探测声先门控再做因果RIR卷积 → 六麦适配与1024/512分帧 → 原PHAT及β=.75分别定位 → 相同5/12跟踪 → 最后才加入接收存在标签计算指标。

四个方法共享同一输入帧。方向真值、发声时间和RIR支撑均不进入定位和捕获决策。独立原始候选输出留存，可区分前端候选与跟踪层影响。每个试验保存输入哈希；保存36份实际RIR和48份标注，可确定性重建波形，未保存144份大体积混合波形。

尾声模型是每麦独立随机FIR，不是真实房间的空间扩散场。各类噪声相同全频RMS不代表相同带内SNR；本轮仅是条件内算法配对比较。目标在单一固定方向出现两次，不含声源身份或运动测试。
