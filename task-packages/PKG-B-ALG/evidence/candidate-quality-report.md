# 原定位候选质量：新种子研究结果

版本candidate-quality-0.1；B开发，完整包指定复核/合入人为A。保留所有原定位/捕获实现和旧结果；新weighted_gcc.py是独立研究候选，未替换默认算法。固定参照与前一捕获研究记录的174个哈希条目均保持一致（两个清单可能引用相同文件）。本轮未覆盖总工程、Git提交、推送或合并。

结论：只把PHAT归一化指数从1改为0.75，噪声下候选的时差一致性和有效输出有改善；接相同5/12捕获后，独立新种子的正确输出率仍提高。但同锥竞争者的一项准确率退步，不能作为全场景替换方案。

## 同一新验证集对照

开发种子2026091000–2026091009，最终验证2026091100–2026091109；均与之前捕获研究的种子不重叠。β=0.75与0.5的候选、顺序和判据在开发前固定；两者开发均通过，按事先优先较小改动的规则选0.75。验证前selection.json已锁定源代码哈希，验证后无改参。

以下噪声约0 dB指标来自同一10种子、2890个完整在场帧，HOLD和过渡帧不混入：

| 指标 | 原PHAT | β=0.75 |
|---|---:|---:|
| 原始候选有效帧 | 1322/2890 | 1683/2890 |
| 原始候选有效率 | 45.744% | 58.235% |
| 原始候选≤10°正确率 | 41.972% | 54.602% |
| 原始候选有效P95误差 | 10.843° | 10.323° |
| 同接5/12后新有效率 | 37.474% | 53.945% |
| 同接5/12后≤10°正确率 | 34.464% | 50.727% |
| 同接5/12后新有效P95误差 | 10.782° | 10.232° |
| 同接5/12后不在场错误新输出 | 0/1630 | 0/1630 |

后处理新有效率增加16.471个百分点，≤10°正确率增加16.263个百分点。10/10新种子正确率均提高，逐种子增幅10.727–28.028个百分点；新方案逐种子新有效率49.481–57.439%。这是种子配对描述性统计，未将重叠帧视为独立重复或报告显著性结论。

20个目标发声段，新旧都至少捕获过一次完整在场且≤10°正确的新方向。此类首个输出相对包络起点的时长，原方案90.667–1178.667 ms，新方案76–289.333 ms；它包含渐变、对齐和候选积累，不是处理器/FPGA延迟。

## 时差候选诊断

原候选在2890个在场噪声帧中拒绝1568帧，全部包含“残差过大”，其中5帧还包含范数超限。β=0.75拒绝1207帧，其中1206帧残差过大，2帧范数超限；原因可重叠。

375个原拒绝帧被新候选接受，14个原有效帧变为拒绝，净增加361帧。没有放宽原LS接受条件，仍是残差≤0.5点、范数[0.7,1.3]等原门槛。

在全部在场帧的有限麦克风对上，相对理论球面到达时差的逐帧RMS误差，中位数从0.704点降为0.643点，P95从1.136点降为1.044点。此诊断包含有效和被拒绝帧，支持候选本身有所改善；它不同于求解器残差，不应混为一个指标，也不证明所有错误峰都已修正。

## 必须保留的退步与未解决项

- 同锥竞争者：两种方案后处理有效率都100%，但≤10°正确率从15.917%降至13.841%；不在场身份错误输出仍为97.546%。P95稍降也不能掩盖该正确率退步。
- 等强范围外竞争者：新旧后处理都零捕获；原始候选仅19帧/10帧有效，大部分仍偏向错误目标，问题没有解决。
- 正常掉声/恢复：后处理新有效率保持99.308%；β=0.75原始层在目标不发声时多1个输出，5/12层仍为0。不能宣称原始层处处无副作用。
- 噪声下后处理只有53.945%新有效，不是已经稳定连续输出；HOLD显示和超时仍必须正确处理。0/1630不代表长期零误捕获。

本次预定六项判据均通过，但判据针对噪声改善及若干风险上限，没有要求同锥≤10°正确率不降。故结论限定为噪声研究候选，不自动替换产品默认值。

## 成果和验证

- payload/model/python/weighted_gcc.py：独立部分白化GCC；β=1在原9场景×3方向上与旧GCC逐项一致。
- candidate_quality_research.py和协议JSON：开发/新种子验证隔离，固定5/12捕获，输出逐帧配对、候选诊断、存在标注评分和来源。
- candidate-development-01/：50试验，140100行方法结果、70050条候选诊断；冻结selection.json。
- candidate-heldout-01/：50新种子试验，93400行方法结果、46700条候选诊断，选定代码与开发阶段一致。
- candidate-quality-audit.json：独立检查233500行方法结果、500组逐种子/50组汇总、配对增益、延迟、质量门及参考文件；116750条诊断关联原始结果。
- candidate-tests-final/：161项完整回归通过，保留此前151项。

所有结果仍为连续合成数据；没有实测RIR、自然语音、不同阵列实装误差、硬件/定点和实时性能结论。建议下一步以新噪声类型、方向或混响条件测试候选适用范围，并保留β=1作固定对照；本次验证种子不再用于调参。完整PKG-B-ALG仍需A明确复核后，由A合入。
