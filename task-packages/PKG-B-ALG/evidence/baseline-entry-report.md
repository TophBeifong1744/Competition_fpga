# 已有六麦定位基线接入结果

开发版本 baseline-entry-0.1。B 负责，A 为完整包指定复核及合入人。当前持续开发，没有人工批准或总工程合入。

实现了从独立六麦输入到逐帧时差、方向、有效标志、拒绝原因与基础统计的命令行。数值核心为已有源码的原文摘录，测试检查 AST 一致。原模型完整快照及来源哈希保留于 reference/six-mic-baseline/。H1 读取器、分帧器、A 的原始接口副本均保持原样；没有新四麦声学模拟。

最终完整回归共 94 项通过，其中包括之前 71 项；A 的 15 项读取要求继续全部通过。最终证据见 baseline-validation-final/。新增覆盖六轴理想时差和七个波形方向、静音占位方向隔离、四种拒绝原因、错误率分母、无真值/零有效/零帧、元数据/数组拒绝、CLI 重放和不覆盖输入、数值溢出及空 NPY。

baseline-regression-final/ 记录旧模型 9 场景×3 方向×3 重复×2 帧，共 162 次同帧对照。时差最大绝对差为 0，接受标志全部相同，方向及诊断在 1e-12 绝对容差内一致。六轴 golden 同时提供独立几何理想时差、固定波形数组和原模型预期输出。这些证明接入保持了原算法，不是原算法性能改善的证据。

最终四个教学演示均为默认方位 35°、俯仰 25°、repeat=0，每个只有两个重叠帧：

| 演示 | 有效帧 | 拒绝情况 |
|---|---|---|
| clean | 2/2 | 无；有效帧 P95 三维误差约 0.027712° |
| band_noise0 | 1/2 | 1 帧残差过大 |
| interferer0 | 0/2 | 两帧残差过大，其中一帧范数也超范围 |
| silence | 0/2 | 有限时差不足及几何秩不足；全部方向为 null |

演示数据保存在 baseline-demo-*-final/，每个包含原始裁剪 NPY、元数据、逐帧结果、统计、输入/源码哈希。不要以两帧结果推广声学性能，不覆盖原 2700 行基线审计结论。全拒绝时“错误输出数为 0”不代表表现良好；应同时读有效率和 null 误差分位数。

限制：没有范围锁定、跟踪、语音增强或距离估计；没有新真实录音、硬件性能或定点验证。有效标志只代表通过原数值检查，仍可能指向错误声源；同频带噪声和竞争声源问题继续存在。文件接口限定离线合成源且固定六麦几何，不能把 H1 四通道硬件文件送进此入口。H3 完整包仍未就绪。

下一阶段可接既定允许方向范围与跟踪状态，并以原基线为对照推进整批评价；随后补音频对照和定点准备。成果集中在同一 PKG-B-ALG；完整版本经 A 明确复核后由 A 合入。本轮没有 Git 提交、推送或合并，没有覆盖总工程。
