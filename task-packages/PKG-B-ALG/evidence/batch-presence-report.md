# 多种子整批对照与目标存在标注结果

开发版本batch-presence-0.1；负责人B，完整包指定复核及合入人A。保留原基线与跟踪参数，没有调参。成果全部在同一PKG-B-ALG，没有覆盖总工程、Git提交、推送或合入。

本轮完成5场景×10种子、每次5秒的连续六麦试验。共有23350个声学帧，原定位/仅圆锥/跟踪三种方法共70050行。目标存在标注按整个帧的生成包络定义：满幅在场、全零不在场、其余过渡；后者单列且仍驱动算法。10种子共享每场景的时间表，共2335个不同标注窗口。原始标注与每trial来源均可追溯。

## 核心结果

以下为10个种子合计的稳态比例；不是实测设备性能。新有效不含HOLD。

| 场景 | 方法 | 在场新有效率 | 在场新有效P95误差 | 不在场错误新输出率 |
|---|---|---:|---:|---:|
| 正常掉声/恢复 | 原定位 | 100% | 0.480° | 0% |
| 正常掉声/恢复 | 仅圆锥 | 100% | 0.480° | 0% |
| 正常掉声/恢复 | 跟踪 | 99.308% | 0.481° | 0% |
| 同频带噪声约0 dB | 原定位 | 45.571% | 10.913° | 0.123% |
| 同频带噪声约0 dB | 仅圆锥 | 45.571% | 10.913° | 0.061% |
| 同频带噪声约0 dB | 跟踪 | 1.384% | 9.203° | 0% |
| 等强范围外竞争源 | 原定位 | 0.519% | 95.202° | 100% |
| 等强范围外竞争源 | 仅圆锥 | 0.208% | 10.839° | 0% |
| 等强范围外竞争源 | 跟踪 | 0% | 未定义 | 0% |
| 只有范围外竞争者 | 原定位 | 不适用 | 未定义 | 100% |
| 只有范围外竞争者 | 仅圆锥/跟踪 | 不适用 | 未定义 | 0% |
| 同锥竞争者 | 原定位/仅圆锥 | 100% | 19.759° | 100% |
| 同锥竞争者 | 跟踪 | 100% | 19.759° | 97.546% |

正常掉声/恢复时，跟踪2870/2890在场帧产生新输出，0/1630不在场帧产生新输出；另有343个不在场HOLD显示帧，不计误输出，但必须由显示端处理过期。

同频带噪声下只有1个种子产生跟踪新输出，共40/2890在场帧；其余9个种子为0。逐种子新有效率中位数0、范围0–13.841%。因此9.203°的P95只描述40个被选中的输出，不能宣称噪声问题解决。原定位在场新有效率逐种子范围41.522–48.097%，稳定性规则造成明显捕获损失。

等强范围外竞争源在场时，原定位只有15个有效输出，其中9个误差>30°；仅圆锥剩6个，跟踪没有捕获。圆锥确实排除了目标不在场时的范围外竞争者，但无法恢复原基线缺失的可靠候选。原定位的“不在场100%”是按指定目标任务计分，并不意味着它对实际竞争者方向估计错误。

同锥竞争者例子在场时三个方法都100%新有效，但≤10°正确输出只占全部在场帧的15.675%；在场误差>30°为0仍不足以证明选对声源。目标不发声时，跟踪1590/1630帧仍输出新方向，10种子的该比例均为97.546%。这一点直接暴露了身份不可分辨问题；降低捕获门槛不会解决它。

## 下一步依据

范围筛选能过滤范围外竞争者，但当前捕获策略在噪声下严重缺输出；应把本批次保留为不改动的参照，下一轮对候选质量或捕获机制做独立版本比较，并用新种子检验，避免在这10个种子上反复调到最好。

同锥多个稳定声源的身份问题需单列产品限制或引入可区分信息。此处仅验证连续合成数据，没有自然语音、实测房间响应、硬件或音频增强。目标在场表示目标信号分量存在，不是物理人员进出。H3仍未就绪，只有A对准确版本明确通过后由A合入。
