# 允许范围与跟踪接入记录

版本 sector-tracking-entry-0.1；B 开发，完整包指定复核及合入人为 A。本轮无人工批准，无 Git 提交、推送或合并，无总工程覆盖。

旧 SIM6-002-01 tracker.py 按字节复制进 payload/model/python/sector_tracker.py，默认参数均保持不变。新 six_mic_track.py 接收定位结果及帧可用时间，消费分帧器 reset_before，并提供静态文件配置、会话内释放/重新配置、逐帧与汇总输出。真值只用于后处理评价，不进入跟踪状态决策。

旧六麦定位、核心数值代码、读取器、分帧器均不修改。基线行与未启用跟踪时逐项相同。状态分为 SEARCH/ACQUIRE/LOCKED/HOLD；HOLD 只显示旧方向，不能算新有效输出。沿用 +x 半角 30°圆锥、5 帧捕获、8°捕获稳定性、20°更新门、200 ms 显示保持和 30 ms 输入间断门。

最终 128 项完整回归通过：原 94 项、18 项历史跟踪规则及16 项新集成测试。包括500次时间推进与历史实现输出相同、帧重置、超时间隔、到期释放、配置/人工释放、无效时间不改状态、同锥竞争者的身份局限、连续输入、CLI 重放与拒绝覆盖。最终源码哈希和测试见 tracking-validation-final/。

五个单种子教学例子共 445 个重叠帧；每例从连续 49152 点内部裁剪 46080 点，产生89帧。实跑结果：

| 场景 | 原定位有效帧 | 新有效跟踪帧 | 关键行为 |
|---|---:|---:|---|
| stable | 89/89 | 85/89 | 第5帧、64 ms首次锁定 |
| drop-return | 64/89 | 56/89 | 18帧HOLD，7帧SEARCH，64/640 ms两次捕获 |
| outside | 89/89 | 0/89 | 89帧范围外，全部SEARCH |
| band_noise0 | 36/89 | 0/89 | 连续可靠候选不足，始终未锁定 |
| interferer0 | 0/89 | 0/89 | 原定位全部因残差拒绝，无捕获 |

时间取帧末可用时刻，64 ms是采样跨度，不是硬件延迟。drop-return为同时通道静音的教学信号，无逐帧目标存在真值；角度误差留空，不作在场/不在场性能结论。输出保留完整输入、配置和代码哈希，均位于 tracking-demo-*-final/。

没有按本轮结果调参。低 SNR 和竞争声源仍没有新有效输出，同锥内另一个稳定声源仍可被接受；圆锥和方向连续性不能保证说话人身份。旧报告的失败结论保留在 reference/sector-lock-v0.1/REPORT.md。本轮是集成与教学验证，不替代此前整体声学审计或 SIM6-002 实验。
