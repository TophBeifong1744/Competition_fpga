## 2. 交接点与时间语义（软件即可先实现）

最终部署数据流：PL PCM流 → 分帧/定位/跟踪 → 方向命令 → 连续DAS → 单声道输出。PS不处在逐样本往返路径中；调试复制到DDR，不以PS读取速度决定采样时钟。当前单麦抓取虽由PS轮询DMA，也不能作为最终PL独立连续数据面的已实现证据。

本包提出以下**语义字段**供 H3 使用，物理端口/寄存器地址/位宽尚未冻结，不新增硬件协议：

| 交接点 | 需要携带的信息 | 时序及失败规则 |
|---|---|---|
| 采集→算法 | profile/schema、acquisition/config/geometry版本；sample_id；同步通道码值；stream_error/flags；比例与坐标来源 | 下游valid/ready只管已缓存组；不能反压停麦时钟。满/溢出保留原因与编号，不补假样本 |
| 帧→定位/跟踪 | frame_id、first/last_sample_id、窗/采样率、有效pair及拒绝原因、方向坐标系/单位 | 输入gap、重启、配置切换必须按B规则重置/切段；未知坐标禁止DOA，仍可格式诊断 |
| 跟踪→DAS | 方向向量或延时及单位、fresh/held/lost状态、置信度/有效性、source_frame_id、result_available_sample_id、apply_at_sample_id、config_version | 决定何时可用及何时生效，过期命令不可回写已输出音频。持有/重捕获/切换策略沿用B，缺结果用显式fallback |
| DAS→输出 | mono PCM与定点比例、对应原输入时间区间、输出起点/总延迟、削顶/欠载/不连续标志、mode与命令版本 | 延时线状态与流边界对齐；重置历史/滤波器/交叉渐变行为要有golden。输出时钟若独立需速率匹配，不隐藏丢/重样 |
| PL↔PS | AXI4-Lite配置影子提交与原子状态快照；DMA块+元数据；块级完成/错误事件 | 地址与IRQ实现仍待A，不允许每样本Python轮询。SD/网络吞吐需测，不等于DDR总线峰值 |

特别防止软件“看见未来”：若方向由完整1024点帧末产生，不能拿它处理已输出的帧前音频却宣称零延迟在线。B可选择延后命令生效，或缓存对应音频并把缓存延迟完整计入。离线整段平均方向/双向滤波结果只能标离线参考。

|---|---:|---:|---:|---:|---:|---:|
| V1四麦需求 | 4+6=10 | 655360 | 1066666 | 80000 | 575360 | 986666 |
| 六麦离线需求 | 6+15=21 | 655360 | 1066666 | 168000 | 487360 | 898666 |

8000周期来自已有FFT任务的规划，不是对任意输入间断/背压的承诺；7406是其测试调度间隔，不是最小II证明。61.44MHz列仅把相同周期需求换算到另一个场景，**未在该时钟新建FFT实现**。建议H3规划预留至少20% hop周期给抖动/集成余量（T，待A/B确认），则四麦/六麦在61.44MHz分别余444288/356288周期，100MHz分别余773332/685332周期供其他处理。不能仅凭余量正数判断系统可用。

共享排程上限应逐项审查：

`C_window + C_FFT + C_cross/PHAT + C_IFFT + C_peak/LS/rank/tracker + C_spectrum_IO + C_stall + C_shared_DAS <= floor(fclk*hop/Fs)`

独立并行单元应提交依赖图与关键路径，不盲加所有延迟；共享单元必须算争用、初始化/模式切换、装配/重排、DMA/FIFO背压。音频路径持续每20.833µs产生一个样本；若复用定位运算器，须证明逐样本deadline不会被整帧批处理阻塞。

|---|---:|---:|---|
| 24位PCM净负载 | 576000 B/s | 864000 B/s | 不含元数据、总线填充或协议 |
| 32位PCM容器净负载 | 768000 B/s | 1152000 B/s | 不是CSV文件大小 |

| PCM环1024点/通道 | 16384 B | 24576 B | 不自动兼作下行输出历史 |

| 单个1024全复IFFT装配区 | 8192 B | 8192 B | 不能把513点直接送1024核 |
| 单声道输出hop双缓冲 | 4096 B | 4096 B | 输出int32净负载192000 B/s |

B现有缩放候选部分缓存75317B packed / 84364B逐元素对齐，以及增长候选84551B/92572B只是既有不完整清单；不得与上表重叠项重复相加，也不得称整机内存下界/上限。FFT核内部6RAMB18单列，容量含校验位和配置宽深，不能直接当可用字节。端口数、bank冲突、复制、CDC、日志、描述符、缓存行、LS/倒数工作区及输出缓冲均须补齐。

单麦抓取FIFO16KiB：21.333ms是空到满、完全不服务的理想时间，不是允许的PS最大停顿承诺；已有占用会缩短。4000B包填充5.208ms；DDR 1MiB预留仅属于当前单次抓取，不能给连续多路算法沿用。预算公式 `fifo_records >= ceil(Fs*T_blackout)+burst_margin`，记录字节数另乘；A提供可保证的服务暂停上界再定容量。

DMA所有权顺序：CPU准备缓冲/flush → DMA写期间CPU不读改 → 完成或明确失败后invalidate → CPU读取/导出 → 回收；地址、长度、缓存行与DMA宽度共同对齐。MM2S若以后获准必须另外处理播放缓冲flush和欠载，不凭S2MM测试证明。DDR读/写、CPU copy、FFT谱访问、文件出口分别统计，不能用64bit×时钟理论峰值作实测带宽。

## 4. 延迟预算：不同概念不能混填

- 1024点帧收集21.333ms、hop10.667ms是C。首次5连续合格帧最佳收集 `(1024+4*512)/48000=64ms`，无效帧会推迟；不改 acquire_frames=5。
- 单麦启动丢弃4096点=85.333ms（配置C），不是稳态每帧延迟。理想CIC3/R64群延迟 `3*(64-1)/2=94.5` 个PDM周期≈30.762µs=1.4765625 PCM周期；不含同步/流水/抽取输出相位，不是实测总延迟。
- B common_delay=4样本≈0.0833ms、history=8、fade=480样本10ms、hold200ms来自六麦候选，不是完整音频端到端延迟；几何、符号、负延时转因果与插值支持需重新核对。
- B须拆开 `L_acq + L_frame_or_command_wait + L_processing + L_audio_buffer + L_fractional_delay + L_output_device`，说明哪些并行、哪些随模式改变，分别给启动、稳态、命令生效、恢复和最坏值。最终上限U由A/团队和B协商；本次不制造全链实测数字。

## 5. FFT/IFFT具体候选及替代方案

优先复用F已有1共享核，避免重复开发。输入/输出64bit：实部[24:0]、虚部[56:32]置于两个32位槽；应用S25F23，输入高位符号扩展，输出取25位再按符号解释。N=1024、自然序；每第1024个有效握手标TLAST；配置握手后再发该帧。FFT配置0x0AAAAB，IFFT0x0AAAAA，各10级每级右移1。前向为DFT/N，逆向为正指数和/N；**逆向不可额外再除1024**。

每通道每帧只做一次前向FFT后复用频谱。半谱到全谱必须共轭补全，DC/Nyquist按实信号规则处理；不同pair的缓冲生命周期、自然序地址、FFT/IFFT切换、有限背压需排程。若处理所有513频点，六麦互谱/模长/除法各7695次/帧；B预算300–4000Hz有效79点不意味着当前代码只计算79点，不能擅自削减运算量。

互谱因前向FFT缩放变成原来的2^-20；PHAT epsilon及低能量判据必须用同一物理尺度，避免epsilon=1e-15直接定点成零。IP convergent_rounding不是全部节点舍入已确认。IP溢出应标该帧无效，不能假设其内部饱和；自写CIC等经过论证的模算术也不能套“所有内部加法一律饱和”破坏原滤波行为。保持默认PHAT/跟踪语义不变，候选差异单列。

其他方案仅作条件分支：若共享Burst预算失败，再评估不同Burst/流水架构、多核或自写/HLS核；它们在本包没有XCI、综合/测量证据，资源/II保持U，不宣称更快或一定能放下。不因为六麦软件入库而启动这些实现。

## 6. 可以先审什么、还不能接什么

可以现在审：输入profile/数值标度、帧与连续区间、因果跟踪→DAS语义、异常fallback、逐级定点候选、FFT历史证据、运算/缓存清单、脱离板卡的RTL/TB接口计划。

尚不能直接接板：六路采集、六路DMA、三维几何/秩求解的最终资源、全链定点算法、跨61.44/100MHz时钟的未设计CDC、Codec连续音频输出、完整四麦定位/波束验收。四麦6pair与二维几何、六麦15pair与三维秩不同，不能只把常量CHANNELS从6改4就认定移植完成。可复用的是接口思想/参数化控制/FFT配置候选，不是未经复核的六路资源或坐标。

这些“不能接板”不阻断B继续软件闭环。C不承担算法或采集技术验收；仪器、映射、板级安全由A/硬件负责人确认。RTL按用户语言规则：简单.v；复杂.sv可保留，但Module Reference采用保持位宽/符号/握手/延迟的纯.v包装；测试平台可.sv。
