# B 提交预算与闭环材料时必须包含的字段

本表供H3复核，不改默认算法。允许带明确T/U参数提交研究结果；不得把未知伪装为已测，或借未知要求所有工作停工。

## 1. 一行一个模块的预算账本

| 字段组 | 必填内容 |
|---|---|
| 身份 | B提交SHA、算法/配置/协议版本；依赖FFT候选SHA与XCI哈希；输入文件/种子/生成器SHA；默认算法未改的diff说明 |
| 场景 | 通道profile，Fs/N/hop/窗，pair映射、几何/声速与来源；正常/低能量/缺pair/重捕获/交叉渐变等最坏分支 |
| 模块 | 窗、FFT、谱装配、互谱、模长/倒数、IFFT、峰/插值、几何/秩/质量、跟踪、延时生成、DAS、混合、输出管理分别列项 |
| 运算 | 每帧、每样本、每秒的乘/加/复乘/除/开方/比较/查表次数；分支上界、共享并行数；别把NumPy函数调用当一周期 |
| 调度 | 依赖、首输出延迟、服务间隔II、配置切换、读写及停顿周期、WCET计算条件；所在时钟域与CDC；共享DAS逐样本deadline |
| 缓存 | 对象名、形状/元素数、W/F/signed、packed与字节对齐大小、内存位置、live区间、读写端口/并发、双缓冲、复制、FFT内置RAM及遗漏项 |
| 定点 | 输入/系数/累加器每级格式、整数码最大最小、物理标度、乘法扩位、舍入点/方式、饱和或受论证模回绕；计数、invalid及恢复策略 |
| FFT/PHAT | 实际正反配置、缩放/指数、频率顺序、共轭/DC/Nyquist、epsilon及输入公共增益映射，分母零/低能量保护；不能挪用冒烟16码容差 |
| 数据搬运 | 各生产者/消费者每秒字节、每块长度/开销、缓存行与DMA对齐、环形队列容量、服务暂停上界、溢出/欠载策略及CPU缓存所有权 |
| 音频 | common delay、插值tap、历史、权重更新、fade中断导致旧权重稠密化、两支滤波器/混合开销、输出缩放/削顶、fallback与连续性 |
| 结果与限制 | 平均/最坏周期的证据种类；延迟分解、资源实测或估计来源；数值误差、离散状态差异、哪些字段仍U及负责人 |

B现有六麦预算包括54+12=66 MAC/输出、3.168M MAC/s以及混合乘加另计；先沿用为核查对象。若优化为别的结构须单列数学等价/状态等价与实际调度证据，不能默默降低上界。固定点54位累加器是候选分析，不意味着实测零饱和。应用输入+1超出S24F23正端点，必须记录其量化/饱和处理。

## 2. 对齐向量（无需新增四麦声学模拟）

| 编号 | 输入/动作 | 必须输出的golden与比较 |
|---|---|---|
| V01 标度/格式 | 0、−8388608、8388607、±半满量程、+1浮点端点、公共增益超范围；ID跨2^32、接近uint64上限 | 精确整数码、缩放、饱和计数；uint64不得经float；非法值应拒绝 |
| V02 帧/时间 | 长度N−1/N/N+hop、截段首ID非零、gap/重复/乱序、错误行、重启/换配置 | 帧first/last ID、覆盖/尾部处理、reset标志、不得跨间断拼帧；可用人工码型而非声学模拟 |
| V03 窗与FFT | 零、冲激、DC、Nyquist、bin对齐/非对齐正弦、复数近满量程、固定种子宽带、正反变换 | 窗后码、FFT实虚整数、索引/TLAST、正反比例、DC/Nyquist、溢出/舍入；分别浮点与供应商位精确模型对照 |
| V04 PHAT | 零分母、epsilon上下、极弱频点、共轭对、负/正lag、带边频点 | 缩放后的互谱/模长/倒数/PHAT整数，屏蔽原因、有效pair；epsilon不能量化成零后悄悄沿用 |
| V05 定位与秩 | B已有六麦合成及研究边缘例，pair缺失/冲突、低秩/病态、相同峰、插值分母近零 | 每pair lag/质量、几何残差、秩/拒绝原因、方向/有效性；不新增四麦模拟、不把稳定等于正确 |
| V06 离散跟踪 | 扇区边界、五帧捕获门槛、刚好hold到期、fresh/held/lost切换、gap恢复 | 逐帧完整状态与命令，量化前后有差异即逐项报告；不能只交角度RMSE掩盖误捕获/延迟 |
| V07 因果DAS | 常量、冲激、整数/分数延时、负延时转因果、命令在帧末才可用、fade中途新命令/失锁 | 每输出样本依赖的输入ID、命令apply_at ID、权重、累加、削顶、fallback；不得用未来帧处理已输出样本 |
| V08 AXIS/缓存 | 输入间断/输出背压、TLAST异常、复位中断帧、FIFO满、输出欠载、配置中途更新 | 握手稳定性、超时/invalid与恢复、丢样编号；未写RTL时可先给事务级向量和预期规则，不冒称板测 |
| V09 实际输入范围 | 已有单麦安静/歌曲诊断包 | 只能验证读取、数值与单通道输出/旁路；不可复制成多麦用于定位或算法精度；来源标签与未测字段保留 |

每向量保存：vector_id/profile、输入文件SHA、原始/量化输入、每级输出、状态轨迹、expected_valid/拒绝原因、确定种子/生成器版本、容差来源、命令、环境、运行日志。字节差异与数值差异分开；浮点允许有依据的容差，控制/编号/flags默认要求精确一致，算法离散差异必须说明并由B/A共同裁定，不能自定阈值掩盖。

## 4. H3 判定必须分层

本约束包由A交B评审；B完整算法包另由A组织H3。依次区分：文档/合同可用 → 软件可复现 → 固定点与离散状态可接受 → 调度/缓存满足 → 对应模块仿真/实现 → 已授权硬件闭环。不能用本包或PR #3批准替代其中任何后续证据。
