# Results

本目录保存小型、经过确认、可追溯的结果摘要，例如：

- 仿真回归摘要；
- RTL 与 MATLAB 位精确对比；
- Vivado 资源、时序和功耗摘要；
- 板上吞吐、丢样、DOA 误差、SNR 提升与长稳测试；
- 用于报告的最终图表。
- 定位的 P50/P95 误差、有效输出比例、错误指向比例和无效原因；
- 使用同一四通道输入得到的单麦、手动真实方向、自动估计方向三路对照；
- 目标/干扰角度、距离、高度、频带、输入 SNR、混响条件和评价方法。

每份结果必须注明日期、Git 提交、工具版本、板卡/硬件版本、实验条件、复现命令和 PASS/FAIL。原始录音、完整波形、bitstream 和大体积导出文件不直接提交到 Git。

模型、仿真与板上实测必须分目录和分标题标识。理想阵列响应不得写成实测音频收益；只报告有效帧会造成选择偏差，全部有效、拒绝和错误帧都必须进入统计。
